## 3. 第 1 步：认识输入网表（**这一节不要跳过**）

### 3.1 赛题给的三个文件

路径：`extracted/赛题数据本身/netlist/`

| 文件 | 是什么 | 我们要不要用它 |
|---|---|---|
| `OPA_loopgain.netlist` | **真正的电路网表**，Spectre 格式，含 `OPA` 子电路 + 顶层 TestBench | ✅ **模块二的唯一输入** |
| `OPA_loopgain.scs` | 仿真控制文件（`include` 模型库、`dcOp`/`ac` 分析语句、`save` 节点） | ❌ 模块三/四才用 |
| `OPA_loopgain.map` | 原理图 instance ↔ 网表节点的对照表 | ⚠️ 只用来**核对器件数**，不参与解析 |

先看一眼 `.map` 能帮你建立信心：它列出了原理图上的 **41 个 instance**。
而解析 `.netlist` 会得到 **59 个器件**。**为什么不一致？**

> **因为 poly 电阻在网表里被按 segment 展开成了串联分段。**
> 原理图上的 `R0` 一个器件，在网表里是 `R0`、`R0_2_res_gen` … `R0_10_res_gen` 共 **10 段**，
> `R3` 同理。所以 41 − 2 + 20 = **59**。
>
> 这个账在答辩时会被问到（"你识别出来多少个器件？"），**先记住**：
> **原理图器件 41 个 / 网表器件 59 个 / 其中 20 个是 2 只 poly 电阻的串联分段。**

### 3.2 器件构成速查

| 器件 | 型号 `model` | 端子顺序 | 数量 | 尺寸变量 |
|---|---|---|---|---|
| NMOS | `n_mos_a` | `(D G S B)` | 16（NM0–NM15） | `NMx_l` / `NMx_fw` / `NMx_m` |
| PMOS | `p_mos_a` | `(D G S B)` | 13（PM0–PM12） | `PMx_l` / `PMx_fw` / `PMx_m` |
| poly 电阻 | `res_n_poly` / `res_p_poly` | `(p n)` | 24 段（来自 R0/R1/R2/R3/R5/R6） | `Rx_segL` / `Rx_segW` |
| MIM 电容 | `cap_mim` | `(p n)` | 6（C0/C2/C3/C4/C5/C11） | `Cx_l` |

**原始优化变量总数 = 16×3 + 13×3 + 6×2 + 6×1 = 48 + 39 + 12 + 6 = 105。**

> 注意 `w` 在网表里叫 **`fw`**（finger width）。赛题 PDF 里写的是 `M1_w`，
> 本 PDK 导出的是 `NM1_fw`，**是同一个东西**。报告里要解释这一句，否则评委会以为你漏了 W。

### 3.3 Spectre 网表的四个坑（解析器要专门处理）

| 坑 | 长什么样 | 不处理会怎样 |
|---|---|---|
| **续行** | 器件语句跨十几行，续行以 `+` 开头 | 每行只解析出半个器件，参数全丢 |
| **两种注释** | `//` 整行或行内；`*` 整行 | 把注释当成器件 |
| **派生参数** | `ad=(NM15_fw<300n)?((0*(9e-14+...)))/1:...` | 里面有变量名，但它是**因变量**，不是优化变量；误当成变量会让计数虚高 |
| **长度前缀命名** | `R3_10_res_gen`、`R0_2_res_gen` | 字符串排序会把 `R3_10` 排到 `R3_2` 前面，输出顺序错乱 |

第 3 个坑最关键，**直接决定你的变量个数对不对**：

> 只有**值是裸标识符**的参数才是变量（`w=NM15_fw` ✅），
> 值是数字或表达式的是常量／派生量（`w=10u` ❌、`ad=(NM15_fw<300n)?...` ❌）。

## 4. 第 2 步：先人工看懂电路（**你的金标准**）

在写任何代码之前，**你必须自己能说出这个电路是什么**。否则智能体算出来的东西你没法验收。

### 4.1 判读结论

这是一个 **PMOS 输入的两级全差分运放**：

```
                 VDDA
                  │
        ┌─────────┴─────────┐        ← PM1 尾电流源 (m=8)
        │        PM1        │
        └────┬─────────┬────┘
           PM9        PM10             ← 输入差分对 (m=2)
        (VINP)      (VINN)
             │      │
       net4 ─┘      └─ net44
             │      │
       NM4 ──┤      ├── NM5            ← 折叠共源共栅（栅极 IREF）
       NM6 ──┤      ├── NM7            ← 底部电流阱（栅极 net53）
         ┌───┘      └───┐
        net0          net8             ← 第一级高阻输出节点
         │              │
    PM2 ─┤         ├─ PM3              ← CMFB 注入管 (m=40, 栅极 vcmfb)
         │              │
    PM7 ─┴─ VOUTP   VOUTN ─┴─ PM11     ← 第二级共源放大
    NM8 ────┘         └──── NM9        ← 第二级有源负载 (m=4)
         │              │
    R1+C11 ──────────── R2+C0          ← 米勒补偿（R 串联 C，跨在第一级和第二级之间）

    R0 链: VOUTP ──[10 段]── outaverage ──[10 段]── VOUTN : R3 链   ← 共模取样
    C2 / C3 : outaverage 到两个输出的滤波电容
    outaverage → PM12 栅极 与 VCM → PM8 栅极 : CMFB 误差放大器差分对
    PM12/PM8 ─ NM13/NM12 ─ NM11/NM10 ─ PM6/PM5 : CMFB 放大器
    CMFB 输出 vcmfb → PM2/PM3 栅极
```

### 4.2 逐条推演（这就是报告里"模块识别依据"要写的东西）

| 结论 | 你是怎么推出来的（**看端子，不看器件名**） |
|---|---|
| **NMOS 电流镜（8 管）** | `NM2 NM3 NM6 NM7 NM8 NM9 NM12 NM13` 的**栅极全是 `net53`、源极全是 `GNDA`**；其中 `NM2` 栅极=漏极（栅漏短接），是参考管。共栅共源 = 电流镜的标准画法 |
| **PMOS 电流镜（PM0/PM1/PM4）** | 栅极全是 `net6`、源极全是 `VDDA`；`PM0` 栅漏短接作参考 |
| **PMOS 电流镜（PM5/PM6）** | 栅极全是 `net5`、源极 `VDDA`；`PM5` 栅漏短接 |
| **PMOS 电流镜（PM2/PM3）** | 栅极全是 `vcmfb`、源极 `VDDA`（共模反馈的执行管，m=40） |
| **输入差分对** | `PM9/PM10` 同型号、**源极同接 `net37`**、栅极分别接**输入端口** `VINP`/`VINN` |
| **尾电流源** | `PM1` 的漏极接 `net37`，正好是差分对的公共源 |
| **折叠共源共栅** | `NM4` 的源极 `net4` = `NM6` 的漏极（上下叠起来）；`NM5`/`NM7` 同理 |
| **输出级** | `PM7`(栅极 `net0`) 漏极接 `VOUTP`，`PM11`(栅极 `net8`) 漏极接 `VOUTN`；栅极接的正是第一级高阻节点 |
| **Dummy 器件** | `R5(net11,net11)`、`R6(net12,net12)`、`C4(net11,net11)`、`C5(net12,net12)` —— **两个端子接在同一个网上**，电气上根本不通，纯粹是版图/占位用 |
| **共模取样网络** | `R0` 从 `VOUTP` 出发经 10 段到 `outaverage`，`R3` 从 `outaverage` 经 10 段到 `VOUTN`。**两条链在 `outaverage` 汇合** —— 这就是共模电平 |
| **CMFB 误差放大器** | `PM12`(栅极 `outaverage`) 与 `PM8`(栅极 `VCM`) 共源 `net13`，构成差分对：一个接"检测到的共模"，一个接"目标共模" |
| **米勒补偿** | `R1(net0,net17)` + `C11(net17,VOUTP)` 串联，跨在第一级节点 `net0` 和第二级输出 `VOUTP` 之间；`R2`+`C0` 是它的镜像支路 |

### 4.3 匹配清单 —— 手工数一遍（**分两类，这是本版最关键的概念**）

#### (a) 图对称对（自同构 σ，22 对）

在"差分端口对换"下两侧可以互换，尺寸必须完全一致：

```
输入对   ：PM9 = PM10
第一级   ：NM4=NM5（折叠cascode） NM6=NM7（底部电流阱） PM7=PM11（输出管）
第二级   ：NM8 = NM9
CMFB注入 ：PM2 = PM3
输出二极管：NM14 = NM15
补偿支路 ：R1 = R2      C11 = C0
取样网络 ：R0 链 与 R3 链 逐段对应（R0↔R3_10, R0_2↔R3_9, … 共 10 对）
取样电容 ：C2 = C3
Dummy 岛 ：R5 = R6      C4 = C5
```

#### (b) 工艺匹配对（**不是**图对称，4 对）

```
CMFB 误差放大器：PM8 = PM12   ← 输入对：栅极分别是 VCM 与 outaverage
                 NM12 = NM13  ← 镜像负载：由 PM8/PM12 的漏极对应 net3↔net52 推出
                 NM10 = NM11  ← 共源共栅：同上
主输入对        ：PM9 = PM10  ← 同时也在 (a) 里
```

**为什么必须分两类**：`VCM` 是基准输入、`outaverage` 是取样节点，把二者互换**整个网表并不自同构**
（`net5` 上挂着二极管接法的 `PM5`，`vcmfb` 上却没有对应器件）。这类"必须一致"来自**版图工程要求**，
只能**局部**判定，不能冒充全局对称 —— 详见第 9 节。

**合计 25 个不重复配对。** 后面代码算出来的配对如果和这张表对不上，就是代码有 bug —— **这就是"金标准"的意义**。

## 5. 第 3 步：架构设计 —— 为什么不能"全交给大模型"

模块一的思路是"提示词约束 + 校验兜底"。模块二**不能照搬**，因为网表里的器件太多、连接关系太密：

| 理由 | 具体后果 |
|---|---|
| **事实不能概率化** | 59 个器件、约 150 条端子连接。让模型"读"网表，它一定会漏器件、编网名，而且**每次跑的结果还不一样** |
| **判定规则本来就是确定的** | "栅极相同、源极相同就是电流镜"是精确规则，用代码算 100% 正确、耗时 0 成本 |
| **评分要的是"不能错"** | 6.3(1) 明写"每错一个约束扣 1 分"，概率性输出在这里是纯风险 |
| **但评分也要求"决策依据"** | 赛题 6.2 要求报告记录"为何约减掉某参数、为何保留某变量"，这确实需要自然语言论述 |

所以模块二采用**三段式**：

```
输入网表
   │
   ├─ 第 1 段  netlist_parser.py    确定性解析   →  器件/端子/参数/变量   【事实】
   │
   ├─ 第 2 段  topo_analyzer.py     确定性识别   →  模块/配对/Dummy/约减  【结论】
   │                    │
   │                    └─→ 打包成"事实包" JSON
   │
   └─ 第 3 段  agent.py + 大模型     只写"为什么"  →  决策依据文案        【论证】
                        │
                        └─ 校验：不许编造器件名、必须覆盖每条规则
                             ↓ 不合格就带着问题重试；仍不合格 → 规则兜底文案
                        交付物（永远完整可交）
```

**一句话记住这个分工**：
> **代码负责"是什么"，模型负责"为什么"。模型永远拿不到改结论的权力。**

好处有两个，答辩时都要讲：
1. **可复现**：同一份网表，跑一百次结论完全一样，与模型无关；
2. **可降级**：模型挂了、Key 没了、断网了，加 `--no-llm` 依然能产出完整交付物（只是决策依据变成规则文案）。

## 6. 第 4 步：写 `netlist_parser.py`（完整代码）

在 `module2/agent/` 下新建 `netlist_parser.py`，整段复制：

```python
# -*- coding: utf-8 -*-
"""
模块二 · 第 1 层：确定性网表解析器（不调用大模型）

职责：把 Spectre 网表文本变成结构化对象 —— 子电路、端口、器件、端子、参数、变量。
这一层的输出必须 100% 可复现：网表里写了什么，就解析出什么，不允许"猜"。

解析难点（本 PDK 网表的真实情况）：
1. 器件语句跨行，续行以 `+` 开头，必须先拼成一整行再解析；
2. 注释有 `//`（整行或行内）和 `*`（整行）两种；
3. MOS 的 ad/as/pd/ps/nrd/nrs/sa/sb 是**派生参数表达式**，
   里面也含变量名（如 PM3_fw），但它们是**因变量**，不是优化变量；
4. 真正可优化的只有尺寸参数（w/l/m/segL/segW/...），
   且只有"值是裸标识符"的才叫变量（w=10u 是常量）。
"""
from __future__ import annotations

import re
from dataclasses import dataclass, field
from pathlib import Path

# ---------- 常量表 ----------

# PDK 模型名 -> 逻辑器件类型
MODEL_KIND = {
    "n_mos_a": "nmos",
    "p_mos_a": "pmos",
    "res_n_poly": "res",
    "res_p_poly": "res",
    "cap_mim": "cap",
}

# 只有这些参数是"尺寸参数"，才有资格成为优化变量
SIZE_PARAMS = ("w", "l", "m", "multi", "seg", "segL", "segW", "r", "c", "nf", "fw")

# MOS 的端口顺序（Spectre：D G S B）
MOS_NETS = ("d", "g", "s", "b")
# 两端器件的端口顺序（R / C）
TWO_NETS = ("p", "n")

# 值是裸标识符才算变量；含数字/运算符/括号的都是常量或表达式
IDENT_RE = re.compile(r"^[A-Za-z_]\w*$")
# 器件语句：NAME (net1 net2 ...) model param=value ...
DEVICE_RE = re.compile(r"^(\S+)\s*\(([^)]*)\)\s*(\S+)\s*(.*)$")
# 参数：key=value（value 取到下一个空白）
PARAM_RE = re.compile(r"([A-Za-z_]\w*)\s*=\s*(\S+)")
SUBCKT_RE = re.compile(r"^subckt\s+(\S+)\s*\(([^)]*)\)", re.I)
ENDS_RE = re.compile(r"^ends\b", re.I)


# ---------- 数据结构 ----------

@dataclass
class Device:
    """一个器件实例。"""
    name: str
    nets: tuple[str, ...]
    model: str
    params: dict[str, str] = field(default_factory=dict)
    line_no: int = 0
    raw: str = ""

    @property
    def kind(self) -> str:
        return MODEL_KIND.get(self.model.lower(), "unknown")

    @property
    def net_map(self) -> dict[str, str]:
        """端口名 -> 网名，MOS 用 d/g/s/b，两端器件用 p/n。"""
        keys = MOS_NETS if self.kind in ("nmos", "pmos") else TWO_NETS
        return dict(zip(keys, self.nets))

    @property
    def size_params(self) -> dict[str, str]:
        return {k: v for k, v in self.params.items() if k in SIZE_PARAMS}

    @property
    def variables(self) -> dict[str, str]:
        """尺寸参数里"值是裸标识符"的 -> 优化变量。返回 {参数名: 变量名}。"""
        out = {}
        for k, v in self.size_params.items():
            if IDENT_RE.match(v):
                out[k] = v
        return out

    @property
    def var_names(self) -> list[str]:
        return sorted(self.variables.values())

    def is_diode_connected(self) -> bool:
        """栅极与漏极同网 = 二极管接法（电流镜的参考管）。"""
        if self.kind not in ("nmos", "pmos"):
            return False
        m = self.net_map
        return m.get("g") == m.get("d")

    def is_two_terminal_shorted(self) -> bool:
        """两端器件两个端子接同一网 = 电气上悬空无用（Dummy 的典型特征）。"""
        return len(self.nets) == 2 and self.nets[0] == self.nets[1]

    def size_suffix_set(self) -> frozenset:
        return frozenset(self.size_params.keys())


@dataclass
class Circuit:
    subckt: str
    ports: list[str]
    devices: list[Device]
    top_devices: list[Device] = field(default_factory=list)
    source: str = ""

    def by_name(self, name: str) -> Device | None:
        for d in self.devices:
            if d.name == name:
                return d
        return None

    @property
    def all_variables(self) -> list[str]:
        """原始变量清单（去重、排序）。"""
        seen = []
        for d in self.devices:
            for v in d.var_names:
                if v not in seen:
                    seen.append(v)
        return seen


# ---------- 解析 ----------

def _strip_comments(text: str) -> list[str]:
    """去掉整行注释（// 与 * 开头）与行内 // 注释。"""
    out = []
    for line in text.splitlines():
        s = line.strip()
        if not s or s.startswith("//") or s.startswith("*"):
            continue
        if "//" in s:
            s = s.split("//", 1)[0].strip()
            if not s:
                continue
        out.append(s)
    return out


def _join_continuations(lines: list[str]) -> list[tuple[int, str]]:
    """把以 `+` 开头的续行拼到上一行；返回 (起始行号, 完整语句)。"""
    joined: list[tuple[int, str]] = []
    for i, s in enumerate(lines, start=1):
        if s.startswith("+") and joined:
            no, prev = joined[-1]
            joined[-1] = (no, prev + " " + s[1:].strip())
        else:
            joined.append((i, s))
    return joined


def parse_netlist(path: str | Path) -> Circuit:
    """解析网表文件，返回 Circuit。只取第一个 subckt 作为 DUT。"""
    p = Path(path)
    raw_lines = _strip_comments(p.read_text(encoding="utf-8", errors="replace"))
    stmts = _join_continuations(raw_lines)

    subckt, ports = "", []
    devices: list[Device] = []
    top_devices: list[Device] = []
    inside = False

    for no, s in stmts:
        m = SUBCKT_RE.match(s)
        if m:
            subckt = m.group(1)
            ports = m.group(2).split()
            inside = True
            continue
        if ENDS_RE.match(s):
            inside = False
            continue
        if s.lower().startswith("parameters"):   # 裸关键字，跳过
            continue

        dm = DEVICE_RE.match(s)
        if not dm:
            continue
        name, nets, model, tail = dm.groups()
        params = dict(PARAM_RE.findall(tail))
        dev = Device(name=name, nets=tuple(nets.split()), model=model,
                     params=params, line_no=no, raw=s)
        if inside:
            devices.append(dev)
        else:
            top_devices.append(dev)

    return Circuit(subckt=subckt, ports=ports, devices=devices,
                   top_devices=top_devices, source=str(p))

设计原则：**结构判定必须可复现，大模型只负责"讲道理"**。

2026-10-14 修正说明（初版有 4 处问题，全部已修，并有自检断言兜底）
==================================================================
F1 关系分离：初版用一个 σ 同时承担"图对称"和"工艺匹配"两种语义。

   （误差放大器输入对必须一致），**不是**图对称（VCM 是基准输入、outaverage

   （只要求在两条臂内部一致，不要求全局成立）。
F2 σ 全局校验：任何器件在 σ 下必须有镜像对象，否则拒绝该配对并逐对回退。
F3 电流镜判据补强：桶键补 model（原来只分 nmos/pmos，不同型号会被并成一组）；
   无二极管参考管的组改判 common_gate_pair，不再写"复制参考电流"；
   短接/悬空 MOS 不参与；补 references / confidence 字段。
F4 配对可追溯：每一对都登记 relation（symmetry / differential / arm_match），
   报告里能看出"这一对凭什么成立"。

识别用的证据链（全部来自网表本身，不依赖器件命名）：
  E1 端口/网表事实：端子连接、器件 model、参数取值
  E2 电气判据：二极管接法、两端同网、共栅共源
  E3 对称（自同构）：差分端口对换下的图自同构 —— WL 颜色细化 + 全局校验
  E4 匹配（局部支路）：由差分对出发，沿两臂对应网做结构对应（只局部成立）
  E5 功能网络：CMFB 取样网络（电阻割点）、尾电流、输出级

# 参与合并的尺寸参数（不含 m / multi —— 它们是比值旋钮）
MERGE_PARAMS = ("w", "l", "segL", "segW", "r", "c")

RAILS = {"0", "gnd!", "gnda", "gnd", "vdda", "vdd", "vssa", "vss", "sub"}

# ---------- 小工具 ----------

def _natkey(s: str):
    """自然排序键：NM2 < NM13（字符串排序会把 NM13 排到 NM2 前面）。"""
    return [int(t) if t.isdigit() else t for t in re.split(r"(\d+)", s)]


def _const_params(d: Device) -> dict:
    """器件上"真正的常量参数"，用于判断两台器件是不是同一种画法。

    注意：MOS 的 ad/as/pd/ps/nrd/nrs/sa/sb 是**派生表达式**，
    里面嵌了本器件自己的变量名（如 NM6_fw），逐字比较会把所有 MOS 都判成不同款，
    所以这里把"值引用了本器件变量"的参数一律排除，只留纯常量
    （multi / sca / trise / option_vop ...）以及常量尺寸（如电容 w=30u、m=2）。
    """
    varnames = set(d.variables.values())
    out = {}
    for k, v in d.params.items():
        if IDENT_RE.match(v):          # 裸标识符 = 变量本身，跳过
            continue
        if any(re.search(r"\b" + re.escape(vn) + r"\b", v) for vn in varnames):
            continue                   # 派生表达式，跳过
        out[k] = v
    return out


def _same_style(a: Device, b: Device) -> bool:
    return (a.model == b.model
            and a.size_suffix_set() == b.size_suffix_set()
            and _const_params(a) == _const_params(b))


def _orderings(d: Device):
    """两端器件的两个端子顺序无关，允许交换。"""
    yield d.nets
    if len(d.nets) == 2:
        yield (d.nets[1], d.nets[0])


def _roles(d: Device):
    """端子在连接图里的角色标签：MOS 用 d/g/s/b，两端器件统一 't'。

    两端器件的两个端子电气等价、网表书写顺序任意
    （`C2 (outaverage VOUTP)` 与 `C3 (VOUTN outaverage)` 就是反着写的），
    所以不能拿"第几个端子"当角色，否则会把一对本来对应的器件判成不同结构。
    """
    if d.kind in ("nmos", "pmos"):
        return ("d", "g", "s", "b")[:len(d.nets)]
    return ("t",) * len(d.nets)


def _multi_key(d: Device):
    return d.params.get("multi", d.params.get("m"))


class UnionFind:
    def __init__(self):
        self.p: dict = {}

    def find(self, x):
        self.p.setdefault(x, x)
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra != rb:
            self.p[rb] = ra


# ---------- E3：图对称（WL 颜色细化 + 全局自同构校验） ----------

def _diff_port_pairs(ports) -> list:
    """端口名里的差分对：末位 P/N 成对（VINP/VINN、VOUTP/VOUTN、INP/INN...）。

    只按命名规则识别、不写死具体端口名，隐藏电路换名字也适用。
    """
    pset = {p for p in ports if p}
    out = []
    for p in sorted(pset):
        if p[-1] not in "PpNn":
            continue
        sib = p[:-1] + ("N" if p[-1] in "Pp" else "P")
        if sib in pset and sib != p and p < sib:
            out.append((p, sib))
    return out


def _net_role(n: str, ports, diff_prefix: dict) -> str:
    """网的初色：差分端口对折叠成同一角色，电源地保留真实名，内部网统一 'N'。"""
    if n is None or n == "":
        return "NC"
    if n.lower() in RAILS:
        return n.lower()
    if n in diff_prefix:
        return "DIFF:" + diff_prefix[n]
    if n in ports:
        return n
    return "N"


def _canon(values) -> dict:
    m: dict = {}
    for v in values:
        if v not in m:
            m[v] = len(m)
    return m


def wl_colors(c: Circuit):
    """Weisfeiler-Lehman 颜色细化：给"器件—网"二部图算稳定颜色。

    同色 = 在该图的自同构下**可能**互换。这是识别"图对称器件"的正确基础：
      - 只看尺寸参数值不行：参数化后每个器件尺寸都是独立变量名，永远不同；
      - 只看"同 model + 同 multi"会跨支路误配（PM0 与 PM5 都是 p_mos_a/multi=1
        的二极管接法管子，却分属两条不同镜像支路）。
    颜色细化会把"周围连接结构不同"的器件自动分开，而真正对称的两只会保持同色。
    """
    devs = list(c.devices)
    nets = sorted({n for d in devs for n in d.nets})
    diff_prefix = {}
    for p, q in _diff_port_pairs(c.ports):
        diff_prefix[p] = p[:-1]
        diff_prefix[q] = p[:-1]
    ports = set(c.ports)

    net_color: dict = {n: _net_role(n, ports, diff_prefix) for n in nets}
    dev_color: dict = {}
    for _ in range(16):
        dsig = {}
        for d in devs:
            cols = [net_color[n] for n in d.nets]
            if d.kind not in ("nmos", "pmos"):
                cols = sorted(cols)          # 两端器件端子无序
            dsig[d.name] = (d.model, _multi_key(d), tuple(cols))
        cm = _canon(dsig.values())
        dev_color = {k: cm[v] for k, v in dsig.items()}

        nsig = {}
        for n in nets:
            nsig[n] = tuple(sorted((dev_color[d.name], r)
                                   for d in devs for r, x in zip(_roles(d), d.nets) if x == n))
        cm2 = _canon(nsig.values())
        new = {n: cm2[v] for n, v in nsig.items()}
        if new == net_color:
            break
        net_color = new
    return dev_color, net_color


def _align(a: Device, b: Device, sigma: dict):
    """求两只"互为镜像"器件的端子对应；不相容返回 None。

    MOS 是四端有向器件，按位置对应；两端器件的两个端子可互换，两种对应都试，
    取与当前 σ 相容的一种；两种都相容且派生的映射不同则视为歧义（返回 None）。
    """
    cands = [list(zip(a.nets, b.nets))]
    if len(a.nets) == 2 and len(b.nets) == 2:
        cands.append(list(zip(a.nets, b.nets[::-1])))
    good = []
    for pr in cands:
        ok = True
        for x, y in pr:
            if x == y:
                continue
            if sigma.get(x, y) != y or sigma.get(y, x) != x:
                ok = False
                break
        if ok:
            good.append(pr)
    if not good:
        return None
    if len(good) > 1:
        m1 = {x: y for x, y in good[0] if x != y}
        m2 = {x: y for x, y in good[1] if x != y}
        if m1 != m2:
            return None
    return good[0]


def _verify_sigma(c: Circuit, sigma: dict, pairs: list):
    """全局自同构校验：除配对器件外，每个器件在 σ 下都必须保持不变。

    返回 (是否通过, 找不到镜像对象的器件列表)。
    """
    images = {}
    for a, b in pairs:
        images[a.name] = b.name
        images[b.name] = a.name

    missing = []
    for d in c.devices:
        if d.name in images:
            continue
        imgs = {tuple(sigma.get(n, n) for n in pr) for pr in _orderings(d)}
        if tuple(d.nets) in imgs:                     # 自身在 σ 下不变
            continue
        hit = None
        for e in c.devices:
            if e.name == d.name or not _same_style(d, e):
                continue
            if tuple(e.nets) in imgs:
                hit = e.name
                break
        if hit is None:
            missing.append(d.name)
    return (not missing), missing


def _rebuild_sigma(c: Circuit, pairs: list) -> dict:
    sigma: dict = {}
    for p, q in _diff_port_pairs(c.ports):
        sigma[p] = q
        sigma[q] = p
    for d in c.devices:
        for n in d.nets:
            if n.lower() in RAILS:
                sigma.setdefault(n, n)
    for a, b in pairs:
        al = _align(a, b, sigma)
        if al is None:
            return sigma
        for x, y in al:
            if x != y:
                sigma[x] = y
                sigma[y] = x
    return sigma


def _solve_symmetry(c: Circuit, cands: list, banned: set):
    """在"禁用若干配对"的约束下，用**不动点迭代**求解 σ。

    为什么必须迭代而不是一遍扫过：候选对的端子对应是否唯一，取决于 σ 已经知道多少。
    以共模取样电阻链为例，链首那对（R3↔R0_10）在早期处理时"两种端子对应都说得通"，
    会被判为歧义；只有先接受靠输出端口锚定的那一对，链上的对应才逐段唯一。
    所以：先接受当前唯一可判的，再回头重试之前歧义的，直到不再前进。
    """
    sigma = _rebuild_sigma(c, [])
    pairs: list = []
    paired: set = set()
    pending = [p for p in cands
               if tuple(sorted((p[0].name, p[1].name))) not in banned]
    skipped: list = []
    while pending:
        progressed = False
        rest = []
        for a, b in pending:
            if a.name in paired or b.name in paired:
                continue
            al = _align(a, b, sigma)
            if al is None:
                rest.append((a, b))
                continue
            for x, y in al:
                if x != y:
                    sigma[x] = y
                    sigma[y] = x
            pairs.append((a, b))
            paired.update((a.name, b.name))
            progressed = True
        if not progressed:
            skipped = [(a.name, b.name, "端子对应存在歧义或与已建立的 σ 冲突")
                       for a, b in rest]
            break
        pending = rest
    return pairs, sigma, skipped


def find_symmetry_pairs(c: Circuit) -> dict:
    """E3：找**真正的图对称**器件对（差分端口对换下的自同构）。

    ① WL 颜色细化；② 只取颜色类恰为 2 的对；③ 不动点迭代建立 σ；
    ④ **全局校验**（每个器件都必须有镜像对象），不通过就把卷入冲突的配对拉黑重解。
    宁可少认，不可错认。
    """
    devs = list(c.devices)
    dev_color, _ = wl_colors(c)
    classes: dict = {}
    for d in devs:
        classes.setdefault(dev_color[d.name], []).append(d)
    ordered = sorted(classes.items(), key=lambda kv: str(kv[0]))
    cands = [(m[0], m[1]) for _, m in ordered if len(m) == 2]
    # 颜色类 >2 的（多重对称）：本引擎只处理两两对称，保守跳过并登记，供人工确认
    multifold = [sorted(x.name for x in m) for _, m in ordered if len(m) > 2]

    banned: set = set()
    pairs, sigma, skipped = _solve_symmetry(c, cands, banned)
    rejected = list(skipped)
    for _ in range(6):
        ok, missing = _verify_sigma(c, sigma, pairs)
        if ok:
            break
        ms = set(missing)
        newban = {tuple(sorted((a.name, b.name))) for a, b in pairs
                  if ms & (set(a.nets) | set(b.nets))}
        if not newban and pairs:
            a, b = pairs[-1]
            newban = {tuple(sorted((a.name, b.name)))}
        if not newban:
            break
        for a, b in pairs:
            if tuple(sorted((a.name, b.name))) in newban:
                rejected.append((a.name, b.name,
                                 "全局自同构校验失败：%d 个器件找不到镜像对象" % len(missing)))
        banned |= newban
        pairs, sigma, skipped = _solve_symmetry(c, cands, banned)
        rejected = list(skipped) + rejected

    ok, missing = _verify_sigma(c, sigma, pairs)
    return {"pairs": pairs, "sigma": sigma, "verified": ok,
            "missing_images": missing, "rejected": rejected,
            "multifold_classes": multifold}


# ---------- E4：工艺匹配（差分对 + 局部支路对应） ----------

def find_differential_pairs(c: Circuit, mos: list, dummy_names: set) -> list:
    """差分对：同款 MOS、**共尾节点**（非电源地）、栅极互不相同且漏极互不相同，
    且该尾节点下这一尺寸档**恰好两只**。

    为什么要求"恰好两只"：同一条尾节点上可能挂着 3 只以上同款管子（如输出支路），
    此时配对不唯一，宁可不判、交给人工确认。
    "主输入对"的判据是两栅同属一对差分端口（按端口名 P/N 成对识别）。
    """
    diff_pref = {}
    for p, q in _diff_port_pairs(c.ports):
        diff_pref[p] = p[:-1]
        diff_pref[q] = p[:-1]
    out = []
    buckets: dict = {}
    for d in mos:
        if d.name in dummy_names:
            continue
        src = d.net_map.get("s")
        if not src or src.lower() in RAILS:
            continue
        buckets.setdefault((src, d.model, _multi_key(d)), []).append(d)
    for (src, model, multi), members in sorted(buckets.items(), key=lambda kv: str(kv[0])):
        if len(members) != 2:
            continue
        a, b = members
        ma, mb = a.net_map, b.net_map
        if ma["g"] == mb["g"] or ma["d"] == mb["d"]:
            continue
        pref_a, pref_b = diff_pref.get(ma["g"]), diff_pref.get(mb["g"])
        is_main = bool(pref_a and pref_b and pref_a == pref_b)
        out.append({"a": a, "b": b, "tail": src,
                    "role": "main" if is_main else "auxiliary",
                    "gates": [ma["g"], mb["g"]]})
    return out


def arm_match(c: Circuit, seeds: list, already: set, dummy_names: set):
    """E4：由匹配对出发，沿"两臂对应网"做**局部**结构对应。

    与 σ（全局自同构）的区别：
      · σ 要求整个网表一致 —— 因此"VCM 对 outaverage"这种匹配关系不可能成立；
      · 本函数只要求在两条臂内部一致，走出臂的范围就停。
    典型收获：CMFB 误差放大器两侧的镜像负载与共源共栅
      （PM12↔PM8 是差分对 -> net52↔net3 -> NM13↔NM12、NM11↔NM10）。
      由此得到的 net5↔vcmfb **只在臂内成立**，不会外溢到 PM5/PM6/PM2/PM3
      —— 这正是"匹配"与"对称"必须分开的原因。
    配对不唯一时保守跳过（宁少不错）。
    """
    corr: dict = {}

    def consistent(x, y):
        if x == y:
            return True
        if x in corr and corr[x] != y:
            return False
        if y in corr and corr[y] != x:
            return False
        return True

    def put(x, y):
        if not consistent(x, y):
            return False
        if x != y:
            corr[x] = y
            corr[y] = x
        return True

    devs = list(c.devices)
    paired = set(already)
    pairs: list = []
    work: list = []
    for s in seeds:
        a, b = s["a"], s["b"]
        if a.kind in ("nmos", "pmos"):
            put(a.net_map["d"], b.net_map["d"])
            work.append((a.net_map["d"], b.net_map["d"]))

    guard = 0
    while work and guard < 128:
        guard += 1
        na, nb = work.pop(0)
        for role in ("d", "g", "s", "t"):
            left = [d for d in devs
                    if d.name not in dummy_names and d.name not in paired
                    and any(r == role and x == na for r, x in zip(_roles(d), d.nets))]
            right = [d for d in devs
                     if d.name not in dummy_names and d.name not in paired
                     and any(r == role and x == nb for r, x in zip(_roles(d), d.nets))]
            if len(left) != 1 or len(right) != 1:
                continue                      # 不唯一 -> 保守跳过
            x, y = left[0], right[0]
            if not _same_style(x, y):
                continue
            # 端子重复模式必须一致：二极管接法（d==g）只能对应二极管接法。
            # 否则会把 PM5(net5,net5,...) 与 PM6(vcmfb,net5,...) 误配成同位器件。
            if len(set(x.nets)) != len(set(y.nets)):
                continue
            options = [list(zip(x.nets, y.nets))]
            if len(x.nets) == 2 and len(y.nets) == 2:
                options.append(list(zip(x.nets, y.nets[::-1])))
            chosen = None
            for opt in options:
                if all(consistent(xn, yn) for xn, yn in opt):
                    chosen = opt
                    break
            if chosen is None:
                continue
            for xn, yn in chosen:
                put(xn, yn)
            pairs.append((x, y, corr.get(na, na), corr.get(nb, nb)))
            paired.update((x.name, y.name))
            for xn, yn in chosen:
                if xn != yn and (xn, yn) not in work and (yn, xn) not in work:
                    work.append((xn, yn))
    return pairs, corr


# ---------- 主分析 ----------

def analyze(c: Circuit) -> dict:
    devs = c.devices
    mos = [d for d in devs if d.kind in ("nmos", "pmos")]
    twoterm = [d for d in devs if d.kind in ("res", "cap")]

    # ================= E2：基础电气判据 =================
    # 两端同网（R/C）以及全端子同网的 MOS 都算 Dummy：电气上构不成通路。
    dummies = [d for d in devs
               if d.is_two_terminal_shorted() or len(set(d.nets)) == 1]
    dummy_names = {d.name for d in dummies}
    diode = [d for d in mos if d.is_diode_connected() and d.name not in dummy_names]

    # ================= E5-1：CMFB 取样网络（电阻图割点） =================
    res_adj: dict = {}
    res_devs = [d for d in twoterm if d.kind == "res" and d.name not in dummy_names]
    for d in res_devs:
        res_adj.setdefault(d.nets[0], set()).add(d.nets[1])
        res_adj.setdefault(d.nets[1], set()).add(d.nets[0])

    def res_reach(start: str, blocked=None) -> set:
        seen, stack = {start}, [start]
        while stack:
            for nb in res_adj.get(stack.pop(), ()):
                if nb == blocked or nb in seen:
                    continue
                seen.add(nb)
                stack.append(nb)
        return seen

    cap_nets = set()
    for d in twoterm:
        if d.kind == "cap" and d.name not in dummy_names:
            cap_nets.update(d.nets)
    out_ports = [p for p in c.ports if p.lower() not in RAILS and p in cap_nets]
    out_pair = tuple(out_ports[:2]) if len(out_ports) >= 2 else None

    res_dev_names = {d.name for d in res_devs}
    nonres_nets: dict = {}
    for d in devs:
        if d.name in res_dev_names or d.name in dummy_names:
            continue
        for n in d.nets:
            nonres_nets.setdefault(n, []).append(d.name)

    cm_sense = None
    if out_pair:
        a, b = out_pair
        candidates = [n for n in res_reach(a)
                      if n != b and n.lower() not in RAILS
                      and b not in res_reach(a, blocked=n)
                      and nonres_nets.get(n)]
        if len(candidates) == 1:
            cm_sense = candidates[0]

    # ================= E3：图对称（自同构） =================
    sym = find_symmetry_pairs(c)
    pairing = [(a.name, b.name) for a, b in sym["pairs"]]
    paired_names = {n for p in pairing for n in p}

    # ================= E4：工艺匹配（差分对 + 局部支路对应） =================
    diff_pairs = find_differential_pairs(c, mos, dummy_names)
    match_pairs: list = []                 # (a, b, relation, why)
    for dp in diff_pairs:
        a, b = dp["a"], dp["b"]
        rel = "differential/%s" % dp["role"]
        why = "共尾节点 %s、栅极 %s/%s" % (dp["tail"], dp["gates"][0], dp["gates"][1])
        if a.name in paired_names and b.name in paired_names:
            rel += "+symmetry"
            why += "（同时通过 σ 自同构校验）"
        match_pairs.append((a, b, rel, why))
        paired_names.update((a.name, b.name))

    arm_pairs, _corr = arm_match(c, diff_pairs, paired_names, dummy_names)
    for x, y, na, nb in arm_pairs:
        match_pairs.append((x, y, "arm_match",
                            "两臂对应网 %s↔%s 上的同位器件" % (na, nb)))

    # ================= E2：电流镜组（同类型 + 同栅 + 同源） =================
    mirror_groups: list = []
    buckets: dict = {}
    for d in mos:
        if d.name in dummy_names:
            continue
        m = d.net_map
        buckets.setdefault((d.kind, d.model, m["g"], m["s"]), []).append(d)
    for (kind, model, gate, src), members in sorted(buckets.items(), key=lambda kv: str(kv[0])):
        if len(members) < 2:
            continue
        refs = [x for x in members if x.is_diode_connected()]
        ref = refs[0].name if refs else None
        if ref:
            mtype, conf = "current_mirror", (3 if len(refs) == 1 else 2)
            ev = (f"{kind}({model}) 管栅极同为 {gate}、源极同为 {src}，共 {len(members)} 管；"
                  f"其中 {ref} 栅漏短接，是参考管；其余各管按 (W/L·m) 之比复制参考电流")
            zh = ("NMOS" if kind == "nmos" else "PMOS") + " 电流镜"
        else:
            mtype, conf = "common_gate_pair", 2
            ev = (f"{kind}({model}) 管栅极同为 {gate}、源极同为 {src}，共 {len(members)} 管；"
                  f"组内无二极管接法器件 -> 不是标准电流镜，栅压由 {gate} 外部确定，"
                  f"各管电流比 = (W/L·m) 之比；仍需尺寸匹配但**不能**称参考管")
            zh = ("NMOS" if kind == "nmos" else "PMOS") + " 共栅对（无参考管）"
        mirror_groups.append({
            "type": mtype, "name_zh": zh, "kind": kind, "model": model,
            "gate": gate, "source": src, "reference": ref,
            "references": [r.name for r in refs], "confidence": conf,
            "devices": [x.name for x in members], "evidence": ev,
        })

    # CMFB 误差放大器差分对（辅助差分对）
    cmfb_pair = None
    if cm_sense:
        for dp in diff_pairs:
            if cm_sense in dp["gates"]:
                cmfb_pair = (dp["a"], dp["b"])
                break

    # ================= 功能模块清单 =================
    modules: list = []
    if dummies:
        modules.append({
            "id": "D1", "type": "dummy", "name_zh": "Dummy 器件（电气无效）",
            "devices": [d.name for d in dummies],
            "evidence": "两端接同一节点或全端子同网：" + "、".join(
                f"{d.name}({','.join(d.nets)})" for d in dummies)
                + "。电气上不构成通路，对任何性能指标无贡献，其尺寸参数应从优化变量中剔除"
                  "（器件保留在网表中，否则仿真读不到初值）",
        })
    for i, g in enumerate(mirror_groups, 1):
        g["id"] = f"CM{i}"
        modules.append(g)
    for i, dp in enumerate(diff_pairs, 1):
        a, b = dp["a"], dp["b"]
        modules.append({
            "id": f"DP{i}", "type": "differential_pair",
            "name_zh": "输入差分对" if dp["role"] == "main" else "辅助差分对（误差放大器）",
            "devices": [a.name, b.name],
            "evidence": (f"{a.name}/{b.name} 同为 {a.model}、同 multi {_multi_key(a)}，"
                         f"源极共接 {dp['tail']}，栅极分别接 {dp['gates'][0]}/{dp['gates'][1]}；"
                         f"{'主输入对' if dp['role'] == 'main' else '非主输入（如共模反馈误差放大器输入）'}"
                         f"，两管必须严格匹配（失配直接恶化失调与 CMRR）"),
        })
    main_pair = next((dp for dp in diff_pairs if dp["role"] == "main"), None)
    if main_pair:
        tail_node = main_pair["tail"]
        pair_names = {main_pair["a"].name, main_pair["b"].name}
        tail = [d for d in mos if d.name not in dummy_names and d.name not in pair_names
                and any(x == tail_node for x in d.nets)]
        if tail:
            modules.append({
                "id": "T1", "type": "tail_current_source", "name_zh": "尾电流源",
                "devices": [d.name for d in tail],
                "evidence": (f"{tail[0].name} 的端子接在差分对公共源 {tail_node} 上，"
                             f"为输入对提供尾电流"),
            })
    if out_pair:
        outs = [d for d in mos if d.name not in dummy_names and d.nets[0] in out_pair]
        if outs:
            modules.append({
                "id": "O1", "type": "output_stage", "name_zh": "输出级",
                "devices": [d.name for d in outs],
                "evidence": f"漏极直接驱动输出端口 {out_pair[0]}/{out_pair[1]}",
            })
    if cm_sense:
        net_devs = [d for d in devs if cm_sense in d.nets and d.name not in dummy_names]
        # 取样电阻链：端点落在"从两个输出出发的电阻可达网"里的电阻（按网判断，不是按器件名）
        reach = (res_reach(out_pair[0]) | res_reach(out_pair[1])) if out_pair else set()
        chain = [d for d in res_devs if any(n in reach for n in d.nets)]
        modules.append({
            "id": "FB1", "type": "cmfb", "name_zh": "共模反馈网络（CMFB）",
            "devices": [d.name for d in net_devs],
            "evidence": (f"取样：从 {out_pair[0]}/{out_pair[1]} 各经一条纯电阻链在 "
                         f"{cm_sense} 汇合，{cm_sense} 是电阻图上分开两个输出的割点，"
                         f"链上共 {len(chain)} 段电阻；"
                         + (f"误差放大差分对 {cmfb_pair[0].name}/{cmfb_pair[1].name} 的栅极分别为 "
                            f"{cmfb_pair[0].net_map['g']}/{cmfb_pair[1].net_map['g']}；"
                            if cmfb_pair else "")
                         + f"与 {cm_sense} 直连的器件 {len(net_devs)} 个"),
        })
    if pairing:
        modules.append({
            "id": "MB1", "type": "matching", "name_zh": "对称结构（自同构 σ，已全局校验）",
            "devices": sorted({n for p in pairing for n in p}, key=_natkey),
            "evidence": "由差分端口对换（VINP/VINN、VOUTP/VOUTN）建立网表自同构 σ："
                        "WL 颜色细化求候选，再**全局校验**每个器件都有镜像对象，"
                        "不通过则逐对回退；满足 σ(d1)=d2 的器件对结构严格对称，尺寸必须完全一致。"
                        "配对结果：" + "，".join(f"{a}={b}" for a, b in pairing),
        })
    if match_pairs:
        modules.append({
            "id": "MB2", "type": "matching", "name_zh": "工艺匹配结构（差分对 + 两臂对应）",
            "devices": sorted({n for a, b, _, _ in match_pairs for n in (a.name, b.name)},
                              key=_natkey),
            "evidence": "工艺匹配**不等于**图对称：差分对两侧栅极接的是不同信号"
                        "（例如共模反馈误差放大器的 VCM 与 outaverage），整体网表并不自同构。"
                        "所以这里用「差分对种子 + 两臂对应网的结构对应」单独识别，只在两条臂内部成立；"
                        "配对结果：" + "，".join(f"{a.name}={b.name}[{rel}]"
                                                for a, b, rel, _ in match_pairs),
        })

    # ================= 参数约减 =================
    uf = UnionFind()
    for d in devs:
        for p in d.variables:
            uf.find((d.name, p))
    prefer: dict = {}                      # 并查集根 -> 期望的规范器件名（可追溯）

    # R2：同名变量天然共享（电阻串联分段）
    var_shared: dict = {}
    for d in devs:
        for v in d.var_names:
            var_shared.setdefault(v, []).append(d.name)
    segment_groups = {v: ns for v, ns in var_shared.items() if len(ns) > 1}
    for v, names in segment_groups.items():
        first = None
        for n in names:
            dd = c.by_name(n)
            if not dd:
                continue
            for p, vv in dd.variables.items():
                if vv != v:
                    continue
                key = (n, p)
                if first is None:
                    first = key
                else:
                    uf.union(first, key)

    # R3/R4：对称对与匹配对完全共享尺寸（含 m）
    pair_notes: dict = {}
    pair_relation: list = []
    strict_pairs = [(a.name, b.name, "symmetry") for a, b in sym["pairs"]]
    strict_pairs += [(a.name, b.name, rel) for a, b, rel, _ in match_pairs]
    seen_pairs: set = set()
    for a, b, rel in strict_pairs:
        key = tuple(sorted((a, b)))
        if key in seen_pairs:
            continue
        seen_pairs.add(key)
        da, db = c.by_name(a), c.by_name(b)
        if not da or not db:
            continue
        shared = []
        for p in PAIR_MERGE_PARAMS:
            if p in da.variables and p in db.variables:
                uf.union((da.name, p), (db.name, p))
                shared.append(p)
        pair_notes.setdefault(a, []).append(b)
        pair_notes.setdefault(b, []).append(a)
        pair_relation.append({"a": a, "b": b, "relation": rel, "shared": sorted(shared)})

    # R5：电流镜组内共享 w/l（比值由 m 承担，m 逐管保留）
    for g in mirror_groups:
        members = [m for m in (c.by_name(n) for n in g["devices"]) if m]
        for p in ("w", "l"):
            anchor = None
            if g.get("reference"):
                ref_d = c.by_name(g["reference"])
                if ref_d and p in ref_d.variables:
                    anchor = ref_d
            if anchor is None:
                anchor = next((m for m in members if p in m.variables), None)
            if not anchor:
                continue
            for m in members:
                if p in m.variables:
                    uf.union((anchor.name, p), (m.name, p))
            # 只有"真正有参考管"的镜像组才用参考管名当规范名；
            # 无参考管的共栅对保持自然序最小的器件名（避免凭空改名，便于与 PDK 初值文件对齐）
            if g.get("reference"):
                prefer[uf.find((anchor.name, p))] = anchor.name

    # 规范名：优先用基准器件/参考管的变量名（可追溯）
    groups: dict = {}
    for d in devs:
        if d.name in dummy_names:
            continue
        for p, v in d.variables.items():
            groups.setdefault(uf.find((d.name, p)), []).append((d.name, p, v))

    reduced: list = []
    rename: dict = {}
    for root, items in groups.items():
        names = sorted({v for _, _, v in items}, key=_natkey)
        pref = prefer.get(root)
        by_dev = sorted({n for n, _, _ in items}, key=lambda n: (_natkey(n), n))
        want_dev = pref or by_dev[0]
        cand = [v for n, _, v in items if n == want_dev]
        canon = cand[0] if cand else names[0]
        for _, _, v in items:
            rename[v] = canon
        reduced.append({
            "var": canon,
            "param": items[0][1],
            "devices": sorted({n for n, _, _ in items}, key=_natkey),
            "merged_from": names,
            "kind": "integer" if items[0][1] in INTEGER_PARAMS else "continuous",
            "unit": UNIT_BY_PARAM.get(items[0][1], "-"),
        })
    reduced.sort(key=lambda r: _natkey(r["var"]))

    fixed_vars = [{"var": v, "param": p, "device": d.name,
                   "reason": "Dummy 器件（电气无效），尺寸不参与优化"}
                  for d in dummies for p, v in d.variables.items()]

    by_cat: dict = {}
    for r in reduced:
        k = "整数(m)" if r["kind"] == "integer" else r["param"]
        by_cat[k] = by_cat.get(k, 0) + 1

    # ================= 自检断言（防止"看起来对、实际不自洽"） =================
    assert sym["verified"], "σ 未通过全局自同构校验：%s" % sym["missing_images"]
    all_names = {d.name for d in devs}
    for a, b, _ in strict_pairs:
        assert a in all_names and b in all_names, "配对里出现不存在的器件 %s/%s" % (a, b)
    for m in mirror_groups:
        for n in m["devices"]:
            assert n in all_names, "电流镜组里出现不存在的器件 %s" % n
        if m["type"] == "current_mirror":
            assert m["reference"] in m["devices"], "电流镜缺少参考管"
    assert len({r["var"] for r in reduced}) == len(reduced), "约减后变量名有重复"

    return {
        "subckt": c.subckt, "ports": c.ports, "device_count": len(devs),
        "raw_variable_count": len(c.all_variables), "raw_variables": c.all_variables,
        "modules": modules, "mirror_groups": mirror_groups,
        "pairing": [{"a": a, "b": b} for a, b in pairing],
        "pairing_relation": pair_relation,
        "symmetry_verified": sym["verified"],
        "symmetry_missing_images": sym["missing_images"],
        "symmetry_rejected": [{"a": a, "b": b, "why": w} for a, b, w in sym["rejected"]],
        "multifold_classes": sym["multifold_classes"],
        "match_pairs": [{"a": a.name, "b": b.name, "relation": rel, "why": why}
                        for a, b, rel, why in match_pairs],
        "seeds": ["差分端口对换 " + "/".join("%s~%s" % (p, q)
                                            for p, q in _diff_port_pairs(c.ports))],
        "sigma_conflicts": [],
        "segment_groups": segment_groups,
        "dummies": [d.name for d in dummies],
        "diode_connected": [d.name for d in diode],
        "cm_sense_node": cm_sense,
        "output_pair": list(out_pair) if out_pair else [],
        "reduced_variable_count": len(reduced),
        "reduced_variables": reduced,
        "reduced_by_category": by_cat,
        "fixed_variables": fixed_vars,
        "rename_map": rename,
        "pair_notes": pair_notes,
    }

## 9. 第 7 步：读懂两个关系 —— 对称（自同构）与匹配（局部支路）（**全篇最难，也最值钱**）

`topo_analyzer.py` 里最重要的机制是**两种"必须一致"的关系**。它们看着像，其实完全不同；
初版把两者混成一个 σ，结果配出了假对称对 —— 下面每个坑都是真实踩过的。

### 9.1 要解决的问题

你要找出"哪些器件必须严格匹配"。**不能靠器件名**（Hidden 电路里命名可能完全不同），只能靠**结构**。

### 9.2 关系一：图对称（自同构 σ）

精确定义：**存在把网表映射到自身的变换 σ，使 σ(器件A)=器件B** —— A、B 在结构上完全可互换。

**怎么算（三步）：**

1. **WL 颜色细化**：给"器件—网"二部图迭代上色。差分端口（`VINP/VINN`、`VOUTP/VOUTN`）先折叠成
   同一个角色，于是真正对称的器件保持同色；周围结构不同的器件会自动分开（例如 `PM0` 与 `PM5`
   都是 `p_mos_a`、都是二极管接法，但 `net6` 与 `net5` 邻域不同，颜色必然不同，不会误配）。
2. **只取颜色类恰为 2 的对**（三重以上对称不配对，避免"谁跟谁配"不唯一）。
3. **全局校验**：在 σ 下**每个器件都必须能找到镜像对象**，否则把卷入冲突的配对拉黑重解。

**为什么第 3 步是命门**：初版把 CMFB 差分对（`PM8`/`PM12`，栅极 `VCM`/`outaverage`）当种子，
强制 σ(`VCM`)=`outaverage`；再经 `NM11↔NM10` 强制 σ(`net5`)=`vcmfb`。
而 `net5` 上挂着二极管接法的 `PM5`，`vcmfb` 上没有对应器件 —— 于是
`PM5/PM6/PM2/PM3/R0/R3/C2/C3` **8 个器件在 σ 下都找不到镜像对象**，σ 已经不是自同构了，
而初版的冲突检测器却报"无冲突"（"两端本来就相同的端子"被直接跳过，绕过了校验）。
本版把这 8 个器件的校验做成硬断言：**校验不过就回退配对**，宁少不错。

### 9.3 关系二：工艺匹配（局部支路对应，**不是**自同构）

差分对两侧的栅极接的是**不同信号**（`VINP`/`VINN`，或 `VCM`/`outaverage`），
所以"把两侧互换"根本不是网表的对称 —— 但版图工程上它们**必须一致**。于是单独用一条规则：

| 步骤 | 做法 | 本例结果 |
|---|---|---|
| ① 找差分对 | 同型号、**共尾节点**（非电源地）、双栅不同、双漏不同，且该尾节点下同尺寸档**恰好两只** | `PM9/PM10`（主输入）、`PM8/PM12`（CMFB 误差放大器） |
| ② 两臂对应 | 从差分对出发登记两条臂的对应网（`net3↔net52`），再沿对应网找**同位置、同端子角色、同款**的器件 | `NM13↔NM12`（镜像负载）、`NM11↔NM10`（共源共栅） |
| ③ 保守退出 | 配对不唯一、或走出臂的范围就停 | 不会外溢到 `PM5/PM6/PM2/PM3` |

**这就是把两类关系分开的价值**：`net5↔vcmfb` 这条对应**只在 CMFB 放大器内部成立**，
用它去认 `NM11↔NM10` 是对的，用它去要求"整个网表自同构"就是错的。

> 答辩高频问题：**"为什么 `PM8/PM12` 不算对称对？"**
> 答：`VCM` 是基准输入、`outaverage` 是取样节点，二者不可互换，全图并不自同构；
> 它们是**匹配对**（版图要求一致），依据是"共尾节点 + 双栅双漏"，不是 σ。

### 9.4 五条约减规则

| 规则 | 内容 | 本例删掉多少 |
|---|---|---|
| **R1** | Dummy（两端同网 / 全端子同网）尺寸移出优化变量 | `R5 R6 C4 C5` 共 6 个变量 |
| **R2** | 共用同一变量名的器件（串联分段）归为同一组 | 避免 `R0`~`R0_10` 被数成 10 份 |
| **R3** | **对称对**（自同构 σ）的 `w/l/m` 全部合并为一份 | 22 对 |
| **R4** | **工艺匹配对**（差分对/两臂对应）的 `w/l/m` 全部合并 | 4 对 |
| **R5** | 电流镜组内共享 `w/l`，**`m` 保持独立** | 4 个镜组 |

> **R3/R4 与 R5 的区别是刻意设计的**，答辩必问：
> - 对称对与匹配对（差分对、左右支路）两侧必须**完全一致，包括 m** —— m 不等会破坏对称性、恶化失调与 CMRR；
> - 电流镜里 `m` 是**比值旋钮**（1:4、1:8 就是靠 m 实现的），所以共享 `w/l` 但 `m` 必须留独立。
>
> 一句话：**对称对/匹配对合并 m，电流镜不合并 m。**

- risks 至少 2 条，必须是有工程意义的（例如：合并电流镜 W/L 后各支路电流只能靠 m 调节，
  若镜像管工作在非饱和区则匹配失效；Dummy 器件的尺寸虽被剔除但仍保留符号，
  仿真初值仍需 PDK 提取文件提供；工艺匹配对的匹配依据需在仿真中对齐验证）。
- 只讲事实包里能支持的话；不确定就写"需在仿真中对齐验证"。
```

```python
# -*- coding: utf-8 -*-
"""
模块二：电路网表拓扑模块识别与参数约减智能体

运行方式（必须先激活 .venv，见教程第 4 步）：
    python agent.py                       # 用默认的赛题网表
    python agent.py "D:\\path\\x.netlist"  # 指定网表
    python agent.py --check                # 只检查环境，不调模型
    python agent.py --no-llm               # 只跑确定性流程，不调模型（零成本、可离线）

三段式设计：
  第 1 段  netlist_parser  确定性解析   —— 事实来源，不允许出错
  第 2 段  topo_analyzer   确定性识别   —— 结构判定，必须可复现
  第 3 段  大模型         决策依据生成 —— 只写"为什么"，不许改结论
"""
from __future__ import annotations

import csv
import json
import os
import re
import sys
import time
from pathlib import Path

from netlist_parser import parse_netlist
from topo_analyzer import analyze, emit_reduced_netlist

HERE = Path(__file__).resolve().parent
ROOT = HERE.parent.parent            # 项目根目录
OUT_ROOT = HERE.parent               # module2/

# 赛题提供的网表（默认输入）
DEFAULT_INPUT = (ROOT / "extracted" / "赛题数据本身" / "netlist" / "OPA_loopgain.netlist")

# 本次实际使用的约减规则（会写进事实包，模型必须逐条解释）
REDUCTION_RULES = [
    {"rule": "R1", "desc": "Dummy 器件（两端接同一节点 / 全端子同网）的尺寸参数移出优化变量清单，"
                           "只保留符号供仿真读初值"},
    {"rule": "R2", "desc": "共用同一变量名的器件（如 poly 电阻的串联分段）天然共享变量，归为同一组"},
    {"rule": "R3", "desc": "对称对（差分端口对换下的图自同构 σ，**已通过全局校验**：每个器件都有"
                           "镜像对象）共享全部尺寸 w/l/m"},
    {"rule": "R4", "desc": "工艺匹配对（差分对 + 两臂对应网上的同位器件，如共模反馈误差放大器的"
                           "输入对及其镜像负载/共源共栅）共享全部尺寸 w/l/m。这类匹配**不是**图对称"
                           "（两侧栅极接的是不同信号），因此与 R3 分开判定"},
    {"rule": "R5", "desc": "电流镜组（同型号、同栅、同源）内各管共享 w/l，"
                           "各支路电流比值由 m 承担，m 保持独立"},
]


# ---------- 基础工具 ----------

def load_config() -> dict:
    with open(HERE / "config.json", "r", encoding="utf-8") as f:
        return json.load(f)


def read_text(p: Path) -> str:
    return p.read_text(encoding="utf-8").strip()


def strip_code_fence(text: str) -> str:
    t = text.strip()
    m = re.search(r"```(?:json)?\s*(.*?)```", t, re.S)
    if m:
        t = m.group(1).strip()
    i, j = t.find("{"), t.rfind("}")
    if i != -1 and j > i:
        t = t[i:j + 1]
    return t


def resolve_input() -> Path:
    args = [a for a in sys.argv[1:] if not a.startswith("--")]
    return Path(args[0]).resolve() if args else DEFAULT_INPUT


# ---------- 事实包：给大模型的唯一信息源 ----------

def build_facts(cir, res: dict) -> dict:
    return {
        "circuit": {
            "subckt": res["subckt"],
            "ports": res["ports"],
            "device_count": res["device_count"],
        },
        "variable_stats": {
            "raw": res["raw_variable_count"],
            "reduced": res["reduced_variable_count"],
            "removed": res["raw_variable_count"] - res["reduced_variable_count"],
            "reduction_pct": round(
                100 * (1 - res["reduced_variable_count"] / res["raw_variable_count"]), 1),
            "by_category": res["reduced_by_category"],
        },
        "modules": [{"id": m["id"], "type": m["type"], "name_zh": m["name_zh"],
                     "devices": m["devices"], "evidence": m["evidence"]}
                    for m in res["modules"]],
        "pairing": res["pairing"],
        "symmetry": {
            "verified": res["symmetry_verified"],
            "pairs": res["pairing"],
            "missing_images": res["symmetry_missing_images"],
            "rejected": res["symmetry_rejected"],
            "note": "对称对由差分端口对换下的图自同构 σ 判定，并通过全局校验"
                    "（每个器件都有镜像对象）；校验不通过的配对会被回退，不出现在 pairs 里",
        },
        "matching_pairs": res["match_pairs"],
        "mirror_groups": [{"id": m["id"], "type": m["type"], "reference": m["reference"],
                           "gate": m["gate"], "source": m["source"],
                           "devices": m["devices"], "confidence": m.get("confidence")}
                          for m in res["mirror_groups"]],
        "dummies": res["dummies"],
        "diode_connected": res["diode_connected"],
        "segment_groups": {k: v for k, v in res["segment_groups"].items()},
        "output_pair": res["output_pair"],
        "cm_sense_node": res["cm_sense_node"],
        "seeds": res["seeds"],
        "reduction_rules": REDUCTION_RULES,
        "fixed_variables": res["fixed_variables"],
        "reduced_variables": [
            {"var": r["var"], "param": r["param"], "kind": r["kind"],
             "devices": r["devices"], "merged_from": r["merged_from"]}
            for r in res["reduced_variables"]
        ],
    }


# ---------- 大模型：只生成"为什么" ----------

def ask_model(client, cfg, system_prompt, facts: dict, feedback: str = "") -> str:
    user = ("【事实包】\n" + json.dumps(facts, ensure_ascii=False, indent=1)
            + "\n\n请按系统提示词要求，只输出那段 JSON。")
    if feedback:
        user += f"\n\n【上一次输出不合格，请修正后重新只输出 JSON】\n{feedback}"
    resp = client.chat.completions.create(
        model=cfg["model"],
        messages=[{"role": "system", "content": system_prompt},
                  {"role": "user", "content": user}],
        temperature=cfg.get("temperature", 0.2),
        max_tokens=cfg.get("max_tokens", 4096),
        timeout=cfg.get("timeout_s", 120),
    )
    return resp.choices[0].message.content or ""


def validate_reasoning(obj: dict, facts: dict) -> list[str]:
    """校验模型输出：结构齐全 + 没有编造器件名。返回问题清单（空=通过）。"""
    problems = []
    for k in ("topology", "module_reasons", "reduction_strategy",
              "variable_notes", "risks"):
        if k not in obj:
            problems.append(f"缺少字段 {k}")

    known_ids = {m["id"] for m in facts["modules"]}
    known_vars = {v["var"] for v in facts["reduced_variables"]}
    known_devs = set()
    for m in facts["modules"]:
        known_devs.update(m["devices"])
    for p in facts["pairing"]:
        known_devs.update((p["a"], p["b"]))

    for i, mr in enumerate(obj.get("module_reasons") or []):
        if mr.get("id") not in known_ids:
            problems.append(f"module_reasons[{i}].id={mr.get('id')} 不在识别结果中")
    for i, vn in enumerate(obj.get("variable_notes") or []):
        if vn.get("var") not in known_vars:
            problems.append(f"variable_notes[{i}].var={vn.get('var')} 不是约减后变量")

    # 编造器件名检测：文中出现的、形如 XX12 的标识符必须真实存在
    text = json.dumps(obj, ensure_ascii=False)
    for tok in set(re.findall(r"\b[A-Z]{2,3}\d+[A-Za-z_]*\b", text)):
        base = tok.split("_")[0]
        if base not in {n.split("_")[0] for n in known_devs} and base not in {"R0", "R3"}:
            problems.append(f"文本中出现未知器件名 {tok}")
    rules = {r["rule"] for r in facts["reduction_rules"]}
    said = {s.get("rule") for s in (obj.get("reduction_strategy") or [])}
    missed = rules - said
    if missed:
        problems.append(f"reduction_strategy 未覆盖规则 {sorted(missed)}")
    return problems


def fallback_reasoning(res: dict) -> dict:
    """无大模型（或调用失败）时的规则兜底文案：保证交付物永远完整可交。"""
    return {
        "topology": "由确定性解析器判定的全差分运放："
                    + "、".join(m["name_zh"] for m in res["modules"] if m["type"] != "matching"),
        "module_reasons": [{"id": m["id"], "reason": m["evidence"]} for m in res["modules"]],
        "reduction_strategy": [{"rule": r["rule"], "reason": r["desc"]}
                               for r in REDUCTION_RULES],
        "variable_notes": [],
        "risks": ["本次未启用大模型解释，各条依据直接取自确定性判据，风险点需人工复核",
                  "对称对（自同构 σ）已通过全局校验；工艺匹配对（差分对/两臂对应）"
                  "只在两条臂内部成立、**不冒充图对称**，其匹配依据来自版图工程要求，"
                  "建议在仿真中对齐验证",
                  "镜像组内 W/L 合并后，各支路电流只能靠 m 调节；"
                  "若某镜像管进入非饱和区，匹配关系失效"],
        "_source": "rule_fallback",
    }


# ---------- 运行时自检 ----------

def preflight(cfg, in_path: Path) -> int:
    print(f"Python    : {sys.executable}")
    in_venv = sys.prefix != getattr(sys, "base_prefix", sys.prefix)
    print(f"虚拟环境  : {'是 (.venv 生效)' if in_venv else '否（正在用系统 Python！请先激活 .venv）'}")
    print(f"模型      : {cfg['model']}")
    print(f"接口      : {cfg['base_url']}")

    need_llm = "--no-llm" not in sys.argv and "--check" not in sys.argv
    key = os.getenv(cfg["api_key_env"], "")
    if key:
        print(f"API Key   : 已设置（长度 {len(key)}，不打印内容）")
    elif need_llm:
        print(f"[错误] 环境变量 {cfg['api_key_env']} 没设置。")
        print('请在 PowerShell 里执行：$env:DASHSCOPE_API_KEY = "sk-你的Key"')
        print("或者加 --no-llm 只跑确定性流程。")
        return 1
    else:
        print("API Key   : 未设置（本次不需要）")

    if not in_path.exists():
        print(f"[错误] 找不到网表文件：{in_path}")
        return 1
    print(f"网表文件  : {in_path}")
    return 0


# ---------- 主流程 ----------

def main():
    cfg = load_config()
    in_path = resolve_input()

    if preflight(cfg, in_path) != 0:
        sys.exit(1)
    if "--check" in sys.argv:
        print("\n[自检通过] 环境没问题，去掉 --check 就能正式跑。")
        return

    out_dir = (HERE / cfg["output_dir"]).resolve()
    out_dir.mkdir(parents=True, exist_ok=True)
    stamp = time.strftime("%Y%m%d-%H%M%S")
    trace_path = out_dir / f"trace_{stamp}.jsonl"

    def trace(rec: dict):
        rec["time"] = time.strftime("%Y-%m-%d %H:%M:%S")
        with open(trace_path, "a", encoding="utf-8") as f:
            f.write(json.dumps(rec, ensure_ascii=False) + "\n")

    print("-" * 64)

    # ---------- 第 1 段：确定性解析 ----------
    cir = parse_netlist(in_path)
    trace({"step": "1_parse", "input": str(in_path), "subckt": cir.subckt,
           "ports": cir.ports, "device_count": len(cir.devices),
           "top_device_count": len(cir.top_devices),
           "raw_variables": cir.all_variables})
    print(f"[1/4] 解析完成：{cir.subckt}，内部器件 {len(cir.devices)} 个，"
          f"原始变量 {len(cir.all_variables)} 个")

    # ---------- 第 2 段：确定性识别与约减 ----------
    res = analyze(cir)
    trace({"step": "2_analyze",
           "modules": [{"id": m["id"], "type": m["type"],
                        "devices": m["devices"], "evidence": m["evidence"]}
                       for m in res["modules"]],
           "pairing": res["pairing"], "seeds": res["seeds"],
           "symmetry_verified": res["symmetry_verified"],
           "symmetry_missing_images": res["symmetry_missing_images"],
           "symmetry_rejected": res["symmetry_rejected"],
           "match_pairs": res["match_pairs"],
           "dummies": res["dummies"], "cm_sense_node": res["cm_sense_node"],
           "sigma_conflicts": res["sigma_conflicts"],
           "raw_variable_count": res["raw_variable_count"],
           "reduced_variable_count": res["reduced_variable_count"]})
    print(f"[2/4] 识别完成：功能模块 {len(res['modules'])} 个，"
          f"对称对 {len(res['pairing'])} 对"
          f"（σ 全局校验{'通过' if res['symmetry_verified'] else '失败'}），"
          f"工艺匹配对 {len(res['match_pairs'])} 对，Dummy {len(res['dummies'])} 个")
    print(f"      参数约减：{res['raw_variable_count']} -> {res['reduced_variable_count']} "
          f"（约减 {100 * (1 - res['reduced_variable_count'] / res['raw_variable_count']):.1f}%）")

    facts = build_facts(cir, res)

    # ---------- 第 3 段：大模型生成决策依据 ----------
    reasoning = None
    if "--no-llm" not in sys.argv:
        from openai import OpenAI
        client = OpenAI(api_key=os.getenv(cfg["api_key_env"]), base_url=cfg["base_url"])
        system_prompt = read_text((HERE / cfg["prompt_file"]).resolve())
        problems: list[str] = []
        for attempt in range(1, cfg.get("max_retries", 3) + 1):
            print(f"[3/4] 第 {attempt} 次调用模型生成决策依据 ...")
            try:
                raw = ask_model(client, cfg, system_prompt, facts,
                                feedback="; ".join(problems))
            except Exception as e:
                print(f"      调用失败：{e}")
                trace({"step": "3_llm", "attempt": attempt, "error": str(e)})
                time.sleep(2)
                continue
            trace({"step": "3_llm", "attempt": attempt, "model": cfg["model"],
                   "raw_output": raw})
            try:
                obj = json.loads(strip_code_fence(raw))
            except json.JSONDecodeError as e:
                problems = [f"输出不是合法 JSON：{e}"]
                print(f"      JSON 解析失败：{e}")
                continue
            problems = validate_reasoning(obj, facts)
            if not problems:
                reasoning = obj
                print("      校验通过")
                break
            print(f"      校验不通过：{problems}")
        if reasoning is None:
            print("[3/4] 模型未能给出合格输出，改用规则兜底文案（交付物仍然完整）")
            trace({"step": "3_llm_fallback", "problems": problems})
    else:
        print("[3/4] --no-llm：跳过大模型，使用规则兜底文案")

    if reasoning is None:
        reasoning = fallback_reasoning(res)
    trace({"step": "3_reasoning", "reasoning": reasoning})

    # ---------- 第 4 段：落盘交付物 ----------
    report = {
        "circuit": facts["circuit"],
        "variable_stats": facts["variable_stats"],
        "modules": res["modules"],
        "pairing": res["pairing"],
        "symmetry": {
            "verified": res["symmetry_verified"],
            "missing_images": res["symmetry_missing_images"],
            "rejected": res["symmetry_rejected"],
            "multifold_classes": res.get("multifold_classes", []),
        },
        "matching_pairs": res["match_pairs"],
        "pairing_relation": res["pairing_relation"],
        "mirror_groups": res["mirror_groups"],
        "seeds": res["seeds"],
        "dummies": res["dummies"],
        "diode_connected": res["diode_connected"],
        "segment_groups": res["segment_groups"],
        "output_pair": res["output_pair"],
        "cm_sense_node": res["cm_sense_node"],
        "reduction_rules": REDUCTION_RULES,
        "reduced_variables": res["reduced_variables"],
        "fixed_variables": res["fixed_variables"],
        "reasoning": reasoning,
    }
    report_path = OUT_ROOT / "module_report.json"
    report_path.write_text(json.dumps(report, ensure_ascii=False, indent=2),
                           encoding="utf-8")
    (out_dir / f"module_report_{stamp}.json").write_text(
        json.dumps(report, ensure_ascii=False, indent=2), encoding="utf-8")

    # CSV：参数约减后的变量统计列表（赛题"变量统计列表"交付项）
    rel_by_pair = {tuple(sorted((pr["a"], pr["b"]))): pr["relation"]
                   for pr in res["pairing_relation"]}

    def note_for(v: dict) -> str:
        if len(v["devices"]) <= 1:
            return "独立变量"
        kinds = set()
        devs = v["devices"]
        for i, a in enumerate(devs):
            for b in devs[i + 1:]:
                r = rel_by_pair.get(tuple(sorted((a, b))))
                if r:
                    kinds.add(r)
        if kinds:
            return "共享(" + "/".join(sorted(kinds)) + ")"
        if v["param"] in ("w", "l", "segL", "segW"):
            return "电流镜组共享 w/l"
        return "同名变量共享（电阻分段）"

    csv_path = OUT_ROOT / "var_reduction.csv"
    with open(csv_path, "w", encoding="utf-8-sig", newline="") as f:
        w = csv.writer(f)
        w.writerow(["变量名", "参数", "类型", "单位", "涉及器件", "合并来源", "说明"])
        for v in res["reduced_variables"]:
            w.writerow([v["var"], v["param"], v["kind"], v["unit"],
                        "|".join(v["devices"]), "|".join(v["merged_from"]), note_for(v)])
        for v in res["fixed_variables"]:
            w.writerow([v["var"], v["param"], "fixed", "-", v["device"], "", v["reason"]])

    # 参数清单：供 PyAether 流程的 --param_file 使用
    initial = {}
    for cand in (in_path.parent / "extractcdfVal_0.txt", OUT_ROOT / "extractcdfVal_0.txt"):
        if cand.exists():
            for line in cand.read_text(encoding="utf-8", errors="replace").splitlines():
                if "=" in line:
                    k, _, val = line.partition("=")
                    initial[k.strip()] = val.strip()
            break
    param_path = OUT_ROOT / "param_list_reduced.txt"
    missing = 0
    with open(param_path, "w", encoding="utf-8") as f:
        for v in res["reduced_variables"]:
            val = initial.get(v["var"], "")
            if not val:
                missing += 1
            f.write(f"{v['var']}={val}\n")

    # 约减后网表
    net_path = OUT_ROOT / f"{in_path.stem}_reduced.netlist"
    net_path.write_text(emit_reduced_netlist(cir, res), encoding="utf-8")

    print("[4/4] 交付物已生成")
    print("-" * 64)
    print(f"识别与约减报告 : {report_path}")
    print(f"变量统计列表   : {csv_path}")
    print(f"约减后网表     : {net_path}")
    print(f"参数清单       : {param_path}"
          + (f"   （{missing} 个变量缺初值，需 extractcdfVal_0.txt 提供）" if missing else ""))
    print(f"推理链日志     : {trace_path}")
    print("-" * 64)
    print(f"原始优化变量 {res['raw_variable_count']} -> 约减后 "
          f"{res['reduced_variable_count']}")
    print(f"决策依据来源   : {reasoning.get('_source', '大模型生成并通过校验')}")
    print(f"\n拓扑概括：{reasoning.get('topology', '')}")


if __name__ == "__main__":
    main()
```

**代码在干什么**：

| 阶段 | 函数 | 要点 |
|---|---|---|
| 自检 | `preflight()` | 打印解释器路径、判断 `.venv` 是否生效、Key 是否设置、网表是否存在 —— **99% 的翻车都在这四项** |

| 第 2 段 | `analyze()` | 确定性识别与约减，结果写进 trace |

## 附 C：答辩可能会被问到的问题

| 问题 | 回答要点 |
|---|---|
| **为什么不让大模型直接读网表？** | 网表事实必须可复现：59 器件、约 150 条连接，模型会漏、会编、每次结果还不一样；而 6.3(1) 明写"每错一个约束扣 1 分"。所以把"判定"交给代码、把"论述"交给模型。 |
| **怎么保证识别的电流镜/匹配对是对的？** | 四重保障：① 判据只用端子连接（不看器件名），Hidden 电路同样成立；② 自同构 σ 有**全局校验**（每个器件都必须有镜像对象，不过就回退）；③ 工艺匹配走独立的局部支路对应，不冒充对称；④ 与人工判读的金标准逐条核对，且对称对数量、Dummy 名单都是可验证的离散量。 |
| **σ 是什么？** | 网表的镜像自同构：σ(器件A)=器件B 表示 A、B 结构严格对称、尺寸必须一致。本版用 WL 颜色细化求候选，再对 σ 做全局校验（每个器件都要有镜像对象），不通过就回退。 |
| **对称和匹配有什么区别？** | 对称是「整个网表可互换」（可验证为自同构）；匹配是「版图要求两管一致」（如 CMFB 误差放大器输入对，两栅分别接 VCM 与 outaverage，全图并不可互换）。混在一起的初版会把 VCM↔outaverage 当对称，导致 `PM5/PM6/PM2/PM3/R0/R3/C2/C3` 共 8 个器件找不到镜像对象。 |
| **为什么对称对合并 m，电流镜却不合并？** | 对称对的两侧 multiplier 不等会直接破坏对称性、恶化失调与 CMRR，所以必须一起合并；电流镜的 m 是**比值旋钮**（1:4、1:8 靠它实现），是设计自由度而不是冗余，合并它就等于砍掉设计空间。 |
| **约减率只有 53%？** | 剩下的 49 个变量里有 19 个是整数 m。m 是设计自由度，不该为了数字好看强行合并。我们在报告里主动交代了这一点。 |
| **Dummy 器件为什么还留在网表里？** | 它的尺寸被移出了优化变量，但符号必须保留，否则仿真读不到初值。所以网表符号是 55 个 = 49 优化变量 + 6 个 Dummy 固定符号，这笔账写在约减后网表的文件头里。 |
| **怎么证明约减没改坏电路？** | 闭环重解析校验：用同一个解析器重新读取约减后网表，器件数与端子连接关系与原始网表**逐条一致**。 |
| **模型输出不可靠怎么办？** | 三层防护：提示词约束 + 校验器（不许编造器件名、必须覆盖每条规则、变量名与模块 id 必须真实存在）+ 规则兜底文案。模型失败时交付物依然完整。 |
| **断网了还能交吗？** | 能。`python agent.py --no-llm` 只跑确定性流程，五样交付物照样全出，只是决策依据换成规则文案。 |
| **模块二比模块一多了什么虚拟环境知识？** | 几乎没有 —— 这正是重点：**模块二没有引入任何新依赖，所以复用同一个 `.venv`**。"一个项目一个 venv"是默认姿势，只有依赖版本冲突时才拆第二个。 |
