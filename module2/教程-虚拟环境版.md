## 3. 第 1 步：认识输入网表（**这一节不要跳过**）

### 3.1 赛题给的三个文件

路径：`extracted/赛题数据本身/netlist/`

| 文件 | 是什么 | 我们要不要用它 |
|---|---|---|
| `OPA_loopgain.netlist` | **真正的电路网表**，Spectre 格式，含 `OPA` 子电路 + 顶层 TestBench | ✅ **模块二的唯一输入** |
| `OPA_loopgain.scs` | 仿真控制文件（`include` 模型库、`dcOp`/`ac` 分析语句、`save` 节点） | ❌ 模块三/四才用 |
| `OPA_loopgain.map` | 原理图 instance ↔ 网表节点的对照表 | ⚠️ 只用来**核对器件数**，不参与解析 |

先看一眼 `.map` 能帮你建立信心：它列出了原理图上的 **41 个 instance**。
而解析 `.netlist` 会得到 **59 个器件**。**为什么不一致？**

> **因为 poly 电阻在网表里被按 segment 展开成了串联分段。**
> 原理图上的 `R0` 一个器件，在网表里是 `R0`、`R0_2_res_gen` … `R0_10_res_gen` 共 **10 段**，
> `R3` 同理。所以 41 − 2 + 20 = **59**。
>
> 这个账在答辩时会被问到（"你识别出来多少个器件？"），**先记住**：
> **原理图器件 41 个 / 网表器件 59 个 / 其中 20 个是 2 只 poly 电阻的串联分段。**

### 3.2 器件构成速查

| 器件 | 型号 `model` | 端子顺序 | 数量 | 尺寸变量 |
|---|---|---|---|---|
| NMOS | `n_mos_a` | `(D G S B)` | 16（NM0–NM15） | `NMx_l` / `NMx_fw` / `NMx_m` |
| PMOS | `p_mos_a` | `(D G S B)` | 13（PM0–PM12） | `PMx_l` / `PMx_fw` / `PMx_m` |
| poly 电阻 | `res_n_poly` / `res_p_poly` | `(p n)` | 24 段（来自 R0/R1/R2/R3/R5/R6） | `Rx_segL` / `Rx_segW` |
| MIM 电容 | `cap_mim` | `(p n)` | 6（C0/C2/C3/C4/C5/C11） | `Cx_l` |

**原始优化变量总数 = 16×3 + 13×3 + 6×2 + 6×1 = 48 + 39 + 12 + 6 = 105。**

> 注意 `w` 在网表里叫 **`fw`**（finger width）。赛题 PDF 里写的是 `M1_w`，
> 本 PDK 导出的是 `NM1_fw`，**是同一个东西**。报告里要解释这一句，否则评委会以为你漏了 W。

### 3.3 Spectre 网表的四个坑（解析器要专门处理）

| 坑 | 长什么样 | 不处理会怎样 |
|---|---|---|
| **续行** | 器件语句跨十几行，续行以 `+` 开头 | 每行只解析出半个器件，参数全丢 |
| **两种注释** | `//` 整行或行内；`*` 整行 | 把注释当成器件 |
| **派生参数** | `ad=(NM15_fw<300n)?((0*(9e-14+...)))/1:...` | 里面有变量名，但它是**因变量**，不是优化变量；误当成变量会让计数虚高 |
| **长度前缀命名** | `R3_10_res_gen`、`R0_2_res_gen` | 字符串排序会把 `R3_10` 排到 `R3_2` 前面，输出顺序错乱 |

第 3 个坑最关键，**直接决定你的变量个数对不对**：

> 只有**值是裸标识符**的参数才是变量（`w=NM15_fw` ✅），
> 值是数字或表达式的是常量／派生量（`w=10u` ❌、`ad=(NM15_fw<300n)?...` ❌）。

## 4. 第 2 步：先人工看懂电路（**你的金标准**）

在写任何代码之前，**你必须自己能说出这个电路是什么**。否则智能体算出来的东西你没法验收。

### 4.1 判读结论

这是一个 **PMOS 输入的两级全差分运放**：

```
                 VDDA
                  │
        ┌─────────┴─────────┐        ← PM1 尾电流源 (m=8)
        │        PM1        │
        └────┬─────────┬────┘
           PM9        PM10             ← 输入差分对 (m=2)
        (VINP)      (VINN)
             │      │
       net4 ─┘      └─ net44
             │      │
       NM4 ──┤      ├── NM5            ← 折叠共源共栅（栅极 IREF）
       NM6 ──┤      ├── NM7            ← 底部电流阱（栅极 net53）
         ┌───┘      └───┐
        net0          net8             ← 第一级高阻输出节点
         │              │
    PM2 ─┤         ├─ PM3              ← CMFB 注入管 (m=40, 栅极 vcmfb)
         │              │
    PM7 ─┴─ VOUTP   VOUTN ─┴─ PM11     ← 第二级共源放大
    NM8 ────┘         └──── NM9        ← 第二级有源负载 (m=4)
         │              │
    R1+C11 ──────────── R2+C0          ← 米勒补偿（R 串联 C，跨在第一级和第二级之间）

    R0 链: VOUTP ──[10 段]── outaverage ──[10 段]── VOUTN : R3 链   ← 共模取样
    C2 / C3 : outaverage 到两个输出的滤波电容
    outaverage → PM12 栅极 与 VCM → PM8 栅极 : CMFB 误差放大器差分对
    PM12/PM8 ─ NM13/NM12 ─ NM11/NM10 ─ PM6/PM5 : CMFB 放大器
    CMFB 输出 vcmfb → PM2/PM3 栅极
```

### 4.2 逐条推演（这就是报告里"模块识别依据"要写的东西）

| 结论 | 你是怎么推出来的（**看端子，不看器件名**） |
|---|---|
| **NMOS 电流镜（8 管）** | `NM2 NM3 NM6 NM7 NM8 NM9 NM12 NM13` 的**栅极全是 `net53`、源极全是 `GNDA`**；其中 `NM2` 栅极=漏极（栅漏短接），是参考管。共栅共源 = 电流镜的标准画法 |
| **PMOS 电流镜（PM0/PM1/PM4）** | 栅极全是 `net6`、源极全是 `VDDA`；`PM0` 栅漏短接作参考 |
| **PMOS 电流镜（PM5/PM6）** | 栅极全是 `net5`、源极 `VDDA`；`PM5` 栅漏短接 |
| **PMOS 电流镜（PM2/PM3）** | 栅极全是 `vcmfb`、源极 `VDDA`（共模反馈的执行管，m=40） |
| **输入差分对** | `PM9/PM10` 同型号、**源极同接 `net37`**、栅极分别接**输入端口** `VINP`/`VINN` |
| **尾电流源** | `PM1` 的漏极接 `net37`，正好是差分对的公共源 |
| **折叠共源共栅** | `NM4` 的源极 `net4` = `NM6` 的漏极（上下叠起来）；`NM5`/`NM7` 同理 |
| **输出级** | `PM7`(栅极 `net0`) 漏极接 `VOUTP`，`PM11`(栅极 `net8`) 漏极接 `VOUTN`；栅极接的正是第一级高阻节点 |
| **Dummy 器件** | `R5(net11,net11)`、`R6(net12,net12)`、`C4(net11,net11)`、`C5(net12,net12)` —— **两个端子接在同一个网上**，电气上根本不通，纯粹是版图/占位用 |
| **共模取样网络** | `R0` 从 `VOUTP` 出发经 10 段到 `outaverage`，`R3` 从 `outaverage` 经 10 段到 `VOUTN`。**两条链在 `outaverage` 汇合** —— 这就是共模电平 |
| **CMFB 误差放大器** | `PM12`(栅极 `outaverage`) 与 `PM8`(栅极 `VCM`) 共源 `net13`，构成差分对：一个接"检测到的共模"，一个接"目标共模" |
| **米勒补偿** | `R1(net0,net17)` + `C11(net17,VOUTP)` 串联，跨在第一级节点 `net0` 和第二级输出 `VOUTP` 之间；`R2`+`C0` 是它的镜像支路 |

### 4.3 对称对（匹配器件）清单 —— 手工数一遍

这是**参数约减的依据**。结构镜像的两侧，尺寸必须一致：

```
输入对   ：PM9 = PM10
第一级   ：NM4=NM5（折叠cascode） NM6=NM7（底部电流阱） PM7=PM11（输出管）
第二级   ：NM8 = NM9
CMFB     ：PM8=PM12（输入对） NM10=NM11（cascode） NM12=NM13（底部） PM2=PM3（注入管）
输出二极管：NM14 = NM15
补偿支路 ：R1 = R2      C11 = C0
取样网络 ：R0 链 与 R3 链 逐段对应（R0↔R3_10, R0_2↔R3_9, …）
取样电容 ：C2 = C3
```

**共 23 对。** 后面代码算出来的配对如果和这张表对不上，就是代码有 bug —— **这就是"金标准"的意义**。

## 5. 第 3 步：架构设计 —— 为什么不能"全交给大模型"

模块一的思路是"提示词约束 + 校验兜底"。模块二**不能照搬**，因为网表里的器件太多、连接关系太密：

| 理由 | 具体后果 |
|---|---|
| **事实不能概率化** | 59 个器件、约 150 条端子连接。让模型"读"网表，它一定会漏器件、编网名，而且**每次跑的结果还不一样** |
| **判定规则本来就是确定的** | "栅极相同、源极相同就是电流镜"是精确规则，用代码算 100% 正确、耗时 0 成本 |
| **评分要的是"不能错"** | 6.3(1) 明写"每错一个约束扣 1 分"，概率性输出在这里是纯风险 |
| **但评分也要求"决策依据"** | 赛题 6.2 要求报告记录"为何约减掉某参数、为何保留某变量"，这确实需要自然语言论述 |

所以模块二采用**三段式**：

```
输入网表
   │
   ├─ 第 1 段  netlist_parser.py    确定性解析   →  器件/端子/参数/变量   【事实】
   │
   ├─ 第 2 段  topo_analyzer.py     确定性识别   →  模块/配对/Dummy/约减  【结论】
   │                    │
   │                    └─→ 打包成"事实包" JSON
   │
   └─ 第 3 段  agent.py + 大模型     只写"为什么"  →  决策依据文案        【论证】
                        │
                        └─ 校验：不许编造器件名、必须覆盖每条规则
                             ↓ 不合格就带着问题重试；仍不合格 → 规则兜底文案
                        交付物（永远完整可交）
```

**一句话记住这个分工**：
> **代码负责"是什么"，模型负责"为什么"。模型永远拿不到改结论的权力。**

好处有两个，答辩时都要讲：
1. **可复现**：同一份网表，跑一百次结论完全一样，与模型无关；
2. **可降级**：模型挂了、Key 没了、断网了，加 `--no-llm` 依然能产出完整交付物（只是决策依据变成规则文案）。

## 6. 第 4 步：写 `netlist_parser.py`（完整代码）

在 `module2/agent/` 下新建 `netlist_parser.py`，整段复制：

```python
# -*- coding: utf-8 -*-
"""
模块二 · 第 1 层：确定性网表解析器（不调用大模型）

职责：把 Spectre 网表文本变成结构化对象 —— 子电路、端口、器件、端子、参数、变量。
这一层的输出必须 100% 可复现：网表里写了什么，就解析出什么，不允许"猜"。

解析难点（本 PDK 网表的真实情况）：
1. 器件语句跨行，续行以 `+` 开头，必须先拼成一整行再解析；
2. 注释有 `//`（整行或行内）和 `*`（整行）两种；
3. MOS 的 ad/as/pd/ps/nrd/nrs/sa/sb 是**派生参数表达式**，
   里面也含变量名（如 PM3_fw），但它们是**因变量**，不是优化变量；
4. 真正可优化的只有尺寸参数（w/l/m/segL/segW/...），
   且只有"值是裸标识符"的才叫变量（w=10u 是常量）。
"""
from __future__ import annotations

import re
from dataclasses import dataclass, field
from pathlib import Path

# ---------- 常量表 ----------

# PDK 模型名 -> 逻辑器件类型
MODEL_KIND = {
    "n_mos_a": "nmos",
    "p_mos_a": "pmos",
    "res_n_poly": "res",
    "res_p_poly": "res",
    "cap_mim": "cap",
}

# 只有这些参数是"尺寸参数"，才有资格成为优化变量
SIZE_PARAMS = ("w", "l", "m", "multi", "seg", "segL", "segW", "r", "c", "nf", "fw")

# MOS 的端口顺序（Spectre：D G S B）
MOS_NETS = ("d", "g", "s", "b")
# 两端器件的端口顺序（R / C）
TWO_NETS = ("p", "n")

# 值是裸标识符才算变量；含数字/运算符/括号的都是常量或表达式
IDENT_RE = re.compile(r"^[A-Za-z_]\w*$")
# 器件语句：NAME (net1 net2 ...) model param=value ...
DEVICE_RE = re.compile(r"^(\S+)\s*\(([^)]*)\)\s*(\S+)\s*(.*)$")
# 参数：key=value（value 取到下一个空白）
PARAM_RE = re.compile(r"([A-Za-z_]\w*)\s*=\s*(\S+)")
SUBCKT_RE = re.compile(r"^subckt\s+(\S+)\s*\(([^)]*)\)", re.I)
ENDS_RE = re.compile(r"^ends\b", re.I)


# ---------- 数据结构 ----------

@dataclass
class Device:
    """一个器件实例。"""
    name: str
    nets: tuple[str, ...]
    model: str
    params: dict[str, str] = field(default_factory=dict)
    line_no: int = 0
    raw: str = ""

    @property
    def kind(self) -> str:
        return MODEL_KIND.get(self.model.lower(), "unknown")

    @property
    def net_map(self) -> dict[str, str]:
        """端口名 -> 网名，MOS 用 d/g/s/b，两端器件用 p/n。"""
        keys = MOS_NETS if self.kind in ("nmos", "pmos") else TWO_NETS
        return dict(zip(keys, self.nets))

    @property
    def size_params(self) -> dict[str, str]:
        return {k: v for k, v in self.params.items() if k in SIZE_PARAMS}

    @property
    def variables(self) -> dict[str, str]:
        """尺寸参数里"值是裸标识符"的 -> 优化变量。返回 {参数名: 变量名}。"""
        out = {}
        for k, v in self.size_params.items():
            if IDENT_RE.match(v):
                out[k] = v
        return out

    @property
    def var_names(self) -> list[str]:
        return sorted(self.variables.values())

    def is_diode_connected(self) -> bool:
        """栅极与漏极同网 = 二极管接法（电流镜的参考管）。"""
        if self.kind not in ("nmos", "pmos"):
            return False
        m = self.net_map
        return m.get("g") == m.get("d")

    def is_two_terminal_shorted(self) -> bool:
        """两端器件两个端子接同一网 = 电气上悬空无用（Dummy 的典型特征）。"""
        return len(self.nets) == 2 and self.nets[0] == self.nets[1]

    def size_suffix_set(self) -> frozenset:
        return frozenset(self.size_params.keys())


@dataclass
class Circuit:
    subckt: str
    ports: list[str]
    devices: list[Device]
    top_devices: list[Device] = field(default_factory=list)
    source: str = ""

    def by_name(self, name: str) -> Device | None:
        for d in self.devices:
            if d.name == name:
                return d
        return None

    @property
    def all_variables(self) -> list[str]:
        """原始变量清单（去重、排序）。"""
        seen = []
        for d in self.devices:
            for v in d.var_names:
                if v not in seen:
                    seen.append(v)
        return seen

def _strip_comments(text: str) -> list[str]:
    """去掉整行注释（// 与 * 开头）与行内 // 注释。"""
    out = []
    for line in text.splitlines():
        s = line.strip()
        if not s or s.startswith("//") or s.startswith("*"):
            continue
        if "//" in s:
            s = s.split("//", 1)[0].strip()
            if not s:
                continue
        out.append(s)
    return out


def _join_continuations(lines: list[str]) -> list[tuple[int, str]]:
    """把以 `+` 开头的续行拼到上一行；返回 (起始行号, 完整语句)。"""
    joined: list[tuple[int, str]] = []
    for i, s in enumerate(lines, start=1):
        if s.startswith("+") and joined:
            no, prev = joined[-1]
            joined[-1] = (no, prev + " " + s[1:].strip())
        else:
            joined.append((i, s))
    return joined


def parse_netlist(path: str | Path) -> Circuit:
    """解析网表文件，返回 Circuit。只取第一个 subckt 作为 DUT。"""
    p = Path(path)
    raw_lines = _strip_comments(p.read_text(encoding="utf-8", errors="replace"))
    stmts = _join_continuations(raw_lines)

    subckt, ports = "", []
    devices: list[Device] = []
    top_devices: list[Device] = []
    inside = False

    for no, s in stmts:
        m = SUBCKT_RE.match(s)
        if m:
            subckt = m.group(1)
            ports = m.group(2).split()
            inside = True
            continue
        if ENDS_RE.match(s):
            inside = False
            continue
        if s.lower().startswith("parameters"):   # 裸关键字，跳过
            continue

        dm = DEVICE_RE.match(s)
        if not dm:
            continue
        name, nets, model, tail = dm.groups()
        params = dict(PARAM_RE.findall(tail))
        dev = Device(name=name, nets=tuple(nets.split()), model=model,
                     params=params, line_no=no, raw=s)
        if inside:
            devices.append(dev)
        else:
            top_devices.append(dev)

    return Circuit(subckt=subckt, ports=ports, devices=devices,
                   top_devices=top_devices, source=str(p))

# -*- coding: utf-8 -*-
"""
模块二 · 第 2 层：拓扑模块识别 + 参数约减（确定性规则，不调用大模型）

设计原则：**结构判定必须可复现，大模型只负责"讲道理"**。
本文件给出结论（哪些是电流镜、哪些是匹配管、删掉哪些变量），
agent.py 再让大模型基于这些事实生成"为什么这么做"的说明文字。

识别用的四条证据链（全部来自网表本身，不依赖器件命名）：
  E1 端口/网表事实：端子连接、器件 model、参数取值
  E2 电气判据：二极管接法、两端同网、共栅共源
  E3 镜像置换 σ 传播：从差分对/输出对/CMFB 差分对三个种子出发，
     求网表的镜像自同构 σ，满足 σ(d1)=d2 的器件对即严格对称的匹配器件
  E4 功能网络：CMFB 取样网络（电阻割点）、米勒补偿支路、偏置链

参数约减规则：
  R1 Dummy（两端同网）      -> 尺寸参数移出优化变量（固定）
  R2 同名变量（串联分段）    -> 天然共享，归入同一组
  R3 镜像对称对（σ 配对）    -> 共享 w/l（或 segL/segW、l）
  R4 电流镜组（共栅共源）    -> 参考管与镜像管共享 w/l，比值由 m 承担
  注：m（Multiplier）与 seg 是**整数比值旋钮**，不合并，逐管保留。
"""
from __future__ import annotations

import re
from dataclasses import dataclass

from netlist_parser import Circuit, Device, IDENT_RE

# 参与合并的尺寸参数（不含 m / multi —— 它们是比值旋钮）
MERGE_PARAMS = ("w", "l", "segL", "segW", "r", "c")

# 镜像对称对（σ 配对）必须**完全一致**，包括 m：
# 差分对/对称支路两侧的 multiplier 不等会直接破坏对称性、恶化失调与 CMRR。
# 注意这和"电流镜比值旋钮"是两回事：后者由 MERGE_PARAMS 控制，m 保持独立。
PAIR_MERGE_PARAMS = MERGE_PARAMS + ("m", "multi", "seg", "nf")

# 电源/地网络：不参与极性判定
RAILS = {"0", "gnd!", "gnda", "gnd", "vdda", "vdd", "vssa", "vss", "sub"}

INTEGER_PARAMS = {"m", "multi", "seg", "nf"}
UNIT_BY_PARAM = {"w": "m", "l": "m", "segL": "m", "segW": "m", "r": "Ohm",
                 "c": "F", "m": "-", "multi": "-", "seg": "-"}


# ---------- 小工具 ----------

def _natkey(s: str):
    """自然排序键：NM2 < NM13（字符串排序会把 NM13 排到 NM2 前面）。"""
    return [int(t) if t.isdigit() else t for t in re.split(r"(\d+)", s)]


def _const_params(d: Device) -> dict:
    """器件上"真正的常量参数"，用于判断两台器件是不是同一种画法。

    注意：MOS 的 ad/as/pd/ps/nrd/nrs/sa/sb 是**派生表达式**，
    里面嵌了本器件自己的变量名（如 NM6_fw），逐字比较会把所有 MOS 都判成不同款，
    所以这里把"值引用了本器件变量"的参数一律排除，只留纯常量
    （multi / sca / trise / option_vop ...）以及常量尺寸（如电容 w=30u、m=2）。
    """
    varnames = set(d.variables.values())
    out = {}
    for k, v in d.params.items():
        if IDENT_RE.match(v):          # 裸标识符 = 变量本身，跳过
            continue
        if any(re.search(r"\b" + re.escape(vn) + r"\b", v) for vn in varnames):
            continue                   # 派生表达式，跳过
        out[k] = v
    return out


def _same_style(a: Device, b: Device) -> bool:
    return (a.model == b.model
            and a.size_suffix_set() == b.size_suffix_set()
            and _const_params(a) == _const_params(b))


def _orderings(d: Device):
    """两端器件的两个端子顺序无关，允许交换。"""
    yield d.nets
    if len(d.nets) == 2:
        yield (d.nets[1], d.nets[0])


class UnionFind:
    def __init__(self):
        self.p: dict = {}

    def find(self, x):
        self.p.setdefault(x, x)
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra != rb:
            self.p[rb] = ra

def analyze(c: Circuit) -> dict:
    from netlist_parser import parse_netlist  # noqa: F401  (供外部 import 兼容)

    devs = c.devices
    mos = [d for d in devs if d.kind in ("nmos", "pmos")]
    twoterm = [d for d in devs if d.kind in ("res", "cap")]

    # ================= E2：基础电气判据 =================
    dummies = [d for d in devs if d.is_two_terminal_shorted()]
    dummy_names = {d.name for d in dummies}
    diode = [d for d in mos if d.is_diode_connected()]

    # ================= E4-1：CMFB 取样网络（电阻图割点） =================
    res_adj: dict[str, set[str]] = {}
    res_devs = [d for d in twoterm if d.kind == "res" and d.name not in dummy_names]
    for d in res_devs:
        res_adj.setdefault(d.nets[0], set()).add(d.nets[1])
        res_adj.setdefault(d.nets[1], set()).add(d.nets[0])

    def res_reach(start: str, blocked: str | None = None) -> set[str]:
        seen, stack = {start}, [start]
        while stack:
            for nb in res_adj.get(stack.pop(), ()):
                if nb == blocked or nb in seen:
                    continue
                seen.add(nb)
                stack.append(nb)
        return seen

    # 输出端口对：接了电容、且不是电源地的端口
    cap_nets = set()
    for d in twoterm:
        if d.kind == "cap" and d.name not in dummy_names:
            cap_nets.update(d.nets)
    out_ports = [p for p in c.ports if p.lower() not in RAILS and p in cap_nets]
    out_pair = tuple(out_ports[:2]) if len(out_ports) >= 2 else None

    # 共模检测点 = 电阻链上的交汇节点
    # 判据（两条同时满足）：
    #   ① 割点：去掉它之后，两个输出端口在纯电阻图上不再连通
    #   ② 有非电阻支路：该节点还接了电容或 MOS 栅极（否则只是电阻链中间的普通节点）
    # 只满足①的节点在"两条链串联"的结构里有十几个，必须靠②把它挑出来。
    res_dev_names = {d.name for d in res_devs}
    nonres_nets: dict[str, list[str]] = {}
    for d in devs:
        if d.name in res_dev_names or d.name in dummy_names:
            continue
        for n in d.nets:
            nonres_nets.setdefault(n, []).append(d.name)

    cm_sense = None
    candidates: list[str] = []
    if out_pair:
        a, b = out_pair
        candidates = [n for n in res_reach(a)
                      if n != b and n.lower() not in RAILS
                      and b not in res_reach(a, blocked=n)
                      and nonres_nets.get(n)]
        if len(candidates) == 1:
            cm_sense = candidates[0]

    # ================= 电流镜组（E2：同类型 + 同栅 + 同源） =================
    mirror_groups: list[dict] = []
    buckets: dict[tuple, list[Device]] = {}
    for d in mos:
        if d.name in dummy_names:
            continue
        m = d.net_map
        buckets.setdefault((d.kind, m["g"], m["s"]), []).append(d)
    for (kind, gate, src), members in buckets.items():
        if len(members) < 2:
            continue
        refs = [x for x in members if x.is_diode_connected()]
        mirror_groups.append({
            "type": "current_mirror",
            "name_zh": "NMOS 电流镜" if kind == "nmos" else "PMOS 电流镜",
            "kind": kind, "gate": gate, "source": src,
            "reference": refs[0].name if refs else None,
            "devices": [x.name for x in members],
            "evidence": (f"{kind} 管栅极同为 {gate}、源极同为 {src}，共 {len(members)} 管；"
                         + (f"其中 {refs[0].name} 栅漏短接，是参考管；" if refs else "无二极管接法参考管；")
                         + "其余各管复制参考电流，比值由 m 决定"),
        })

    # ================= 输入差分对（E1/E2） =================
    ports_lc = {p.lower() for p in c.ports}
    input_pair = None
    for i, a in enumerate(mos):
        for b in mos[i + 1:]:
            if a.kind != b.kind or a.name in dummy_names or b.name in dummy_names:
                continue
            ma, mb = a.net_map, b.net_map
            if ma["s"] != mb["s"] or ma["s"].lower() in RAILS:
                continue
            ga, gb = ma["g"], mb["g"]
            if ga == gb or ga.lower() not in ports_lc or gb.lower() not in ports_lc:
                continue
            input_pair = (a, b)
            break
        if input_pair:
            break

    # ================= E3：镜像置换 σ 传播 =================
    sigma: dict[str, str] = {}
    conflicts: list[str] = []

    def bind(x: str, y: str) -> bool:
        if x in sigma and sigma[x] != y:
            conflicts.append(f"{x} 已映射到 {sigma[x]}，又与 {y} 冲突")
            return False
        if y in sigma and sigma[y] != x:
            conflicts.append(f"{y} 已映射到 {sigma[y]}，又与 {x} 冲突")
            return False
        sigma[x] = y
        sigma[y] = x
        return True

    def smap(n: str) -> str:
        return sigma.get(n, n)

    def find_pair(d: Device, pool: list[Device], paired: set[str]):
        """找一个且仅一个镜像伙伴。
        判据：端子逐位对应，未登记的网作为新映射写入；
        且**至少有一对端子是已被 σ 锚定的差异**（防止把两个无关同型管配成对）。
        """
        hits = []
        for e in pool:
            if e.name == d.name or e.name in paired or e.name in dummy_names:
                continue
            if not _same_style(d, e):
                continue
            for nets_e in _orderings(e):
                # 重复端子模式必须一致：栅漏短接的自环结构只能映射到自环结构，
                # 否则 (net5,net5,VDDA,VDDA) 会与 (vcmfb,net5,VDDA,VDDA) 误配成对称对。
                if len(set(d.nets)) != len(set(nets_e)):
                    continue
                new, anchored, ok = [], 0, True
                for xn, yn in zip(d.nets, nets_e):
                    if xn == yn:
                        continue
                    if xn in sigma:
                        if sigma[xn] != yn:
                            ok = False
                            break
                        anchored += 1
                    elif yn in sigma:
                        if sigma[yn] != xn:
                            ok = False
                            break
                        anchored += 1
                    else:
                        new.append((xn, yn))
                if ok and anchored >= 1:
                    hits.append((e, new))
                    break
        return hits[0] if len(hits) == 1 else None

    pairing: list[tuple[str, str]] = []
    paired: set[str] = set()

    def seed(a: Device, b: Device, note: str):
        ma, mb = a.net_map, b.net_map
        for k in ma:
            if k in mb:
                bind(ma[k], mb[k])
        pairing.append((a.name, b.name))
        paired.update((a.name, b.name))
        return note

    seeds = []
    if input_pair:
        seed(*input_pair, "差分输入对")
        seeds.append("差分输入对 " + "/".join(x.name for x in input_pair))
    if out_pair:
        bind(out_pair[0], out_pair[1])
        seeds.append(f"输出端口对 {out_pair[0]}/{out_pair[1]}")

    # CMFB 差分对：共源、一栅为基准端口、另一栅为共模检测点
    cmfb_pair = None
    if cm_sense:
        for i, a in enumerate(mos):
            for b in mos[i + 1:]:
                if a.kind != b.kind or a.name in dummy_names or b.name in dummy_names:
                    continue
                ma, mb = a.net_map, b.net_map
                if ma["s"] != mb["s"] or ma["s"].lower() in RAILS:
                    continue
                gs = {ma["g"], mb["g"]}
                if cm_sense in gs and any(
                        g.lower() in ports_lc and g.lower() not in RAILS
                        for g in gs if g != cm_sense):
                    cmfb_pair = (a, b)
                    break
            if cmfb_pair:
                break
    if cmfb_pair:
        seed(*cmfb_pair, "CMFB 误差放大器差分对")
        seeds.append("CMFB 差分对 " + "/".join(x.name for x in cmfb_pair))

    # 迭代到不动点（MOS 与两端器件统一处理）
    for _ in range(len(devs) + 5):
        changed = False
        for pool in (mos, twoterm):
            for d in list(pool):
                if d.name in paired or d.name in dummy_names:
                    continue
                hit = find_pair(d, pool, paired)
                if not hit:
                    continue
                e, new = hit
                if all(bind(x, y) for x, y in new):
                    pairing.append((d.name, e.name))
                    paired.update((d.name, e.name))
                    changed = True
        if not changed:
            break

    # ================= 串联分段：共用同一组变量名 =================
    var_shared: dict[str, list[str]] = {}
    for d in devs:
        for v in d.var_names:
            var_shared.setdefault(v, []).append(d.name)
    segment_groups = {v: ns for v, ns in var_shared.items() if len(ns) > 1}

    # ================= 功能模块清单 =================
    modules: list[dict] = []
    if dummies:
        modules.append({
            "id": "D1", "type": "dummy", "name_zh": "Dummy 器件（两端短接）",
            "devices": [d.name for d in dummies],
            "evidence": "两端接同一节点：" + "、".join(
                f"{d.name}({d.nets[0]},{d.nets[1]})" for d in dummies)
                + "。电气上不构成通路，对任何性能指标无贡献，其尺寸参数应从优化变量中剔除",
        })
    for i, g in enumerate(mirror_groups, 1):
        g["id"] = f"CM{i}"
        modules.append(g)
    if input_pair:
        a, b = input_pair
        modules.append({
            "id": "IN1", "type": "input_pair", "name_zh": "输入差分对",
            "devices": [a.name, b.name],
            "evidence": (f"{a.name}/{b.name} 同型号 {a.model}，源极共接 {a.net_map['s']}，"
                         f"栅极分别接输入端口 {a.net_map['g']}/{b.net_map['g']}；"
                         f"构成差分输入对，两管必须严格匹配（失配直接恶化失调与 CMRR）"),
        })
        tail = [d for d in mos if d.name not in dummy_names
                and d.name not in (a.name, b.name) and a.net_map["s"] in d.nets]
        if tail:
            modules.append({
                "id": "T1", "type": "tail_current_source", "name_zh": "尾电流源",
                "devices": [x.name for x in tail],
                "evidence": f"{tail[0].name} 漏极接差分对公共源 {a.net_map['s']}，为输入对提供尾电流",
            })
    if out_pair:
        outs = [d for d in mos if d.name not in dummy_names and d.nets[0] in out_pair]
        if outs:
            modules.append({
                "id": "O1", "type": "output_stage", "name_zh": "输出级",
                "devices": [d.name for d in outs],
                "evidence": f"漏极直接驱动输出端口 {out_pair[0]}/{out_pair[1]}",
            })
    if cm_sense:
        net_devs = [d for d in devs if cm_sense in d.nets and d.name not in dummy_names]

            "id": "FB1", "type": "cmfb", "name_zh": "共模反馈网络（CMFB）",
            "devices": [d.name for d in net_devs],

                         f"{cm_sense} 汇合，{cm_sense} 是电阻图上分开两个输出的割点，"

        for n in names:

                continue

                    first = key
                else:

        pair_notes.setdefault(b, []).append(a)
    # R4：电流镜组内共享 w/l

            if not anchor:
                continue
            for m in members:
                if p in m.variables:
                    uf.union((anchor.name, p), (m.name, p))

    groups: dict[tuple, list[tuple]] = {}
    for d in devs:
        if d.name in dummy_names:
            continue
        for p, v in d.variables.items():
            groups.setdefault(uf.find((d.name, p)), []).append((d.name, p, v))

    reduced: list[dict] = []
    rename: dict[str, str] = {}
    for root, items in groups.items():
        names = sorted({v for _, _, v in items}, key=_natkey)
        canon = names[0]
        for _, _, v in items:
            rename[v] = canon
        reduced.append({
            "var": canon,
            "param": items[0][1],
            "devices": sorted({n for n, _, _ in items}, key=_natkey),
            "merged_from": names,
            "kind": "integer" if items[0][1] in INTEGER_PARAMS else "continuous",
            "unit": UNIT_BY_PARAM.get(items[0][1], "-"),
        })
    reduced.sort(key=lambda r: _natkey(r["var"]))

    fixed_vars = [{"var": v, "param": p, "device": d.name,
                   "reason": "Dummy 器件两端短接，对性能无影响"}
                  for d in dummies for p, v in d.variables.items()]

    by_cat: dict[str, int] = {}
    for r in reduced:
        k = "整数(m)" if r["kind"] == "integer" else r["param"]
        by_cat[k] = by_cat.get(k, 0) + 1

    return {
        "subckt": c.subckt, "ports": c.ports, "device_count": len(devs),
        "raw_variable_count": len(c.all_variables), "raw_variables": c.all_variables,
        "modules": modules, "mirror_groups": mirror_groups,
        "pairing": [{"a": a, "b": b} for a, b in pairing],

        "diode_connected": [d.name for d in diode],

        "output_pair": list(out_pair) if out_pair else [],
        "reduced_variable_count": len(reduced),

        "fixed_variables": fixed_vars,

        "pair_notes": pair_notes,
    }

## 9. 第 7 步：读懂 σ 传播（**全篇最难的一段，也是最值钱的一段**）

`topo_analyzer.py` 里最重要的机制是 **镜像置换 σ（sigma）**。想明白它，这一节就值回票价。

### 9.1 要解决的问题

你要找出"哪些器件必须严格匹配"。**不能靠器件名**（`PM9`/`PM10` 这种命名在 Hidden 电路里可能完全不同），只能靠**结构**。

结构对称的精确定义是：**存在一个把网表映射到自身的镜像变换 σ，使得 σ(器件A) = 器件B。**

### 9.2 怎么算出 σ

**① 找种子**（三处，都是先用简单规则定位的）：

| 种子 | 判定规则 | 本例结果 |
|---|---|---|
| 差分输入对 | 同型号、共源、两个栅极都是**子电路端口**、且不接电源地 | `PM9`/`PM10` |
| 输出端口对 | **接了电容**的端口（排除电源地） | `VOUTN`/`VOUTP` |
| CMFB 差分对 | 共源、一个栅极接基准端口（`VCM`）、另一个栅极接**共模检测点** | `PM8`/`PM12` |

种子一旦确定，就登记若干条网的对应关系，例如
`VINP↔VINN`、`net4↔net44`、`VOUTP↔VOUTN`、`net3↔net52`。

**② 传播**：反复扫描所有器件，若器件 `d` 的每个端子网都已有镜像对应，
就去找那个"端子逐位对应"的器件 `e`。找到就配对，并把新出现的对应关系（如 `net0↔net8`）登记进 σ。

**③ 三个防伪守卫**（缺一个就会配错，我们实际踩过坑）：

| 守卫 | 防的是什么 | 真实踩坑记录 |
|---|---|---|
| **至少一对端子已被 σ 锚定** | 防止把两个无关的同型管配成对 | 否则 `NM8` 会和 `NM12` 乱配 |
| **重复端子模式必须一致** | 栅漏短接的自环结构只能映射到自环结构 | `PM5(net5,net5,VDDA,VDDA)` 曾被误配到 `PM6(vcmfb,net5,VDDA,VDDA)` |
| **两端器件允许端子交换** | 电阻/电容两个端子电气等价 | 否则 `C2(outaverage,VOUTP)` 配不上 `C3(VOUTN,outaverage)` |

**④ 共模检测点怎么找**（也被坑过）：最初想用"两个输出在电阻图上的交点"，结果整张图连通、交集是全部节点。
最终用两条判据合起来：

> 共模检测点 = **电阻图割点**（去掉它两个输出才断开）**且** 该节点还接了**非电阻器件**（电容或 MOS 栅极）。
> 只看第一条的话，"两条链串联"结构里有十几个节点都满足；第二条才能把 `outaverage` 单独挑出来。

### 9.3 四条约减规则

| 规则 | 内容 | 本例删掉多少 |
|---|---|---|
| **R1** | Dummy 器件（两端同网）尺寸移出优化变量 | `R5 R6 C4 C5` 共 6 个变量 |
| **R2** | 共用同一变量名的器件（串联分段）归为同一组 | 避免 `R0`~`R0_10` 被数成 10 份 |
| **R3** | σ 对称对的 `w/l/m` **全部**合并为一份 | 23 对 |
| **R4** | 电流镜组内共享 `w/l`，**`m` 保持独立** | 4 个镜组 |

> **R3 和 R4 的区别是刻意设计的**，答辩必问：
> - **对称对**（差分对、左右支路）两侧必须**完全一致，包括 m** —— 不等的 m 会直接破坏对称性、恶化失调与 CMRR；
> - **电流镜**里 `m` 是**比值旋钮**（1:4、1:8 就是靠 m 实现的），所以共享 `w/l` 但 `m` 必须留独立。
>
> 一句话：**对称对合并 m，电流镜不合并 m。**

# -*- coding: utf-8 -*-
"""
模块二：电路网表拓扑模块识别与参数约减智能体

运行方式（必须先激活 .venv，见教程第 4 步）：
    python agent.py                       # 用默认的赛题网表
    python agent.py "D:\\path\\x.netlist"  # 指定网表
    python agent.py --check                # 只检查环境，不调模型
    python agent.py --no-llm               # 只跑确定性流程，不调模型（零成本、可离线）

三段式设计：
  第 1 段  netlist_parser  确定性解析   —— 事实来源，不允许出错
  第 2 段  topo_analyzer   确定性识别   —— 结构判定，必须可复现
  第 3 段  大模型         决策依据生成 —— 只写"为什么"，不许改结论
"""
from __future__ import annotations

import csv
import json
import os
import re
import sys
import time
from pathlib import Path

from netlist_parser import parse_netlist
from topo_analyzer import analyze, emit_reduced_netlist

HERE = Path(__file__).resolve().parent
ROOT = HERE.parent.parent            # 项目根目录
OUT_ROOT = HERE.parent               # module2/

# 赛题提供的网表（默认输入）
DEFAULT_INPUT = (ROOT / "extracted" / "赛题数据本身" / "netlist" / "OPA_loopgain.netlist")

# 本次实际使用的约减规则（会写进事实包，模型必须逐条解释）
REDUCTION_RULES = [
    {"rule": "R1", "desc": "Dummy 器件（两端接同一节点）的尺寸参数移出优化变量清单，"
                           "只保留符号供仿真读初值"},
    {"rule": "R2", "desc": "共用同一变量名的器件（如 poly 电阻的串联分段）天然共享变量，归为同一组"},
    {"rule": "R3", "desc": "镜像置换 σ 判定的对称器件对，w/l/m 全部合并为一份变量"},
    {"rule": "R4", "desc": "电流镜组（同型号、同栅、同源）内参考管与镜像管共享 w/l，"
                           "各支路电流比值由 m 承担，m 保持独立"},
]


# ---------- 基础工具 ----------

def load_config() -> dict:
    with open(HERE / "config.json", "r", encoding="utf-8") as f:
        return json.load(f)


def read_text(p: Path) -> str:
    return p.read_text(encoding="utf-8").strip()


def strip_code_fence(text: str) -> str:
    t = text.strip()
    m = re.search(r"```(?:json)?\s*(.*?)```", t, re.S)
    if m:
        t = m.group(1).strip()
    i, j = t.find("{"), t.rfind("}")
    if i != -1 and j > i:
        t = t[i:j + 1]
    return t


def resolve_input() -> Path:
    args = [a for a in sys.argv[1:] if not a.startswith("--")]
    return Path(args[0]).resolve() if args else DEFAULT_INPUT


# ---------- 事实包：给大模型的唯一信息源 ----------

def build_facts(cir, res: dict) -> dict:
    return {
        "circuit": {
            "subckt": res["subckt"],
            "ports": res["ports"],
            "device_count": res["device_count"],
        },
        "variable_stats": {
            "raw": res["raw_variable_count"],
            "reduced": res["reduced_variable_count"],
            "removed": res["raw_variable_count"] - res["reduced_variable_count"],
            "reduction_pct": round(
                100 * (1 - res["reduced_variable_count"] / res["raw_variable_count"]), 1),
            "by_category": res["reduced_by_category"],
        },
        "modules": [{"id": m["id"], "type": m["type"], "name_zh": m["name_zh"],
                     "devices": m["devices"], "evidence": m["evidence"]}
                    for m in res["modules"]],
        "pairing": res["pairing"],
        "dummies": res["dummies"],
        "diode_connected": res["diode_connected"],
        "segment_groups": {k: v for k, v in res["segment_groups"].items()},
        "output_pair": res["output_pair"],
        "cm_sense_node": res["cm_sense_node"],
        "seeds": res["seeds"],
        "reduction_rules": REDUCTION_RULES,
        "fixed_variables": res["fixed_variables"],
        "reduced_variables": [
            {"var": r["var"], "param": r["param"], "kind": r["kind"],
             "devices": r["devices"], "merged_from": r["merged_from"]}
            for r in res["reduced_variables"]
        ],
    }


# ---------- 大模型：只生成"为什么" ----------

def ask_model(client, cfg, system_prompt, facts: dict, feedback: str = "") -> str:
    user = ("【事实包】\n" + json.dumps(facts, ensure_ascii=False, indent=1)
            + "\n\n请按系统提示词要求，只输出那段 JSON。")
    if feedback:
        user += f"\n\n【上一次输出不合格，请修正后重新只输出 JSON】\n{feedback}"
    resp = client.chat.completions.create(
        model=cfg["model"],
        messages=[{"role": "system", "content": system_prompt},
                  {"role": "user", "content": user}],
        temperature=cfg.get("temperature", 0.2),
        max_tokens=cfg.get("max_tokens", 4096),
        timeout=cfg.get("timeout_s", 120),
    )
    return resp.choices[0].message.content or ""


def validate_reasoning(obj: dict, facts: dict) -> list[str]:
    """校验模型输出：结构齐全 + 没有编造器件名。返回问题清单（空=通过）。"""
    problems = []
    for k in ("topology", "module_reasons", "reduction_strategy",
              "variable_notes", "risks"):
        if k not in obj:
            problems.append(f"缺少字段 {k}")

    known_ids = {m["id"] for m in facts["modules"]}
    known_vars = {v["var"] for v in facts["reduced_variables"]}
    known_devs = set()
    for m in facts["modules"]:
        known_devs.update(m["devices"])
    for p in facts["pairing"]:
        known_devs.update((p["a"], p["b"]))

    for i, mr in enumerate(obj.get("module_reasons") or []):
        if mr.get("id") not in known_ids:
            problems.append(f"module_reasons[{i}].id={mr.get('id')} 不在识别结果中")
    for i, vn in enumerate(obj.get("variable_notes") or []):
        if vn.get("var") not in known_vars:
            problems.append(f"variable_notes[{i}].var={vn.get('var')} 不是约减后变量")

    # 编造器件名检测：文中出现的、形如 XX12 的标识符必须真实存在
    text = json.dumps(obj, ensure_ascii=False)
    for tok in set(re.findall(r"\b[A-Z]{2,3}\d+[A-Za-z_]*\b", text)):
        base = tok.split("_")[0]
        if base not in {n.split("_")[0] for n in known_devs} and base not in {"R0", "R3"}:
            problems.append(f"文本中出现未知器件名 {tok}")
    rules = {r["rule"] for r in facts["reduction_rules"]}
    said = {s.get("rule") for s in (obj.get("reduction_strategy") or [])}
    missed = rules - said
    if missed:
        problems.append(f"reduction_strategy 未覆盖规则 {sorted(missed)}")
    return problems


def fallback_reasoning(res: dict) -> dict:
    """无大模型（或调用失败）时的规则兜底文案：保证交付物永远完整可交。"""
    return {
        "topology": "由确定性解析器判定的全差分运放："
                    + "、".join(m["name_zh"] for m in res["modules"] if m["type"] != "matching"),
        "module_reasons": [{"id": m["id"], "reason": m["evidence"]} for m in res["modules"]],
        "reduction_strategy": [{"rule": r["rule"], "reason": r["desc"]}
                               for r in REDUCTION_RULES],
        "variable_notes": [],
        "risks": ["本次未启用大模型解释，各条依据直接取自确定性判据，"
                  "风险点需人工复核",
                  "镜像组内 W/L 合并后，各支路电流只能靠 m 调节；"
                  "若某镜像管进入线性区，匹配关系失效"],
        "_source": "rule_fallback",
    }


# ---------- 运行时自检 ----------

def preflight(cfg, in_path: Path) -> int:
    print(f"Python    : {sys.executable}")
    in_venv = sys.prefix != getattr(sys, "base_prefix", sys.prefix)
    print(f"虚拟环境  : {'是 (.venv 生效)' if in_venv else '否（正在用系统 Python！请先激活 .venv）'}")
    print(f"模型      : {cfg['model']}")
    print(f"接口      : {cfg['base_url']}")

    need_llm = "--no-llm" not in sys.argv and "--check" not in sys.argv
    key = os.getenv(cfg["api_key_env"], "")
    if key:
        print(f"API Key   : 已设置（长度 {len(key)}，不打印内容）")
    elif need_llm:
        print(f"[错误] 环境变量 {cfg['api_key_env']} 没设置。")
        print('请在 PowerShell 里执行：$env:DASHSCOPE_API_KEY = "sk-你的Key"')
        print("或者加 --no-llm 只跑确定性流程。")
        return 1
    else:
        print("API Key   : 未设置（本次不需要）")

    if not in_path.exists():
        print(f"[错误] 找不到网表文件：{in_path}")
        return 1
    print(f"网表文件  : {in_path}")
    return 0


# ---------- 主流程 ----------

def main():
    cfg = load_config()
    in_path = resolve_input()

    if preflight(cfg, in_path) != 0:
        sys.exit(1)
    if "--check" in sys.argv:
        print("\n[自检通过] 环境没问题，去掉 --check 就能正式跑。")
        return

    out_dir = (HERE / cfg["output_dir"]).resolve()
    out_dir.mkdir(parents=True, exist_ok=True)
    stamp = time.strftime("%Y%m%d-%H%M%S")
    trace_path = out_dir / f"trace_{stamp}.jsonl"

    def trace(rec: dict):
        rec["time"] = time.strftime("%Y-%m-%d %H:%M:%S")
        with open(trace_path, "a", encoding="utf-8") as f:
            f.write(json.dumps(rec, ensure_ascii=False) + "\n")

    print("-" * 64)

    # ---------- 第 1 段：确定性解析 ----------
    cir = parse_netlist(in_path)
    trace({"step": "1_parse", "input": str(in_path), "subckt": cir.subckt,
           "ports": cir.ports, "device_count": len(cir.devices),
           "top_device_count": len(cir.top_devices),
           "raw_variables": cir.all_variables})
    print(f"[1/4] 解析完成：{cir.subckt}，内部器件 {len(cir.devices)} 个，"
          f"原始变量 {len(cir.all_variables)} 个")

    # ---------- 第 2 段：确定性识别与约减 ----------
    res = analyze(cir)
    trace({"step": "2_analyze",
           "modules": [{"id": m["id"], "type": m["type"],
                        "devices": m["devices"], "evidence": m["evidence"]}
                       for m in res["modules"]],
           "pairing": res["pairing"], "seeds": res["seeds"],
           "dummies": res["dummies"], "cm_sense_node": res["cm_sense_node"],
           "sigma_conflicts": res["sigma_conflicts"],
           "raw_variable_count": res["raw_variable_count"],
           "reduced_variable_count": res["reduced_variable_count"]})
    print(f"[2/4] 识别完成：功能模块 {len(res['modules'])} 个，"
          f"对称配对 {len(res['pairing'])} 对，Dummy {len(res['dummies'])} 个")
    print(f"      参数约减：{res['raw_variable_count']} -> {res['reduced_variable_count']} "
          f"（约减 {100 * (1 - res['reduced_variable_count'] / res['raw_variable_count']):.1f}%）")

    facts = build_facts(cir, res)

    # ---------- 第 3 段：大模型生成决策依据 ----------
    reasoning = None
    if "--no-llm" not in sys.argv:
        from openai import OpenAI
        client = OpenAI(api_key=os.getenv(cfg["api_key_env"]), base_url=cfg["base_url"])
        system_prompt = read_text((HERE / cfg["prompt_file"]).resolve())
        problems: list[str] = []
        for attempt in range(1, cfg.get("max_retries", 3) + 1):
            print(f"[3/4] 第 {attempt} 次调用模型生成决策依据 ...")
            try:
                raw = ask_model(client, cfg, system_prompt, facts,
                                feedback="; ".join(problems))
            except Exception as e:
                print(f"      调用失败：{e}")
                trace({"step": "3_llm", "attempt": attempt, "error": str(e)})
                time.sleep(2)
                continue
            trace({"step": "3_llm", "attempt": attempt, "model": cfg["model"],
                   "raw_output": raw})
            try:
                obj = json.loads(strip_code_fence(raw))
            except json.JSONDecodeError as e:
                problems = [f"输出不是合法 JSON：{e}"]
                print(f"      JSON 解析失败：{e}")
                continue
            problems = validate_reasoning(obj, facts)
            if not problems:
                reasoning = obj
                print("      校验通过")
                break
            print(f"      校验不通过：{problems}")
        if reasoning is None:
            print("[3/4] 模型未能给出合格输出，改用规则兜底文案（交付物仍然完整）")
            trace({"step": "3_llm_fallback", "problems": problems})
    else:
        print("[3/4] --no-llm：跳过大模型，使用规则兜底文案")

    if reasoning is None:
        reasoning = fallback_reasoning(res)
    trace({"step": "3_reasoning", "reasoning": reasoning})

    # ---------- 第 4 段：落盘交付物 ----------
    report = {
        "circuit": facts["circuit"],
        "variable_stats": facts["variable_stats"],
        "modules": res["modules"],
        "pairing": res["pairing"],
        "seeds": res["seeds"],
        "dummies": res["dummies"],
        "diode_connected": res["diode_connected"],
        "segment_groups": res["segment_groups"],
        "output_pair": res["output_pair"],
        "cm_sense_node": res["cm_sense_node"],
        "reduction_rules": REDUCTION_RULES,
        "reduced_variables": res["reduced_variables"],
        "fixed_variables": res["fixed_variables"],
        "reasoning": reasoning,
    }
    report_path = OUT_ROOT / "module_report.json"
    report_path.write_text(json.dumps(report, ensure_ascii=False, indent=2),
                           encoding="utf-8")
    (out_dir / f"module_report_{stamp}.json").write_text(
        json.dumps(report, ensure_ascii=False, indent=2), encoding="utf-8")

    # CSV：参数约减后的变量统计列表（赛题"变量统计列表"交付项）
    csv_path = OUT_ROOT / "var_reduction.csv"
    with open(csv_path, "w", encoding="utf-8-sig", newline="") as f:
        w = csv.writer(f)
        w.writerow(["变量名", "参数", "类型", "单位", "涉及器件", "合并来源", "说明"])
        for v in res["reduced_variables"]:
            note = ("镜像对称对共享" if len(v["devices"]) > 1 and v["param"] in ("w", "l", "m")
                    else "电流镜组共享 w/l" if len(v["devices"]) > 1
                    else "独立变量")
            w.writerow([v["var"], v["param"], v["kind"], v["unit"],
                        "|".join(v["devices"]), "|".join(v["merged_from"]), note])
        for v in res["fixed_variables"]:
            w.writerow([v["var"], v["param"], "fixed", "-", v["device"], "", v["reason"]])

    # 参数清单：供 PyAether 流程的 --param_file 使用
    initial = {}
    for cand in (in_path.parent / "extractcdfVal_0.txt", OUT_ROOT / "extractcdfVal_0.txt"):
        if cand.exists():
            for line in cand.read_text(encoding="utf-8", errors="replace").splitlines():
                if "=" in line:
                    k, _, val = line.partition("=")
                    initial[k.strip()] = val.strip()
            break
    param_path = OUT_ROOT / "param_list_reduced.txt"
    missing = 0
    with open(param_path, "w", encoding="utf-8") as f:
        for v in res["reduced_variables"]:
            val = initial.get(v["var"], "")
            if not val:
                missing += 1
            f.write(f"{v['var']}={val}\n")

    # 约减后网表
    net_path = OUT_ROOT / f"{in_path.stem}_reduced.netlist"
    net_path.write_text(emit_reduced_netlist(cir, res), encoding="utf-8")

    print("[4/4] 交付物已生成")
    print("-" * 64)
    print(f"识别与约减报告 : {report_path}")
    print(f"变量统计列表   : {csv_path}")
    print(f"约减后网表     : {net_path}")
    print(f"参数清单       : {param_path}"
          + (f"   （{missing} 个变量缺初值，需 extractcdfVal_0.txt 提供）" if missing else ""))
    print(f"推理链日志     : {trace_path}")
    print("-" * 64)
    print(f"原始优化变量 {res['raw_variable_count']} -> 约减后 "
          f"{res['reduced_variable_count']}")
    print(f"决策依据来源   : {reasoning.get('_source', '大模型生成并通过校验')}")
    print(f"\n拓扑概括：{reasoning.get('topology', '')}")


if __name__ == "__main__":
    main()
```

**代码在干什么**：

| 阶段 | 函数 | 要点 |
|---|---|---|
| 自检 | `preflight()` | 打印解释器路径、判断 `.venv` 是否生效、Key 是否设置、网表是否存在 —— **99% 的翻车都在这四项** |
| 第 1 段 | `parse_netlist()` | 确定性解析，结果写进 trace |
| 第 2 段 | `analyze()` | 确定性识别与约减，结果写进 trace |
| 事实包 | `build_facts()` | **只把事实给模型**，不含任何"结论性判断"以外的信息 |
| 第 3 段 | `ask_model()` + `validate_reasoning()` | 生成决策依据并校验：字段齐全、模块 id 真实、变量名真实、**不许出现编造的器件名**、必须覆盖每条约减规则 |
| 兜底 | `fallback_reasoning()` | 模型不可用时用规则文案，**保证交付物永远完整** |
| 落盘 | `main()` 尾部 | 报告 / CSV / 参数清单 / 约减后网表 / trace 五样一起出 |

> **`--no-llm` 是模块二新增的关键开关**：只跑确定性流程、不花额度、断网也能跑。
> 调代码的阶段全程用它，最后再跑一次带模型的版本。

## 附 C：答辩可能会被问到的问题

| 问题 | 回答要点 |
|---|---|
| **为什么不让大模型直接读网表？** | 网表事实必须可复现：59 器件、约 150 条连接，模型会漏、会编、每次结果还不一样；而 6.3(1) 明写"每错一个约束扣 1 分"。所以把"判定"交给代码、把"论述"交给模型。 |
| **怎么保证识别的电流镜/匹配对是对的？** | 三重保障：① 判据只用端子连接（不看器件名），保证对 Hidden 电路同样成立；② σ 传播有三个防伪守卫；③ 与人工判读的金标准逐条核对，且对称对数量、Dummy 名单都是可验证的离散量。 |
| **σ 是什么？** | 网表的镜像自同构。σ(器件A)=器件B 就意味着 A、B 在结构上严格对称，尺寸必须一致。种子取自差分对、输出端口对与 CMFB 差分对，然后迭代传播到不动点。 |
| **为什么对称对合并 m，电流镜却不合并？** | 对称对的两侧 multiplier 不等会直接破坏对称性、恶化失调与 CMRR，所以必须一起合并；电流镜的 m 是**比值旋钮**（1:4、1:8 靠它实现），是设计自由度而不是冗余，合并它就等于砍掉设计空间。 |
| **约减率只有 53%？** | 剩下的 49 个变量里有 19 个是整数 m。m 是设计自由度，不该为了数字好看强行合并。我们在报告里主动交代了这一点。 |
| **Dummy 器件为什么还留在网表里？** | 它的尺寸被移出了优化变量，但符号必须保留，否则仿真读不到初值。所以网表符号是 55 个 = 49 优化变量 + 6 个 Dummy 固定符号，这笔账写在约减后网表的文件头里。 |
| **怎么证明约减没改坏电路？** | 闭环重解析校验：用同一个解析器重新读取约减后网表，器件数与端子连接关系与原始网表**逐条一致**。 |
| **模型输出不可靠怎么办？** | 三层防护：提示词约束 + 校验器（不许编造器件名、必须覆盖每条规则、变量名与模块 id 必须真实存在）+ 规则兜底文案。模型失败时交付物依然完整。 |
| **断网了还能交吗？** | 能。`python agent.py --no-llm` 只跑确定性流程，五样交付物照样全出，只是决策依据换成规则文案。 |
| **模块二比模块一多了什么虚拟环境知识？** | 几乎没有 —— 这正是重点：**模块二没有引入任何新依赖，所以复用同一个 `.venv`**。"一个项目一个 venv"是默认姿势，只有依赖版本冲突时才拆第二个。 |
