## 五、复现命令（一条条都能跑）

```powershell
cd module2\agent

python topo_analyzer.py                      # 只看识别与约减结论（零成本、离线）
python agent.py --no-llm                     # 重新生成全部交付物（不调模型）
python agent.py                              # 带大模型生成决策依据（需 .venv + API Key）
python build_tutorial.py                     # 从真实源码重新生成教程
python expand_params.py --check              # 校验回写模板：105 = 47 自由 + 6 固定

# 闭环校验：约减后网表必须与原始网表电气等价
python -c "import sys; sys.path.insert(0,'.'); from netlist_parser import parse_netlist; a=parse_netlist('../../extracted/赛题数据本身/netlist/OPA_loopgain.netlist'); b=parse_netlist('../OPA_loopgain_reduced.netlist'); print('器件数:',len(a.devices),'->',len(b.devices)); print('连接一致:', [(d.name,d.nets) for d in a.devices]==[(d.name,d.nets) for d in b.devices]); print('符号数:',len(a.all_variables),'->',len(b.all_variables))"
```
