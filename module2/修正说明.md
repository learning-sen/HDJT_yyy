# 模块二修正说明（2026-10-14）

本目录是基于队友 `learning-sen` 的 module2（归档见 `../archive/learning-sen_module2_2026-10-12/`）
**修正后的可运行版本**。修正的出发点是一条可验证的推论：

> **对称（symmetry）与匹配（matching）是两种不同关系，不能共用一个置换。**

## 1. 初版的问题（有证据）

初版用一个镜像置换 σ 同时承担两种语义，并把 **CMFB 差分对（`PM8`/`PM12`）** 当作 σ 的种子之一。
该差分对的栅极是 `VCM`（基准输入）与 `outaverage`（取样节点）—— 这是**版图匹配要求**，
**不是**图对称（二者不可互换）。由此产生连锁错误：

1. 种子强制 σ(`VCM`) = `outaverage`；
2. 再经 `NM11↔NM10` 这一对强制 σ(`net5`) = `vcmfb`；
3. 而 `net5` 上挂着二极管接法的 `PM5`，`vcmfb` 上**没有**对应器件。

用初版自己产出的 `module_report.json` 重建 σ 后校验，**有 8 个器件找不到镜像对象**：

| 器件 | 端子 | σ 下应有的镜像端子 |
|---|---|---|
| PM6 | (vcmfb, net5, VDDA, VDDA) | (net5, vcmfb, VDDA, VDDA) ✗ |
| PM5 | (net5, net5, VDDA, VDDA) | (vcmfb, vcmfb, VDDA, VDDA) ✗ |
| PM3 | (net8, vcmfb, VDDA, VDDA) | (net0, net5, VDDA, VDDA) ✗ |
| PM2 | (net0, vcmfb, VDDA, VDDA) | (net8, net5, VDDA, VDDA) ✗ |
| R3 | (outaverage, R3_ic_2) | (VCM, R0_ic_10) ✗ |
| R0_10_res_gen | (R0_ic_10, outaverage) | (R3_ic_2, VCM) ✗ |
| C3 | (VOUTN, outaverage) | (VOUTP, VCM) ✗ |
| C2 | (outaverage, VOUTP) | (VCM, VOUTN) ✗ |

而初版的冲突检测器报告 **“σ 冲突：无”** —— 因为 `find_pair()` 对“两端本来就相同的端子”
直接 `continue`，绕过了冲突检查，于是 `PM3=PM2`（要求 `vcmfb` 不动）与 `NM11=NM10`
（要求 `vcmfb↔net5`）这两个**互斥要求**同时留在 `pairing` 里。

## 2. 四项修正

| 编号 | 修正 | 落地位置 |
|---|---|---|
| F1 | **关系分离**：对称走“自同构”，匹配走“局部支路对应” | `find_symmetry_pairs()` / `arm_match()` |
| F2 | **σ 全局校验**：每个器件都必须有镜像对象，冲突配对拉黑重解 | `_verify_sigma()` + `_solve_symmetry()` 不动点迭代 |
| F3 | **电流镜判据补强** | 桶键加 `model`；无参考管改判 `common_gate_pair`；短接/悬空 MOS 不参与；补 `references`/`confidence` |
| F4 | **配对可追溯** | 每对带 `relation`（`symmetry` / `differential/*` / `arm_match`）与 `why` |

修正后的核心机制：

- **对称（E3）**：WL 颜色细化求候选（差分端口先折叠成同角色）→ 只取颜色类恰为 2 的对 →
  **全局校验**（每个器件都要有镜像对象）→ 不通过就把卷入冲突的配对拉黑重解（最多 6 轮）。
- **匹配（E4）**：差分对（共尾节点 + 双栅双漏 + 同尺寸档恰好两只）作为种子 →
  沿**两臂对应网**找同位置、同端子角色、同款的器件 → 配对不唯一或走出臂范围即停。
  由此得到的 `net5↔vcmfb` **只在 CMFB 放大器内部成立**，不会外溢。

## 4. 与初版产物的差异

| 项 | 初版 | 本版 |
|---|---|---|
| 关系模型 | 一个 σ 兼两种语义 | 对称（σ）+ 匹配（两臂对应）分开 |
| σ 校验 | 无（冲突检测被绕过） | 全局校验 + 失败回退 + 硬断言 |
| `PM5/PM6/PM2/PM3/R0/R3/C2/C3` 的镜像 | **缺失**（不是自同构） | 保持自身不变（合法） |
| `NM13/NM12`、`NM11/NM10` | 由假的 σ 得出 | 由 §9.3 的“两臂对应”得出，依据可查 |
| `PM2/PM3` 类型 | `current_mirror`（无参考管却称“复制参考电流”） | `common_gate_pair`（表述与事实一致） |
| 电流镜桶键 | `(kind, gate, source)` | `(kind, model, gate, source)` |
| 短接/悬空 MOS | 会被选作“参考管” | 不参与分组 |
| 变量数 | 105 → 49 | 105 → **49**（口径不变，依据更硬） |
| 配对可追溯 | 无 | 每对带 `relation` + `why` |
| 自检断言 | 无 | 3 条（σ 校验 / 器件存在 / 变量名唯一） |

> 命名差异：本版对**有参考管**的镜像组用参考管的变量名当规范名（更可追溯，如 `NM2_fw`、`PM0_l`）；
> **无参考管**的共栅对（`PM2/PM3`）仍取自然序最小的器件名，因此 `PM2_fw/PM2_l` 与初版一致。
> `var_reduction.csv` 的“说明”列也从笼统的“镜像对称对共享”细化为 `共享(symmetry)` /
> `共享(arm_match)` / `共享(differential/auxiliary)` / `电流镜组共享 w/l`。

## 7. 第二轮修正（2026-10-14 晚）

### 7.1 共源共栅偏置家族（`CB1`）与规则 R6

**问题**：栅极接 `IREF` 的 6 只管子（`NM0 NM1 NM4 NM5 NM10 NM11`）里，
`NM4/NM5`（σ 对称）与 `NM10/NM11`（两臂对应）已被覆盖，但 **`NM0`、`NM1` 不属于任何模块**
（识别覆盖 **57/59**）。原因正是 E2 的判据是“同栅 + **同源**”，而共源共栅家族的源极**各不相同**
（各自接在所属支路的下管漏极上：`net32/net4/net44/net3/net52`），会被拆成单元素桶。

**修正**：新增证据链 **E5-2 `find_cascode_banks()`**：

1. 找“偏置网”——网上至少挂着一只二极管接法（栅漏短接）的管子；
2. 同型、栅极都接这条网；
3. **各管源极两两不同、都不是电源地**，且每只都存在“同型下管接在自己源极上”（真叠管）。

两条语义约束（都被真实网表验证过）：

- `NM14/NM15` 是**漏源同网**的器件，被“漏源不能短接”挡掉（否则会出现 `NM15←NM15` 自指）；
- 判据是**逐管筛选**，不是“一只不合格就否掉整桶”。

新增模块 `CB1（共源共栅偏置家族）`，依据可逐条核对：

```text
nmos(n_mos_a) 管栅极共接偏置网 IREF（由二极管接法的 NM0 产生，栅漏短接）；
各管源极分别接不同支路的下管漏极，构成共源共栅叠管：
NM0←NM2、NM1←NM3、NM4←NM6、NM5←NM7、NM10←NM12、NM11←NM13；
源极互不相同（net53, net32, net4, net44, net3, net52）故不是同一支路的镜像。
作用：NM0 给共源共栅管提供栅偏压，所属支路的下管给镜像管提供栅偏压。
```

**新增规则 R6**：共源共栅偏置家族共享 `L`（`NM1/NM4/NM5/NM10/NM11`），
**基准二极管 `NM0` 的 `L` 保持自由**（它决定偏置电压，是设计自由度）。
依据：同一偏置网、同一电流密度下共源共栅取相同 `L` 是常规画法（各支路 Vds 一致、系统失调更小）；
`W` 与 `m` 仍自由，所以各支路电流照旧可调。
开关：`topo_analyzer.BIND_CASCODE_L`（默认 `True`；关掉则变量数多 2 个）。

**效果**：识别覆盖 **57/59 → 59/59**；变量 **49 → 47**（`l` 14 → 12）。

### 7.2 回写面闭合：`params_writeback_template.txt` + `expand_params.py`

**问题**：约减把 99 个原始符号压成 47 个自由变量（`NM2_fw` 代表 8 个符号），
但赛题的 `--param_file` 是**整体替换** `extractcdfVal_0.txt`、作用于**原理图上的 CDF 参数**——
原理图里仍是全部 **105 个符号**。只写 47 行时，被合并掉的成员（如 `NM3_fw`）**不会被写回**，
仍停在初值 ⇒ 精心绑定的镜像管在仿真里尺寸并不相等，**且不报错**（静默失效）。

**修正**（两件交付物）：

| 文件 | 内容 |
|---|---|
| `params_writeback_template.txt` | **105 行**，每行 `<原始符号>=<驱动来源>`；`@自由变量` 表示取该自由变量的最优值，`#fixed` 表示 Dummy（保留原理图初值） |
| `agent/expand_params.py` | 读优化结果（`变量=值` 或 CSV）+ 模板 → 展开成 105 行回写文件；支持 `--init extractcdfVal_0.txt` 给固定符号填值；`--check` 只校验覆盖关系 |

**三条断言**（把“静默失效”变成“跑不起来”）：

1. 模板必须覆盖原理图**每一个**符号、无重复、无多余 —— 反向测试：删掉 `NM3_fw` 后报
   `AssertionError: 模板缺符号（回写会静默失效）：['NM3_fw']`；
2. **同一自由变量的所有成员必须拿到同一个值**（绑定关系的核心保证）；
3. 展开结果重新解析后，符号集合必须与原始网表完全一致。

用法：

```powershell
cd module2\agent
python expand_params.py --check                                  # 校验模板（105 = 47 自由 + 6 固定）
python expand_params.py --values best_values.csv --out params_writeback.txt
```

因此报告里那句账目可以写得很硬：**47 是优化搜索空间、105 是回写面、53 是约减后网表的符号数**
（47 优化变量 + 6 Dummy 固定符号）。
