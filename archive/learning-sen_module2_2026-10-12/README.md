## 3. 他这套模块二做了什么

**架构**：确定性解析器先出"事实包"（拓扑识别 + 参数约减），大模型**只负责生成解释文字**，
不参与判定 —— 这份产物是规则版（`module_report.json → reasoning._source = rule_fallback`，
本次**未启用大模型**，所以结果完全可复现）。

**识别结果（10 个模块）**：

| ID | 类型 | 器件 |
|---|---|---|
| D1 | dummy（两端同网） | R6, R5, C5, C4 |
| CM1 | 电流镜 nmos（参考管 NM2） | NM13, NM12, NM9, NM8, NM7, NM6, NM3, NM2 |
| CM2 | 电流镜 pmos（参考管 PM5） | PM6, PM5 |
| CM3 | 电流镜 pmos（参考管 PM0） | PM4, PM1, PM0 |
| CM4 | 电流镜 pmos（无二极管参考管） | PM3, PM2 |

**四条约减规则**：

| 规则 | 内容 |
|---|---|
| R1 | Dummy（两端接同一节点）尺寸移出优化变量，只留符号供仿真读初值 |
| R2 | 共用同一变量名的器件（poly 电阻串联分段）天然共享变量 |
| R3 | 镜像置换 σ 判定的对称器件对，**w/l/m 全部合并**为一份变量 |
| R4 | 电流镜组内参考管与镜像管共享 **w/l**，各支路电流比值由 **m** 承担，m 保持独立 |

**关键数字**：

| 项 | 值 |
|---|---|
| 器件总数 | 59（MOS 29） |
| 约减前变量 | **105** |
| 约减后变量 | **49**（l=14, w=12, m=19, segL=2, segW=2） |
| 移除 | 56（其中 Dummy 固定 6 个） |
| 约减比例 | **53.3%** |

> 注意：他的"105"与工作区本地口径**完全一致**（网表里以变量名给出的尺寸参数才是真变量，
> `w=10u`/`m=1` 这类字面常数不计入），两边独立算出了同一个数，可互相印证。

## 4. 与工作区本地模块二的关系

两边是**两套独立实现**，目前都在，尚未合并：

| 维度 | 他的 `module2/`（本归档） | 本地 `module1/agent/lib/` |
|---|---|---|
| 形态 | 独立 `module2/` 目录，自带解析器与分析器 | 挂在模块一智能体框架下，`topology_agent.py` + `lib/` 4 个模块 |
| 对称性判定 | 由 3 个种子（差分对/输出对/CMFB 差分对）建立**镜像置换 σ**，逐对传导 | **WL 颜色细化 + 全局自同构校验** |
| 分段电阻 | 不折叠，按段逐一对配（R3_10_res_gen = R0 …） | 先把 10 段折叠成 1 个逻辑器件再分析 |
| 镜像组绑定 | **w/l 合并**，只留 m 独立 → 49 变量 | 只绑 **l**，w/m 自由 → 预计 63 变量 |
| 变量数 | **105 → 49（53.3%）** | 105 → 约 63（约 40%，未最终验证） |
| 大模型角色 | 只写解释（判定全在确定性代码里） | ReAct 决策循环调工具 |
| 需要依赖 | `openai` + `.venv` | 纯标准库 |

**两边都存在、需要团队拍板的取舍**：镜像组内要不要连 w 一起绑定。

- 他（R4）绑 w/l、只留 m 调比值 —— 变量更少，符合"同指宽 + m 比例"的常见画法；
- 本地只绑 l —— 自由度更大，但变量更多。
- 他自己在报告里也写了风险：*"镜像组内 W/L 合并后，各支路电流只能靠 m 调节；
  若某镜像管进入线性区，匹配关系失效"*。这个取舍会直接影响模块三优化能否满足 I_OPA 约束。
