# 模块一 从零到交付 · 手把手教程

> 目标：让一个没写过智能体的人，跟着做完能交出一个**完整的模块一**。
> 适用：Windows + Python 3.12 + 你已经拿到的 Qwen3.8-Max API Key。
> 阅读方式：**从上往下，做一步、验一步，别跳。**

---

## 0. 先搞清楚：模块一要交什么

| 编号 | 交付物 | 文件 | 对应分数 |
|---|---|---|---|
| ① | Spec 解析结果 | `spec_case1.json` | 10 分 |
| ② | 智能体源码 | `agent/agent.py` | （含在"源代码"提交项） |
| ③ | 配置文件 | `agent/config.json` | （报告里要写） |
| ④ | 系统提示词 | `system_prompt.txt` | （报告里要贴） |
| ⑤ | 推理链日志 | `agent/output/trace_*.jsonl` | （报告里要写决策依据） |

**判分口径**（来自赛题 PDF）：
> 自然语言 Spec 正确解析为 Json 结构化指标（10 分）。Json 文件需要包括**硬约束项、优化目标、指标单位及目标优先级**等信息，**每缺少一个扣 1 分**。

记住这句话：**单位、优先级漏了就是丢分。** 后面的自检清单就是按这句设计的。

## 1. 第 1 步：确认 Python 环境

打开 PowerShell，粘贴：

```powershell
python --version
python -m pip list | Select-String "openai|requests|pydantic"
```

**应该看到**：Python 3.12.x，以及 `openai 1.60.1` 等。

如果 `openai` 没有，装一下：

```powershell
python -m pip install -U openai
```

> 为什么用 `openai` 这个库？因为阿里云百炼提供的是 **OpenAI 兼容接口**，换掉 base_url 和 model 就能直接调通义千问，不用学新 SDK。

## 2. 第 2 步：配置 API Key（关键，最容易错）

**原则：Key 绝不写进代码文件，只放环境变量。**

### 2.1 临时设置（只对当前这个窗口有效，推荐先用这个试）

```powershell
$env:DASHSCOPE_API_KEY = "sk-你的Key"
```

**验证一下设进去没有**（注意：只打印长度，不要打印全文）：

```powershell
$env:DASHSCOPE_API_KEY.Length
```

能打印出数字（一般 30 多）就对了。

### 2.2 永久设置（确认能跑通后再做）

```powershell
setx DASHSCOPE_API_KEY "sk-你的Key"
```

> `setx` 设置后**必须关掉 PowerShell 重新开**才生效。

### 2.3 两个必须知道的坑

| 坑 | 现象 | 原因 |
|---|---|---|
| Key 与地域不匹配 | `401 Incorrect API key provided` | 北京空间的 Key 打了别的地域的地址。**你的地址是 `cn-beijing`，所以 Key 必须是在华北2（北京）业务空间里创建的。** |
| Key 没生效 | 报"未找到 API Key" | 用了 `setx` 但没重开终端，或在新窗口里没设临时变量 |

## 4. 第 4 步：检查 / 补全提示词

打开 [system_prompt.txt](system_prompt.txt)，确认它已经存在（你已经有了）。

但**建议在文件末尾追加下面这三段**，能直接堵住三个丢分点（模型漏输出单位、漏优先级、漏赛题底线指标）：

```text
【默认底线补全规则】
当用户没有明确给出下列指标时，按赛题评分底线补成硬约束：
- Phase_Margin >= 50 deg
- Gain_Margin  <= -10 dB
- I_OPA        <= 3 mA
- DC_Gain      >= 40 dB

【口语映射规则】
- "稳定 / 不能振荡"      -> Phase_Margin、Gain_Margin 硬约束
- "低功耗 / 省电"        -> Power 最小化，且 I_OPA 硬约束
- "高增益 / 增益要大"    -> DC_Gain 最大化
- "大带宽 / 速度快"      -> UGB 最大化
- "面积小 / 省面积"      -> Area 最小化

【字段完整性（评分硬要求，缺一项扣 1 分）】
- constraints 每一项必须含：name, op, value, unit, type, priority
- objectives  每一项必须含：name, direction, unit, priority
- priority：1 表示最重要，数字越大越次要
```

> ⚠️ **注意**：你原来的提示词里，`constraints` 格式说明没写 `priority`、`objectives` 格式说明没写 `unit`，但你的样例 [spec_case1.json](spec_case1.json) 里两个字段都有——**规范和数据打架**，模型会随机漏。加上上面第三段就统一了。

## 5. 第 5 步：写 `agent.py`

在 `module1/agent/` 下新建 `agent.py`，**整段复制**下面的代码：

```python
# -*- coding: utf-8 -*-
"""
模块一：自然语言 Spec 解析智能体
用法：
    python agent.py                              # 用默认的需求文件
    python agent.py "C:\\path\\需求.txt"          # 指定需求文件
"""
import json
import os
import re
import sys
import time
from pathlib import Path

from openai import OpenAI

HERE = Path(__file__).resolve().parent

# 赛题提供的需求文件（默认输入）
DEFAULT_INPUT = HERE.parent.parent / "extracted" / "赛题数据本身" / "全差分运放设计需求.txt"

# 指标 -> 默认单位（模型漏了单位时按这个补，补了会记进日志）
UNIT_DEFAULT = {
    "DC_Gain": "dB", "UGB": "MHz", "Phase_Margin": "deg", "Gain_Margin": "dB",
    "I_OPA": "mA", "Area": "um^2", "Slew_Rate": "V/us", "Power": "mW",
    "Output_Swing": "V", "Input_CM_Range": "V", "CMRR": "dB", "PSRR": "dB",
    "Noise": "nV/sqrt(Hz)", "Offset": "mV",
}


def load_config() -> dict:
    with open(HERE / "config.json", "r", encoding="utf-8") as f:
        return json.load(f)


def read_text(p: Path) -> str:
    return p.read_text(encoding="utf-8").strip()


def strip_code_fence(text: str) -> str:
    """模型有时会把 JSON 包在 ```json ... ``` 里，剥掉它。"""
    t = text.strip()
    m = re.search(r"```(?:json)?\s*(.*?)```", t, re.S)
    if m:
        t = m.group(1).strip()
    i, j = t.find("{"), t.rfind("}")
    if i != -1 and j > i:
        t = t[i:j + 1]
    return t


def check_spec(spec: dict) -> list:
    """检查评分要求的字段是否齐全，返回缺失项列表（空=通过）。"""
    missing = []
    for k in ("design_type", "constraints", "objectives", "pvt_condition", "worst_case"):
        if k not in spec:
            missing.append(k)
    for i, c in enumerate(spec.get("constraints") or []):
        for k in ("name", "op", "value", "unit", "type", "priority"):
            if k not in c:
                missing.append(f"constraints[{i}].{k}")
    for i, o in enumerate(spec.get("objectives") or []):
        for k in ("name", "direction", "unit", "priority"):
            if k not in o:
                missing.append(f"objectives[{i}].{k}")
    return missing


def autofill(spec: dict) -> list:
    """把模型漏掉的字段补上，返回补了哪些（会写进日志，报告里要交代）。"""
    filled = []
    for i, c in enumerate(spec.get("constraints") or []):
        if "unit" not in c:
            c["unit"] = UNIT_DEFAULT.get(c.get("name"), "")
            filled.append(f"constraints[{i}].unit -> {c['unit']}")
        if "type" not in c:
            c["type"] = "hard"
            filled.append(f"constraints[{i}].type -> hard")
        if "priority" not in c:
            c["priority"] = i + 1
            filled.append(f"constraints[{i}].priority -> {i + 1}")
    for i, o in enumerate(spec.get("objectives") or []):
        if "unit" not in o:
            o["unit"] = UNIT_DEFAULT.get(o.get("name"), "")
            filled.append(f"objectives[{i}].unit -> {o['unit']}")
        if "priority" not in o:
            o["priority"] = i + 1
            filled.append(f"objectives[{i}].priority -> {i + 1}")
    return filled


def ask_model(client, cfg, system_prompt, requirement, feedback=""):
    user = f"【设计需求】\n{requirement}"
    if feedback:
        user += f"\n\n【上一次输出不合法，请修正后重新只输出 JSON】\n{feedback}"
    resp = client.chat.completions.create(
        model=cfg["model"],
        messages=[
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": user},
        ],
        temperature=cfg.get("temperature", 0.2),
        max_tokens=cfg.get("max_tokens", 4096),
        timeout=cfg.get("timeout_s", 120),
    )
    return resp.choices[0].message.content or ""


def main():
    cfg = load_config()

    # 1) 取 Key
    key = os.getenv(cfg["api_key_env"], "")
    if not key:
        print(f"[错误] 环境变量 {cfg['api_key_env']} 没设置。")
        print('请在 PowerShell 里执行：$env:DASHSCOPE_API_KEY = "sk-你的Key"')
        sys.exit(1)

    client = OpenAI(api_key=key, base_url=cfg["base_url"])
    system_prompt = read_text((HERE / cfg["prompt_file"]).resolve())

    # 2) 取输入
    in_path = Path(sys.argv[1]).resolve() if len(sys.argv) > 1 else DEFAULT_INPUT
    if not in_path.exists():
        print(f"[错误] 找不到需求文件：{in_path}")
        sys.exit(1)
    requirement = read_text(in_path)

    print(f"模型    : {cfg['model']}")
    print(f"接口    : {cfg['base_url']}")
    print(f"需求文件: {in_path}")
    print("-" * 60)

    # 3) 调用 + 校验 + 重试
    out_dir = (HERE / cfg["output_dir"]).resolve()
    out_dir.mkdir(parents=True, exist_ok=True)
    stamp = time.strftime("%Y%m%d-%H%M%S")
    trace_path = out_dir / f"trace_{stamp}.jsonl"

    spec, filled, missing, raw = None, [], [], ""
    for attempt in range(1, cfg.get("max_retries", 3) + 1):
        print(f"[第 {attempt} 次调用] ...")
        try:
            raw = ask_model(client, cfg, system_prompt, requirement,
                            feedback="; ".join(missing))
        except Exception as e:
            print(f"  调用失败：{e}")
            with open(trace_path, "a", encoding="utf-8") as f:
                f.write(json.dumps({"attempt": attempt, "error": str(e)},
                                   ensure_ascii=False) + "\n")
            time.sleep(2)
            continue

        with open(trace_path, "a", encoding="utf-8") as f:
            f.write(json.dumps({
                "attempt": attempt, "time": time.strftime("%Y-%m-%d %H:%M:%S"),
                "model": cfg["model"], "input": requirement, "raw_output": raw,
            }, ensure_ascii=False) + "\n")

        try:
            spec = json.loads(strip_code_fence(raw))
        except json.JSONDecodeError as e:
            missing = [f"输出不是合法 JSON：{e}"]
            print(f"  JSON 解析失败：{e}")
            continue

        missing = check_spec(spec)
        if not missing:
            break
        print(f"  缺字段：{missing}")

    if spec is None or missing:
        print("\n[失败] 重试用完仍未拿到完整 JSON，请把上面的错误信息发我。")
        sys.exit(1)

    filled = autofill(spec)

    # 4) 落盘
    spec_file = out_dir / f"spec_{stamp}.json"
    spec_file.write_text(json.dumps(spec, ensure_ascii=False, indent=2), encoding="utf-8")
    # 同时写一份固定名，方便直接当交付物
    (out_dir / "spec_case1.json").write_text(
        json.dumps(spec, ensure_ascii=False, indent=2), encoding="utf-8")
    (HERE.parent / "spec_case1.json").write_text(
        json.dumps(spec, ensure_ascii=False, indent=2), encoding="utf-8")

    if filled:
        with open(trace_path, "a", encoding="utf-8") as f:
            f.write(json.dumps({"autofill": filled}, ensure_ascii=False) + "\n")

    print("-" * 60)
    print(f"[成功] 解析结果：{spec_file}")
    print(f"       推理日志：{trace_path}")
    if filled:
        print(f"       自动补全了 {len(filled)} 个字段（已记入日志）")
    print("\n--- JSON 预览 ---")
    print(json.dumps(spec, ensure_ascii=False, indent=2))


if __name__ == "__main__":
    main()
```

**代码在干什么**（看懂这几句就够写报告了）：

1. 从 `config.json` 读模型名、地址、Key 的环境变量名 → **Key 不落盘**
2. 读 `system_prompt.txt` 当 system 消息，需求文本当 user 消息
3. 拿到回复后**先剥 markdown 代码块，再解析 JSON**
4. **校验字段**（硬约束/优化目标/单位/优先级），缺了就带着"缺什么"再问一次
5. 还缺的用 `autofill` 兜底补上，**并且把补了什么记进日志**（这一步就是报告里"为什么这么解析"的证据）
6. 输出 `spec_时间戳.json` + 固定名 `spec_case1.json` + 推理日志 `trace_*.jsonl`

## 7. 第 7 步：自检（这一步直接决定那 10 分）

打开生成出来的 `spec_case1.json`，逐条打勾：

- [ ] 有 `design_type`（电路类型）
- [ ] 有 `constraints`，且**每一项都同时有** `name / op / value / unit / type / priority`
- [ ] 有 `objectives`，且**每一项都同时有** `name / direction / unit / priority`
- [ ] 有 `pvt_condition` 和 `worst_case`
- [ ] 需求里说的"增益尽可能大"→ 出现在 `objectives`（不是只在 constraints 里）
- [ ] "不得低于 40dB" → 出现在 `constraints`（**阈值是硬约束，不是优化目标**）
- [ ] 需求里**没写**但赛题要卡的底线，被补齐了：`Phase_Margin >= 50 deg`、`Gain_Margin <= -10 dB`、`I_OPA <= 3 mA`
- [ ] 单位没有空字符串

> ⚠️ 最后两条最容易翻车。如果发现缺失，回去做**第 4 步**（给提示词补那三段），然后重跑。

## 8. 第 8 步：整理成交付物

1. **JSON 结果**：`module1/spec_case1.json`（已自动生成）
2. **源码**：`module1/agent/agent.py` + `config.json`（`api_key_env` 只写变量名，**检查里面没有真 Key**）
3. **提示词**：`module1/system_prompt.txt`
4. **推理链日志**：`module1/agent/output/trace_*.jsonl`
5. **报告里要写的一段**（照抄结构即可）：

   > 模块一采用"提示词约束 + 结构化输出 + 规则校验兜底"三段式设计。
   > 系统提示词固定 JSON Schema、单位归一化规则与语义映射规则；
   > 模型输出后由 `check_spec()` 校验硬约束、优化目标、单位、优先级四类字段，
   > 缺失则携带缺失清单自动重试；仍缺失的字段由 `autofill()` 按指标-单位映射表补齐，
   > 补全动作全部记录于 `trace_*.jsonl` 以保证可追溯性。
   > 完整决策依据见日志文件。

## 9. 常见报错速查

| 报错 | 原因 | 解决 |
|---|---|---|
| `环境变量 DASHSCOPE_API_KEY 没设置` | 没设或换了终端 | 重做第 2 步 |
| `401 Incorrect API key provided` | Key 与北京地域不匹配，或 Key 打错 | 去华北2（北京）业务空间重新创建 Key |
| `Connection error` / 一直转圈 | 网络/DNS | 换个网络（手机热点）试试；公司网络可能需要代理 |
| `输出不是合法 JSON` | 模型带了废话 | 代码已自动重试，重试 3 次仍失败就把原文发我 |
| `finish_reason='length'` | 输出被截断 | 把 `config.json` 里 `max_tokens` 调到 8192 |
| `ModuleNotFoundError: openai` | 没装库 | `python -m pip install -U openai` |
| 每次结果都不一样 | 模型随机性 | `temperature` 调低到 0（不推荐 0，建议 0.1~0.2） |

## 附：为什么不用 `/apps/anthropic` 那个地址

你给的两个地址里：

- `.../compatible-mode/v1` → **OpenAI 兼容接口**，用 `openai` 库调
- `.../apps/anthropic` → **Anthropic 兼容接口**，要用 Anthropic SDK 调

本教程统一用第一个。两者调的是同一个模型，但**不要混用 SDK**，否则会报协议不匹配。
