> **安全约定（先读）**：本文件**不记录**任何口令、账号、服务器地址。这些值只存在于赛方下发的
> 《服务器信息-VPN连接配置.xlsx》里 —— 该文件**只放本地、勿入版本库**

## 0. 开始前需要一个东西：赛方配置表

打开《服务器信息-VPN连接配置.xlsx》，你会看到 8 列。把下面 6 个值抄进自己的密码管理器（**不要抄进任何代码/文档**）：

| 配置表列名 | 用在哪 |
|---|---|
| `vpn地址` | EasyConnect 的"服务器地址" |
| `vpn账号` | EasyConnect 用户名 |
| `初始VPN密码` | EasyConnect 密码（**首次登录会强制修改**） |
| `服务器IP` | TigerVNC 地址栏冒号前；也用于 `Test-NetConnection` |
| `vnc port`（本组是 32） | TigerVNC 地址栏冒号后（**这是 display 号，不是 TCP 端口**） |
| `Linux账号` / `Linux密码` / `VNC密码` | 第 4 步与第 3 步 |

> 同一行里 Linux 账号、Linux 密码、VNC 密码通常是同一组（SOP：三处账号密码一致）。

## 2. 连 VPN（EasyConnect）

1. 打开 EasyConnect。
2. **服务器地址**填配置表的 `vpn地址`。两种写法都可以试：
   - `222.71.182.106:3443`（IP:端口，最稳）
   - `https://222.71.182.106:3443`（带协议头，有的版本需要）
3. 输入 `vpn账号` + `初始VPN密码`，点登录。
4. ⚠️ **首次登录会被强制改密码**。改完立刻存进密码管理器，**不要写进任何文件/聊天记录**。
   如果提示密码错误，先确认队友是否已经改过（同一账号共用，改了就是新密码）。

**验收（两条都要过）**：

```powershell
# ① 能看到 VPN 虚拟网卡（出现新网卡/IP 段）
ipconfig | Select-String "PPP|Sangfor|Ethernet adapter"

# ② 服务器端口可达（端口 = 5900 + display；本组 display=32 → 5932）
Test-NetConnection <服务器IP> -Port 5932
# 期望：TcpTestSucceeded : True
```

> `TcpTestSucceeded : False` 先别打开 TigerVNC —— 说明 VPN 没把该网段路由进来，
> 或者服务器防火墙挡了 5932。见第 7 节。

---

## 3. 连 VNC（TigerVNC Viewer）

1. 打开 **TigerVNC Viewer**，出现 "VNC 服务器" 输入框。
2. 地址栏填：`<服务器IP>:<display>`
   本组就是 **`172.21.170.32:32`**。
3. 点"连接"，弹出认证框，输入 **VNC 密码**。

**格式是这一步唯一的坑**：

| 写法 | 含义 | 结果 |
|---|---|---|
| `IP:32` | display 32 → TCP **5932** | ✅ 正确 |
| `IP:5932` | display 5932 → TCP 11832 | ❌ 连不上 |
| `IP::5932` | **双冒号 = 直接给 TCP 端口** | ✅ 备用写法（第一种连不上时用） |

依据：`media/03-vnc服务器地址.png` 的示例是 `172.21.170.32:6`，
`media/05-linux登录.png` 的窗口标题是 `eda202601:6 (edauser06)` ——
**账号编号和 display 号是同一个数**，所以 `edauser32` 对应 `:32`。

**验收**：出现 Linux 桌面（通常是锁屏界面，说明 VNC 这一层已经通了）。

---

## 4. 登录 Linux

1. 锁屏界面上会显示用户名（如 `edauser32`）和一个 `Password:` 输入框。
2. 输入 **Linux 密码**，点 **Unlock**（不要点 Cancel）。

**验收**：进入桌面；TigerVNC 窗口标题形如 `eda202601:6 (edauser06) - TigerVNC`
（你自己的会是 `...:32 (edauser32)`），说明"display ↔ 账号"对上了。

> 如果显示 "Log in as another user" 而不是 Unlock，说明当前会话锁在别的用户下：
> 点它，用你的 `Linux账号/Linux密码` 重新登录。

## 6. 团队多人共用一个账号（不要各登各的 VPN）

**规则**：一个账号只能在一台机器上挂着 VPN，谁在自己电脑上登 EasyConnect 都会把别人顶掉。
落地架构（详见 `Easyconnect多人操作.txt`）：

```
协作者 A/B/C ── SSH 隧道 ──▶ 跳板机 Win（独占 VPN） ──内网──▶ 目标 Linux :32（VNC AlwaysShared）
```

- 跳板机：独占 EasyConnect + 开 OpenSSH Server；
- 协作者：`ssh -N -L 5932:<服务器IP>:5932 <跳板机用户>@<跳板机IP>`，
  然后 TigerVNC 连 `localhost:5932`；
- 目标机必须开 **`AlwaysShared`**，否则第二个人连上会踢掉第一个人；
- 只想看不想动的人，在 Viewer 里关掉 `Send keyboard/mouse`（View Only）。

> ⚠️ **VNC 剪贴板是共享的**：不要把口令复制粘贴到远程桌面里，其他人能看到。

## 7. 故障速查

| 现象 | 最可能原因 | 处理 |
|---|---|---|
| EasyConnect 提示账号或密码错误 | 队友已改过密码 / 账号输错 | 问队友要新密码；确认账号大小写 |
| EasyConnect 连上了，但 `Test-NetConnection` 不通 | VPN 没下发该网段路由；或服务器防火墙 | 换 `vpn.empyrean.com.cn` 域名试；或让管理员放行 5932 |
| TigerVNC `Connection refused` | 地址填成了 TCP 端口（`:5932`） | 改回 `:32`；或试 `::5932` |
| TigerVNC 连上后黑屏 / 只有灰屏 | 目标机 X 会话没起窗口管理器 | 让管理员重启 `vncserver@:32`；或看 `~/.vnc/xstartup` |
| 第二个人连上，第一个人被踢 | 目标机没开 `AlwaysShared` | 见 `Easyconnect多人操作.txt` 第 1 步 |
| 输完 Linux 密码点 Unlock 没反应 | 密码错 / 键盘布局把符号打错 | 用"眼睛"图标显示明文检查；注意大小写与特殊字符 |
| 每隔几分钟全体掉线 | EasyConnect 空闲超时 | 跳板机加保活脚本 + 关休眠（见 `Easyconnect多人操作.txt` 2.1） |

## 8. 安全纪律（这次血泪教训）

- **口令只进密码管理器**：不进代码、不进文档、不进截图、不进提交包。
- 首次登录立刻改 VPN 密码；改完只在密码管理器里留一份。
- 若怀疑泄露 → **改密码是唯一真正止损的动作**（清历史/删文件都不能挽回已暴露的事实）。
- 不要把账号密码发给第三方；需要协作时用第 6 节的"独占 VPN + 隧道"方案，而不是共享口令。
- 提交代码前跑一遍 `AGENTS.md` 2.10 的三条检查。
