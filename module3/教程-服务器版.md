## 1. 先搞清楚模块三要交什么

### 1.1 评分（赛题 6.3 原文）

| 项 | 分 | 条件 | 口径 |
|---|---|---|---|
| 相位裕度 PM | 10 | **PM ≥ 50°** | **所有 PVT 角**都要满足；不满足本项直接 0 |
| 增益裕度 GM | 10 | **GM ≤ −10 dB** | 所有 PVT 角 |
| 工作电流 I_OPA | 10 | **I_OPA ≤ 3 mA** | 所有 PVT 角 |
| 直流增益 DC Gain | 10 | 越大越好；**< 40 dB 记 0** | 所有 PVT 的**最坏情况**；得分 = (DCGain₁/DCGain₀)×10 |
| 单位增益带宽 UGB | 15 | 越大越好 | 最坏情况；得分 = (UGB₁/UGB₀)×15 |
| 面积 Area | 15 | 越小越好 | 得分 = (A₀/A₁)×15 |
| 运行总时间 | 10 | 越快越好 | 基础分 = (T₀/T₁)×10；**每违反一条约束再扣 5** |

其中 `DCGain₀/UGB₀/A₀/T₀` 是**所有队伍里的最好值**——所以这是**相对排名**，
拿满分意味着"比所有对手都好"，不是"达到某个绝对门限"。

> **推论（很重要）**：硬约束不是"尽量满足"，是**入场券**。
> 30 分约束 + 时间分里的扣分合计 45 分的量级都挂在它上面，风险远大于"多优化出 1 dB 增益"。
> 算法设计要**可行性优先**（feasibility-first），而不是先优化目标再补约束。

### 1.2 面积公式（赛题原文，直接照抄进代码）

```
电容:    area = W · L · 1
电阻:    area = W · L · 2
总面积 = Σ 以上（单位换算成 µm² 报出）
```

## 4. 第 3 步：单次仿真闭环（`sim_once.py`）

目标：**给它一组变量，它返回一个 dict**，其中最坏情况指标已聚合好。这是整个模块三的地基。

```python
# sim_once.py —— 单次仿真封装（纯标准库）
import json, os, re, subprocess, sys, time

# 【待核实】字段名以现场日志为准；这里是常见写法
PATTERNS = {
    "dc_gain_db": [r"DC\s*Gain\s*[:=]\s*([-\d.eE+]+)", r"gain\s*[:=]\s*([-\d.eE+]+)\s*dB"],
    "ugb_hz":     [r"UGB\s*[:=]\s*([-\d.eE+]+)", r"UGF\s*[:=]\s*([-\d.eE+]+)"],
    "pm_deg":     [r"Phase\s*Margin\s*[:=]\s*([-\d.eE+]+)", r"PM\s*[:=]\s*([-\d.eE+]+)"],
    "gm_db":      [r"Gain\s*Margin\s*[:=]\s*([-\d.eE+]+)", r"GM\s*[:=]\s*([-\d.eE+]+)"],
    "i_opa_ma":   [r"I_?OPA\s*[:=]\s*([-\d.eE+]+)", r"current\s*[:=]\s*([-\d.eE+]+)"],
}


def write_param_file(path, values):
    """values: {变量名: 数值/字符串}。格式必须与赛方 extractcdfVal_0.txt 完全一致。"""
    with open(path, "w", encoding="utf-8") as f:
        for k in sorted(values):
            f.write("%s=%s\n" % (k, values[k]))


def parse_log(text):
    """从仿真日志里抽指标。多角时返回 list（每个角一份），单角时返回 1 条。"""
    rows = []
    # 【待核实】若日志是"每个角一段"，按角切块；若是单行 CSV，改成逐行解析
    for block in re.split(r"(?m)^\s*(?:corner|Corner|角)\s*[:=]", text):
        row = {}
        for key, pats in PATTERNS.items():
            for p in pats:
                m = re.search(p, block, re.I)
                if m:
                    row[key] = float(m.group(1))
                    break
        if len(row) >= 3:          # 至少抓到 3 个指标才算一条有效结果
            rows.append(row)
    return rows


def sim_once(param_file, values, workdir, provided_py, fixed_args, timeout=1800):
    """写参数 → 调赛方脚本 → 解析 → 返回 {角: 指标} + 耗时。"""
    write_param_file(os.path.join(workdir, param_file), values)
    cmd = [sys.executable, provided_py] + fixed_args + ["--param_file", param_file]
    t0 = time.time()
    r = subprocess.run(cmd, cwd=workdir, capture_output=True, text=True, timeout=timeout)
    elapsed = time.time() - t0
    log_path = os.path.join(workdir, fixed_args[fixed_args.index("--output_path") + 1]
                            if "--output_path" in fixed_args else ".", "output.log")
    # 【待核实】输出文件实际路径；样例用 --output_path/--output_file
    text = r.stdout + "\n" + r.stderr
    if os.path.exists(log_path):
        text += "\n" + open(log_path, encoding="utf-8", errors="replace").read()
    rows = parse_log(text)
    return {"ok": bool(rows), "elapsed_s": elapsed, "corners": rows,
            "stdout_tail": text[-2000:]}
```

**这一步的验收标准**：用手上已知的一组初始尺寸，`sim_once` 返回的
`dc_gain_db / ugb_hz / pm_deg / gm_db / i_opa_ma` 与你在服务器上**肉眼看到的一致**。
不一致就说明解析器没对齐——**先修解析，别谈优化**。

## 5. 第 4 步：PVT 最坏情况聚合

赛题口径（务必按这个来，不要自己发明）：

| 指标 | 聚合方式 | 原因 |
|---|---|---|
| PM / GM / I_OPA | **所有角都要满足**（min PM、最大 \|GM\|、max I_OPA 判） | 任一角不满足 → 该项 0 分 |
| DC Gain | **所有角的最小值** | 评分按"最坏情况" |
| UGB | **所有角的最小值** | 同上 |
| Area | 不随 PVT 变 | 只看尺寸 |

```python
def aggregate(corners):
    if not corners:
        return None
    def get(k, fn):
        vals = [c[k] for c in corners if k in c]
        return fn(vals) if vals else None
    return {
        "n_corners": len(corners),
        "pm_min":    get("pm_deg", min),        # 约束：>= 50
        "gm_worst":  get("gm_db", max),         # 约束：<= -10（注意符号；若日志给的是正值取反）
        "i_max":     get("i_opa_ma", max),      # 约束：<= 3
        "gain_min":  get("dc_gain_db", min),    # 目标：越大越好，>= 40 否则 0 分
        "ugb_min":   get("ugb_hz", min),        # 目标：越大越好
        "feasible": None,                       # 由 constraints_ok 填
    }


def constraints_ok(agg, pm_lim=50.0, gm_lim=-10.0, i_lim=3.0):
    """三条硬约束（全 PVT）。返回 (是否可行, 违反量明细)。"""
    bad = {}
    if agg["pm_min"] is None or agg["pm_min"] < pm_lim:
        bad["PM"] = pm_lim - (agg["pm_min"] or -1e9)
    if agg["gm_worst"] is None or agg["gm_worst"] > gm_lim:
        bad["GM"] = (agg["gm_worst"] or 1e9) - gm_lim
    if agg["i_max"] is None or agg["i_max"] > i_lim:
        bad["I_OPA"] = (agg["i_max"] or 1e9) - i_lim
    return (not bad), bad
```

> ⚠️ **GM 的符号是经典坑**：赛题写 `GM ≤ −10 dB`，但有的仿真器输出 `|GM| = 12 dB`（正数）。
> 现场核实：如果日志给正值，约束就变成 `GM ≥ 10`，代码里要**统一到一种符号**再比较，
> 并在报告里写明你用的是哪种口径。

## 6. 第 5 步：面积、目标与"模拟打分"

### 6.1 面积

```python
def area_um2(vars_by_device):
    """vars_by_device: {器件名: {param: 值}}，长度统一换算成 µm。
    公式来自赛题：MOS = fw·L·m·1.5；电容 = W·L；电阻 = W·L·2。
    """
    total = 0.0
    for name, p in vars_by_device.items():
        if name.startswith(("NM", "PM")):                 # MOS
            fw_um, l_um, m = p["w_um"], p["l_um"], p["m"]
            total += fw_um * l_um * m * 1.5
        elif name.startswith("C"):                        # 电容
            total += p["w_um"] * p["l_um"]
        elif name.startswith("R"):                        # 电阻
            total += p["w_um"] * p["l_um"] * 2
    return total
```

> 注意：电阻的 `segL/segW` 是**单段**尺寸，串联 n 段时面积要不要乘 n？
> 赛题原文只说"电阻面积为 W·L·2"。**现场按赛方口径核实**（若按物理面积，R0/R3 各 10 段要乘 10，
> 差 20 倍，会明显影响面积目标的相对排名）。

### 6.2 可行性优先的代价函数

```python
def cost(agg, area, mode="feasibility_first"):
    """
    规则：
      1) 先看三条硬约束：不可行 -> 代价 = 1e6 + 归一化违反量（让优化器先修约束）
      2) 可行后：DC Gain < 40dB 视为不可接受（该项 0 分）-> 也给重罚
      3) 可行且 >=40dB：按"越大越好/越小越好"归一化成单目标
    """
    ok, bad = constraints_ok(agg)
    if not ok:
        viol = sum(bad.values())
        return 1e6 + viol
    if agg["gain_min"] < 40.0:
        return 1e5 + (40.0 - agg["gain_min"])
    # 可行：UGB 与面积/增益做加权（权重最后用 A/B 实测调）
    # 归一化用参考值，避免量纲差异
    return (100.0 - agg["gain_min"]) + (1e8 / max(agg["ugb_min"], 1.0)) \
           + (area * 1e3) / 100.0
```

> 权重不是拍脑袋：赛题给的是**排名制**（(UGB₁/UGB₀)×15 等），所以
> 目标之间的相对权重应该**按"每提升 1% 能多拿多少分"**来定，而不是按量纲。
> 实操：先在服务器上跑 2–3 个阶段的粗搜，看 UGB 与 Area 的可达范围，再定权重。

## 7. 第 6 步：变量空间（口径 A/B）

### 7.1 两套口径（依据《对拍》§7 的结论）

| 口径 | 内容 | 变量数 | 用途 |
|---|---|---|---|
| **B（交付物现状）** | 镜像组绑 `w/l`，比例只能用整数 `m` | **47** | 模块二交付、报告里的主口径之一 |
| **A（模块三默认）** | 镜像组**只绑 L**，`w` 保留自由 → 比例连续可调 | 比 B **多 7 个 `w`** | 优化时用，约束风险更低 |

> 为什么 A 更适合先跑：绑 `w` 会把镜像比量化为 `m·multi` 的整数格点（比值不能 <1），
> 一旦某个镜像管掉出饱和区，`I_OPA` 立刻偏离 → **硬约束 0 分**。
> 风险不对称 → 《对拍》结论是"先用只绑 L 跑优化，绑 w 的 47 变量作 A/B 对照"。
>
> **口径 A 的 7 个额外 `w` 已实测**：`CM1` 的 `NM2|NM3|NM6|NM7|NM8|NM9|NM12|NM13` 拆成 5 组（+4）、
> `CM3` 的 `PM0|PM1|PM4` 拆成 3 组（+2）、`CM2` 的 `PM5|PM6` 拆成 2 组（+1）；
> 其余配对（σ 对称对、差分对、支路对应、R6 共源共栅 L）保持不变。

### 7.2 边界与整数处理（赛题 6.3 附 2 的工艺约束）

| 变量 | 类型 | 范围 |
|---|---|---|
| MOS `w`（fw） | 连续 | 0.13 µm – 20 µm |
| MOS `l` | 连续 | 0.13 µm – 10 µm |
| `m`（multiplier） | **整数** | 1 – 20 |
| 电阻 `segL/segW` | 连续 | 0.13 µm – 20 µm |
| 电容 `l` | 连续 | 0.13 µm – 20 µm |

**整数变量的铁律**：优化器内部可以用实数，但**在写 param 文件之前必须取整**，
并且**用取整后的实际值去评估代价**（否则你优化的点和你仿真的点不是同一个点，会出现
"最优解一仿真就废"）。

```python
def to_physical(x, spec):
    """x: 归一化向量 [0,1]^n → 物理值；整数参数取整。"""
    out = {}
    for i, (name, s) in enumerate(spec.items()):
        v = s["lo"] + x[i] * (s["hi"] - s["lo"])
        if s["integer"]:
            v = int(round(v))
        out[name] = v
    return out


def from_physical(values, spec):
    """物理值 → 归一化向量（用于初始化/打印）。"""
    return [ (values[n] - s["lo"]) / (s["hi"] - s["lo"]) for n, s in spec.items() ]
```

### 7.3 回写面：**别只写 47 个变量**

模块二的 `param_list_reduced.txt` 是 47 行，但**原理图上有 105 个符号**。
只写 47 行会导致被合并掉的成员（如 `NM3_fw`）**保持初值** →
你以为绑定成一致的镜像管，仿真里其实不一致，**而且不报错**。

所以服务器侧的参数文件必须是**105 行**：用模块二的
`params_writeback_template.txt` + `expand_params.py` 的同一套逻辑展开
（模板里 `@自由变量` 表示取值来源，`#fixed` 表示 Dummy 保留初值）。

```python
def expand_to_schematic(free_values, template):
    """template 从 module2/params_writeback_template.txt 读入（105 行）。
    返回 {原理图符号: 值}，供写 param 文件。"""
    out = {}
    for sym, src in template.items():
        if src.startswith("@"):
            out[sym] = free_values[src[1:]]
        # '#fixed'（Dummy）不写，让它保留原理图初值；若赛方要求全覆盖再补初值
    return out
```

## 8. 第 7 步：优化算法（差分进化 + 预算控制）

### 8.1 为什么选差分进化（DE）

| 理由 | 说明 |
|---|---|
| 黑盒 | 拿不到梯度，甚至不知道仿真器内部怎么算 |
| 混合变量 | 连续（w/l）+ 整数（m）并存，DE 取整即可 |
| 维度中等 | 50–60 维，DE/GA 这类群体算法还能吃下（不必上代理模型） |
| 好实现 | 纯标准库 60 行；出问题好查 |
| 约束处理简单 | 代价函数里罚函数 + 可行性优先就够了 |

> 备选：贝叶斯优化（采样效率更高，但实现/调参成本高、对整数变量不友好）；
> 遗传算法（和 DE 同族，交叉算子不如 DE 的差分有效）。**先用 DE 跑通，再考虑换。**

### 8.2 预算反推（3 小时是硬上限）

```
总预算        = 3 h = 10800 s
可用预算      = 10800 × 0.7（留 30% 给收尾/反标/PVT 验证/意外）= 7560 s
单次评估耗时 T_eval  ← 第 2 步实测
N_evals      ≈ 7560 / T_eval          （若一次只跑一个角，再除以角数）
```

举例（**用真实 T_eval 替换**）：

| T_eval | N_evals | DE 该怎么配 |
|---|---|---|
| 5 s | ~1500 | 群体 40 × 35 代，可两阶段 |
| 30 s | ~250 | 群体 20 × 12 代，只够单阶段 |
| 300 s | ~25 | **放弃群体算法**，改"手调 + 坐标搜索/贝叶斯"（20+ 维时根本不够） |

> 这一栏是**决定策略**的地方：**先量 T_eval，再选算法**。别先写完 DE 才发现只能跑 20 次。

### 8.3 骨架（DE + 缓存 + 超时保护 + 断点续跑）

```python
# de_opt.py —— 差分进化（纯标准库）
import json, os, random, time


def de(spec, evaluate, budget_evals, pop=30, F=0.6, CR=0.9,
       time_limit_s=None, seed=2026, ckpt="ckpt.json"):
    """spec: {变量名: {lo,hi,integer}}；evaluate(candidate:dict)->(cost, info)
    - 返回值都取整后的物理值 -> 评估（保证"优化的点=仿真的点"）
    - 缓存：同一组取值不重复仿真
    - 超时/次数到就停，并把最优解落盘（断点续跑读这个文件）
    """
    rng = random.Random(seed)
    names = list(spec)
    lo = [spec[n]["lo"] for n in names]
    hi = [spec[n]["hi"] for n in names]
    D = len(names)
    cache, best = {}, {"cost": float("inf"), "x": None, "info": None}
    t_start = time.time()

    def phys(x):
        v = {}
        for i, n in enumerate(names):
            p = lo[i] + x[i] * (hi[i] - lo[i])
            v[n] = int(round(p)) if spec[n]["integer"] else p
        return v

    def f(x):
        nonlocal best
        v = phys(x)
        key = json.dumps(v, sort_keys=True)
        if key in cache:
            return cache[key][0]
        if budget_evals is not None and len(cache) >= budget_evals:
            return float("inf")
        if time_limit_s and time.time() - t_start > time_limit_s:
            return float("inf")
        c, info = evaluate(v)
        cache[key] = (c, info)
        if c < best["cost"]:
            best = {"cost": c, "x": list(x), "info": info, "values": v}
            with open(ckpt, "w", encoding="utf-8") as fp:
                json.dump({"best": best, "n_eval": len(cache)}, fp,
                          ensure_ascii=False, indent=1)
        return c

    # 初始化（含初始解：赛题要求"在给定初始解条件下优化"）
    popu = [[0.5] * D for _ in range(pop)]
    for i in range(1, pop):
        popu[i] = [rng.random() for _ in range(D)]
    costs = [f(x) for x in popu]

    gen = 0
    while True:
        gen += 1
        improved = False
        for i in range(pop):
            a, b, c = rng.sample(range(pop), 3)
            # 若某次采样到的等于 i，重抽
            while i in (a, b, c):
                a, b, c = rng.sample(range(pop), 3)
            trial = [(popu[a][k] + F * (popu[b][k] - popu[c][k])) for k in range(D)]
            trial = [min(1.0, max(0.0, t)) for t in trial]
            jr = rng.randrange(D)
            trial = [trial[k] if (rng.random() < CR or k == jr) else popu[i][k]
                     for k in range(D)]
            ct = f(trial)
            if ct < costs[i]:
                popu[i], costs[i] = trial, ct
                improved = True
        # 收敛判据
        if not improved or (budget_evals and len(cache) >= budget_evals):
            break
        if time_limit_s and time.time() - t_start > time_limit_s:
            break
        # 把最优个体注入种群，加快收敛
        if best["x"] is not None:
            popu[0], costs[0] = list(best["x"]), best["cost"]
        print("[gen %d] best cost=%.4f  n_eval=%d  elapsed=%.0fs"
              % (gen, best["cost"], len(cache), time.time() - t_start))

    return best, {"n_eval": len(cache), "elapsed_s": time.time() - t_start, "gen": gen}
```

### 8.4 两阶段 + 解绑回退（relax）

```
阶段 1（粗搜，占预算 60%）：口径 A（只绑 L）、宽边界、群体 30、F=0.6
阶段 2（精搜，占预算 30%）: 以阶段 1 最优为中心，把边界缩到 ±20%，F=0.3、CR=1.0
收尾   （占预算 10%）     : 在最优解附近做坐标扫描（逐个变量 ±5%）
```

**解绑回退（relax）**——当"可行性优先"反复卡在某个约束上时：

```text
若阶段 1 结束仍不可行，且违反集中在 I_OPA：
  1) 找出通过镜像电流贡献最大的那条支路（可近似：m 最大 / W 最大的镜像管）；
  2) 把该管的 W 从"绑定组"里解绑（口径 A 本来就自由；口径 B 下则放开该组 W）；
  3) 用剩余预算重跑阶段 2；
  4) 在报告里记录"发生过一次解绑回退"及其原因——这是加分的设计细节，不是缺陷。
```

```python
# mock_sim.py —— 假仿真器：用在本地测"优化器 + 解析 + 打包"逻辑
# 用简单模型模拟"尺寸 → 指标"，只求趋势正确，不求物理准确
import math


def mock_sim(params):
    """注意：这里假定 params 里的长度已换算成 µm。"""
    w = params.get("PM9_fw", 10.0)          # µm
    l = params.get("PM9_l", 1.0)            # µm
    m = params.get("NM2_m", 8)              # 整数
    gm = 200.0 * math.sqrt(w / l)
    ugb = 1.0e6 * gm / (1 + l) * (m / 8) ** 0.3
    pm = 60.0 + 40.0 * (l / (l + 2.0)) - 0.5 * (m - 8)
    i_ma = 0.4 * m
    return {"dc_gain_db": 20 * math.log10(max(gm, 1e-3)),
            "ugb_hz": ugb, "pm_deg": pm, "gm_db": -12.0, "i_opa_ma": i_ma}
```
