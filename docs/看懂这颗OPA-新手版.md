# 新手版：带你读懂 `OPA_loopgain` 这颗全差分运放

> 面向：第一次看 Spectre 网表、第一次看运放原理图的人。
> 数据来源：`extracted/赛题数据本身/netlist/OPA_loopgain.netlist`（368 行）+ 配套的 `OPA_loopgain.scs`。
> 配套可读表：[netlist_readable.md](../module1/agent/output/netlist_readable.md)（一行一个器件）。

---

## 0. 三句话结论

1. 这是一颗**两级、全差分、带共模反馈、带米勒补偿**的运算放大器。
2. **第一级**：PMOS 差分输入对 `PM9/PM10` + 电流镜有源负载 `NM6/NM7`（上面还叠了级联管 `NM4/NM5`），把 `VINP/VINN` 的差放大。
3. **第二级**：PMOS 共源放大 `PM7/PM11` 直接驱动 `VOUTP/VOUTN`；另外有一圈**共模反馈**专门管住输出的"平均值"，还有两组 RC 做频率补偿。

记住这三个词，剩下的都是细节：**差模**（有用的信号）、**共模**（两条输出线的平均值，要稳住）、**偏置**（让所有管子工作在正确电流上）。

## 1. 读之前必须认识的 8 件事

### 1.1 一行网表怎么读

```
NM15 (VOUTN IREF VOUTN SUB) n_mos_a l=NM15_l w=NM15_fw multi=1 m=NM15_m
└─┬─┘ └──────┬───────────┘ └──┬───┘ └─────────┬──────────┘
 器件名      4 个端子          模型名         尺寸参数
```

**端子顺序是固定的**：MOS 的四端按 `(漏 d, 栅 g, 源 s, 衬底 b)` 排列。所以 `NM15` 是"漏=VOUTN、栅=IREF、源=VOUTN、衬底=SUB"。

> 两端器件（电阻/电容）只有两个端子，写的是 `(端点1 端点2)`，没有极性之分，**顺序是任意的**——`C2 (outaverage VOUTP)` 和 `C3 (VOUTN outaverage)` 就是反着写的，它们其实是对称的一对。

### 1.2 怎么一眼看出 N 管还是 P 管

看**模型名**：`n_mos_a` = NMOS，`p_mos_a` = PMOS。规矩是固定的：

- **NMOS**：源极接 GND 或低电位，**栅压越高导通越多**，往下"吸"电流。
- **PMOS**：源极接 VDD 或高电位，**栅压越低导通越多**，往上"灌"电流。

### 1.3 "漏源短接在同一个节点"是什么

网表里 `NM2 (net53 net53 GNDA SUB)`：漏=net53、栅=net53 → 这叫**二极管接法**（栅漏短接）。作用是"我用我自己的电流决定我自己的栅压"，也就是**产生一个偏置电压**。这类管子通常出现在电流镜里当**参考管**。

### 1.4 这些尺寸是"变量名"，不是数字

```
l=NM15_l   w=NM15_fw   m=NM15_m
```

**这不是笔误。** 这颗电路已经做过"参数化"：每个管子的尺寸都换成了变量名，等着优化器去填数字。所以网表里你看不到 `w=10u` 这种具体尺寸。

- `l` = 沟道长度，`w`（官方变量名 `fw`）= 单个指条的宽度，`m` = 指条数（整数倍）。
- 电容写作 `l=C0_l w=30u m=2`：`w=30u`、`m=2` 是**字面常数**（PDK 固定的），只有 `l` 是变量。

### 1.5 那些 `+ad=... +as=...` 是什么（也是"乱码感"的来源）

每个 MOS 后面跟着 10 行：

```
+ad=(NM15_fw<300n)?((0*(9e-14+(NM15_fw*1.4e-07)))+((9e-14+(NM15_fw*70n))))/1:((3.8e-07*NM15_fw)+...
```

这是**版图寄生参数**（`ad/as/pd/ps/nrd/nrs/sa/sb`），由 PDK 根据版图自动生成，**不是电路逻辑，也不用去优化**。看电路时**整块跳过**就行——本文后面提到的所有内容都和这些行无关。

### 1.6 自动网名（`net4`、`net53`、`outaverage`）

`net4`、`net53` 这类名字是工具自动起的（原理图里没给网络起名）。它们没有含义，**看它连了哪些器件**才知道作用。少数节点有名字，都是有意义的：

| 节点 | 含义 |
|---|---|
| `VDDA` | 电源（1.8 V） |
| `GNDA` / `SUB` | 地 / 衬底 |
| `IREF` | 偏置参考电流输入（10 µA） |
| `VCM` | 目标共模电平（= VDD/2 = 0.9 V） |
| `VINP` / `VINN` | 差分输入 |
| `VOUTP` / `VOUTN` | 差分输出 |
| `outaverage` | 输出的**平均值**（共模取样点） |
| `vcmfb` | 共模反馈的**控制电压** |

### 1.7 什么是"共模"（最容易听懵的概念）

**先记住一句话：两条线上的电压，可以拆成"差值"和"平均值"两半。差值叫差模，平均值叫共模。**

```
        差模（differential）= VOUTP − VOUTN     ← 有用的信号
        共模（common mode） = (VOUTP + VOUTN)/2  ← 两条线"一起"的动作
```

反过来说也成立（这只是把同一组数字换一种写法）：

```
        VOUTP = 共模 + 差模/2
        VOUTN = 共模 − 差模/2
```

#### 用数字体会一下（关键！）

| 情况 | VOUTP | VOUTN | 差模 = 差值 | 共模 = 平均值 | 说明 |
|---|---|---|---|---|---|
| A | 0.91 V | 0.89 V | **0.02 V** | **0.90 V** | 正常：信号 20 mV，中心在 0.9 V |
| B | 1.01 V | 0.99 V | **0.02 V** | **1.00 V** | **信号没变**，但两条线一起往上跑了 → **共模漂了** |
| C | 1.01 V | 0.79 V | **0.22 V** | **0.90 V** | 信号变大了 10 倍，中心还在 0.9 V ✓ |

看 B 和 A：**差模完全一样（都是 20 mV），但共模从 0.9 V 涨到了 1.0 V**。
这就是共模问题的本质——**信号本身没坏，但两条线集体跑偏了，管子会掉出饱和区，电路失效**。

#### 为什么要分成这两半？因为它们由两条不同的环路管

| | 差模 | 共模 |
|---|---|---|
| 谁在管 | 主放大通路（`VINP/VINN` → `net0/net8` → 输出） | **共模反馈环（CMFB）** |
| 目标 | 越大越好（增益、带宽） | **钉死在 `VCM` = 0.9 V** |
| 为什么差分管不了共模 | 差分对只对"两条线的差"敏感，**两条线一起升高在差模通路里不产生任何信号** | 所以必须另开一条专门看平均值的环路 |

#### 在这颗电路里，共模出现在三个地方

1. **输入共模**：`VINP/VINN` 的平均值。测试台用 `VV3` 把它钉在 `VDD/2 = 0.9 V`，同时接到 `VCM` 端口当参考。
2. **输出共模**：`(VOUTP+VOUTN)/2`，由 CMFB 环钉在 `VCM`。
3. **取样点**：`outaverage` 这个名字就是"输出平均值"的意思——它就是输出共模的实测值，直接送进 `PM12` 的栅极。

#### 一个生活类比

两个人并排走路：

- **差模** = 两人之间的**距离**（你想控制的信息）；
- **共模** = 两人的**中点位置**（你不想它乱跑）。

你可以把两人间距控制得很完美，但如果两个人的中点一起飘到了马路中央，照样出事。所以除了"管距离"（差模反馈），还要有"管中点"（共模反馈）。

> 顺带一提：以后你会看到指标 **CMRR（共模抑制比）**，它衡量的是"这个放大器有多能无视共模干扰"——理想情况下输入共模怎么变，输出都不受影响。

### 1.8 什么是 `w` / `l` / `m`（本文档里简写成 `wlm`）

**这不是术语，是三个尺寸参数的首字母缩写**。看到 `l/w/m`、`w/l`、`wl`、`wlm`，说的都是它们。

**俯视图**：

```
        ┌───────────────────────────┐
        │                           │  W（宽度）
        │        沟道区              │  ↑ 与电流方向垂直
        │    ←────  L  ────→        │  │
        └───────────────────────────┘
          源(S)                 漏(D)

     电流就是这个方向：S ←→ D，跨过的距离 = L
```

| 参数 | 中文 | 含义 | 效果 |
|---|---|---|---|
| **`W`** | 沟道**宽度** | 与电流方向垂直的尺寸 | 越宽 → 电流越大 |
| **`L`** | 沟道**长度** | 源到漏的距离 | 越长 → 电流越小 |
| **`m`** | **Multiplier** | 把这只管子并联 m 份 | 电流 × m |

```
I_D ≈ ½ · μCox · (W/L) · (Vgs − Vth)²  ×  m
                   └────┬────┘          └┬┘
                   宽长比 = 管子多强      并联几份
```

**网表里的写法**：

```
NM13 (net52 net53 GNDA SUB) n_mos_a l=NM13_l w=NM13_fw multi=4 m=NM13_m
                                     └──┬──┘ └───┬───┘ └──┬──┘ └──┬──┘
                                        L      W      指条数  Multiplier
```

⚠️ **两个容易混的地方**：

1. **网表里的键名是 `w`，官方变量名却是 `fw`**（finger width，单指宽度）：`w=NM13_fw` → 变量名 `NM13_fw`。所以本文档说"`w`"时指的是 `fw`。
2. **`multi` 和 `m` 是两回事**：

| 名字 | 例子 | 是什么 | 性质 |
|---|---|---|---|
| `multi` | `multi=4` | **指条数（nf）**——一只管子由几根"手指"拼成 | **字面常数**，不是优化变量 |
| `m` | `m=NM13_m` | **Multiplier**——并联几份 | **优化变量**（赛题约束 1~20 整数）|

怎么确认 `multi` 是指条数？看版图寄生参数表达式的**除数**：

```
NM13 (... multi=4 ...)  +ad=(2*(9e-14+(NM13_fw*1.4e-07)))/4     ← 除以 4
PM2  (... multi=40 ...) +ad=(20*(9e-14+(PM2_fw*1.4e-07)))/40    ← 除以 40
```

除数正好等于 `multi` —— 它在把总寄生参数摊到每根手指上。所以 **总栅宽 = `fw` × `multi` × `m`**。

**这三个就是"尺寸优化"的全部自由度**。赛题给的面积公式正好用的就是这三个量，可以互相印证：

```
每个晶体管的面积 = fw × L × m × 1.5      （赛题 6.3 原文）
                    └┬┘   └┬┘   └┬┘
                     W     L     m
```

**赛题对它们的范围约束**（PDF 附件 2）：

| 参数 | 范围 |
|---|---|
| 宽度 `W`(fw) | 0.13 µm – 20 µm |
| 长度 `L` | 0.13 µm – 10 µm |
| `m` | 1, 2, … 20（**整数**）|

> 顺带说明：模块二里反复出现的"**绑** `w/l/m`"，意思是"让两只管子的这个参数**共用同一个变量**"。镜像管的 `L` 必须绑（否则 `λ` 不同、镜像比会随电压漂移）；对称对（差分两臂）必须三个全绑；而镜像组的 `W` 该不该绑，正是那份方案对拍要讨论的核心取舍。

## 3. 信号是怎么走的（跟着走一遍）

**① 输入进来。** `VINP` 接 `PM9` 的栅，`VINN` 接 `PM10` 的栅。这两只 PMOS 的源极都接在 `net37`——同一个"尾节点"，所以它们构成**主差分输入对**（`IP2`）。

**② 尾电流。** `PM1` 的漏极就是 `net37`，它从 VDDA 往这个差分对送一个恒定电流（`multi=8`，是比较大的管子）。差分对的作用是：**把这个恒定电流按输入电压差"劈"成两半**的一半多一点、一半少一点。

**③ 电流差变成电压。** `PM9` 的漏是 `net4`，`PM10` 的漏是 `net44`。这两个节点上接着 `NM6`/`NM7`（栅极都接 `net53`，是电流镜像，`multi=4`）——它们作为**有源负载**。一条支路电流多了、另一条少了，`net4`/`net44` 的电压就往相反方向变。

**④ 抬高 + 电平搬移。** `NM4`（漏 net0、源 net4、栅 IREF）和 `NM5`（漏 net8、源 net44）是**级联管**，把电流差往上送到 `net0`/`net8`。级联的好处是提高输出阻抗 → 提高增益。

**⑤ 第二级放大。** `net0` 是 `PM7` 的栅，`net8` 是 `PM11` 的栅。`PM7` 从 VDDA 往 `VOUTP` 灌电流，`NM8` 从 `VOUTP` 往 GNDA 吸电流——两者一推一拉，`VOUTP` 就是放大后的输出。另一侧 `PM11`/`NM9` 完全对称。

**⑥ 补偿与共模。** `C11+R1` 跨在 `VOUTP` 和 `net0` 之间做米勒补偿（防止振荡）；`R0/R3` 把两个输出取平均得到 `outaverage`，送给共模反馈环去管住输出的平均值。

> 注意 `net0` 和 `VOUTP` 是**反相**的：`net0` 电压升高 → PMOS `PM7` 导通变少 → `VOUTP` 下降。这就是"共源放大级"的符号。

## 4. 六个功能块逐个拆

### 4.1 偏置链：让所有管子有正确的电流（`BIAS1`）

```
IREF(10µA 从 II12 灌进来)
   │
 [NM0]  二极管接法（栅=漏=IREF），源极接 net53
   │
 net53 ──┬── [NM2] 二极管接法到 GNDA（参考管）
         └──► 所有镜像管的栅：NM3 NM6 NM7 NM8 NM9 NM12 NM13
                  │
        [NM3] 吸收电流 ──► net32 ── [NM1]（栅 IREF，共栅）──► net6
                                                                 │
                                              [PM0] 二极管接法（参考管）
                                                                 │
                                        ┌────────────────────────┴────────┐
                                   net6 ──► [PM1]                   net6 ──► [PM4]
                                          (主差分对尾电流, multi=8)   (共模反馈尾电流, multi=4)
```

**怎么读这个链**：`IREF` 上的 10 µA 是"种子电流"。它流过两只二极管接法的 NMOS（`NM0`、`NM2`），在 `net53` 上造出一个栅压；然后**所有栅接 `net53` 的 NMOS 都按比例复制这个电流**（复制倍数由各自的 W/L 和 `m` 决定）。同理 PMOS 侧用 `PM0` 造出 `net6`，再复制给 `PM1`、`PM4`。

> 新手常见困惑：为什么 `NM0` 和 `NM2` **两只二极管串在一起**？因为要同时造出两个偏置电平，`NM1` 再用它做共栅（cascode）。这属于偏置技巧，**第一遍看可以先只记住"这里在分配电流"**。

### 4.2 主差分输入对 + 尾电流（`IP2`）

| 器件 | 漏 | 栅 | 源 | multi | 角色 |
|---|---|---|---|---|---|
| `PM9` | net4 | **VINP** | net37 | 2 | 输入对（正端） |
| `PM10` | net44 | **VINN** | net37 | 2 | 输入对（负端） |
| `PM1` | net37 | net6 | VDDA | 8 | 尾电流源 |

识别依据（不靠名字，靠结构）：**同型 + 源极同网 + 栅极分别接差分输入端口 + 互为镜像（对称）**。

### 4.3 级联有源负载（`NM6/NM7` + `NM4/NM5`，模块 `CM1`/`AL1`）

| 器件 | 漏 | 栅 | 源 | multi | 角色 |
|---|---|---|---|---|---|
| `NM6` | net4 | net53 | GNDA | 4 | 有源负载（电流镜） |
| `NM7` | net44 | net53 | GNDA | 4 | 有源负载（电流镜） |
| `NM4` | net0 | IREF | net4 | 4 | 级联管（共栅） |
| `NM5` | net8 | IREF | net44 | 4 | 级联管（共栅） |

**为什么用有源负载而不是电阻**：电流镜做负载时输出阻抗极高，同样的电流下能换来大得多的增益。`NM6/NM7` 和参考管 `NM2` 一起构成电流镜 `CM1`。

### 4.4 第二级：共源输出级（`PM7/PM11` + `NM8/NM9`）

| 器件 | 漏 | 栅 | 源 | multi | 角色 |
|---|---|---|---|---|---|
| `PM7` | **VOUTP** | net0 | VDDA | 4 | 输出管（共源，灌电流） |
| `PM11` | **VOUTN** | net8 | VDDA | 4 | 输出管（共源，灌电流） |
| `NM8` | **VOUTP** | net53 | GNDA | 4 | 输出电流源（吸电流） |
| `NM9` | **VOUTN** | net53 | GNDA | 4 | 输出电流源（吸电流） |

`NM8`/`NM9` 的栅也接 `net53`，所以它们是从偏置链复制来的**恒定电流源**；`PM7/PM11` 才是跟着信号变化的。一推一拉就得到输出摆幅。

`NM14`/`NM15` 也接在输出上（栅接 `IREF`，而且**漏和源都接同一个输出节点**，所以 Vds 恒为 0），它们不参与放大，等效为从输出节点到 `IREF` 的 MOS 电容/匹配器件。**看不懂是正常的，报告里如实说明即可。**

### 4.5 共模反馈环（`CMFB1`）：专管输出的"平均值"

**为什么必须有**：全差分电路的输出是两条线，差模信号（有用信号）可以靠反馈稳定，但**两条输出线的平均值（共模）没人管**——工艺/温度一变就可能漂到 VDDA 或 GNDA 上去，管子直接停止工作。所以必须加一圈专门反馈。

```
VOUTP ──[R0]──┐
              ├──► outaverage ──► PM12 的栅      ┌─ 比较对象：VCM (=VDD/2=0.9V)
VOUTN ──[R3]──┘        ▲                         │
                  [C2]/[C3] 滤波          PM8 的栅
                                              │
                        PM8/PM12 = 误差放大差分对（尾电流来自 PM4）
                                              │
                       net3 / net52 （漏极，负载是 NM12/NM13）
                                              │
                                    net52 ──[NM11 共栅]──► vcmfb
                                                              │
                                  [PM2]/[PM3]（multi=40，很大）──► net0/net8
                                                              （修正第二级栅压）
```

**环路怎么工作**：`R0`/`R3` 取平均 → `outaverage`；拿它和 `VCM` 比 → 误差放大 → 产生 `vcmfb` → `PM2/PM3` 往 `net0`/`net8` 注入修正电流 → 改变输出级电流 → 把输出平均值拉回 `VCM`。

- `R0`、`R3` 各是**一条 10 段串联的电阻链**（网表里写作 `R0` + `R0_2_res_gen` … `R0_10_res_gen`）。它们其实是**同一个物理器件**，只是被工具自动拆成 10 段。
- `PM2`/`PM3` 的 `multi=40`，是全电路最大的管子——因为共模环需要快速、有力地修正。
- `PM8`/`PM12` 是**辅助差分对**（`IP1`）：它们同样必须尺寸匹配，只是栅极接的不是主输入，所以判定时要和主输入对区分开。

### 4.6 频率补偿：`C11+R1` 与 `C0+R2`

| 器件 | 连接 | 作用 |
|---|---|---|
| `C11`（30u, m=2） | VOUTP ↔ net17 | 米勒补偿电容 |
| `R1` | net17 ↔ net0 | 调零电阻（消除右半平面零点） |
| `C0`（30u, m=2） | VOUTN ↔ net7 | 米勒补偿电容 |
| `R2` | net7 ↔ net8 | 调零电阻 |

两级放大器的相位裕度通常不够（容易振荡），所以在**输出**和**第二级输入（`net0`/`net8`）**之间跨一个电容，利用米勒效应把主极点拉低、让增益提前降下来——这就是 `PM`（相位裕度）能做合格的常用手段。串联电阻用来消掉米勒电容引入的右半平面零点。

### 4.7 追问答疑：一个"灌"一个"吸"，输出电压是怎么定下来的？

这是新手最容易卡住的地方：`PM7` 从 VDDA 往下灌、`NM8` 从 VOUTP 往 GNDA 吸，**凭什么电压就能停在某个值上？**

#### 第一步：先分清"灌"和"吸"是站在谁的角度说的

常规电流永远从**高电位流向低电位**。而 MOS 的电流通道在**漏和源之间**，方向由"谁的电位高"决定：

| 器件 | 源 | 漏 | 通道电流方向 | 站在 VOUTP 的角度 |
|---|---|---|---|---|
| `PM7` | VDDA(1.8V，高) | VOUTP(中间) | VDDA → VOUTP | **灌进来**（source 在高处） |
| `NM8` | GNDA(0V，低) | VOUTP(中间) | VOUTP → GNDA | **吸走**（drain 在节点上） |

所以"灌/吸"不是两种不同的物理机制——**是同一个机制，只是器件接在节点的上侧还是下侧**。

#### 第二步：MOS 的本质是"压控电流源"

真正要记住的一句话：**在饱和区，MOS 的漏电流基本只由栅源电压决定，跟漏源电压几乎无关。**

```
I_D ≈ ½·μCox·(W/L)·(Vgs − Vth)²        （NMOS）
I_D ≈ ½·μCox·(W/L)·(|Vgs| − |Vth|)²    （PMOS，用绝对值看）
```

"跟 Vds 无关"这一点极其重要：**它让 MOS 变成一个电流源**，而不是电阻。

#### 第三步：看两只管子的栅极分别接什么

| 器件 | 栅极接哪 | 这意味着 |
|---|---|---|
| `PM7` | `net0`（第一级的输出，**信号**） | 电流**随信号变化** → 它是"干活"的那只 |
| `NM8` | `net53`（偏置链的镜像栅，**固定**） | 电流**恒定不变** → 它是"电流源负载" |

`NM8` 的栅和 `NM6`/`NM7`/`NM2` 一样都接 `net53`，所以它就是**从偏置链按比例复制过来的一个恒流源**（复制倍数由它自己的 `W/L` 和 `multi=4` 决定）。

> 因为 `PM7` 是 PMOS，`Vgs = V(net0) − 1.8V`。所以 **`net0` 越低 → `|Vgs|` 越大 → 灌得越多**。这就是"反相"的来源。

#### 第四步：节点电压由"电流拔河"的平衡点决定（基尔霍夫电流定律）

`VOUTP` 这个节点在直流上只有这两条主要电流路径，**流进去的必须等于流出来的**：

```
        VDDA (1.8V)
             │
        ┌────┴────┐
        │  PM7    │  ← 栅 = net0（信号）：信号越"低"，灌得越多
        │ PMOS    │
        └────┬────┘
             │  ↓ I_PM7（可变）
    VOUTP ───┼──────────► 输出节点
             │  ↓ I_NM8（恒定）
        ┌────┴────┐
        │  NM8    │  ← 栅 = net53（偏置）：电流恒定
        │ NMOS    │
        └────┬────┘
             │
          GNDA (0V)

    直流平衡条件：  I_PM7(VOUTP, net0) = I_NM8
                    └── 随 VOUTP 和 net0 变化 ──┘   └─ 固定 ─┘
```

- 如果 `PM7` 灌的**多于** `NM8` 吸的 → 多余的电流只能给节点电容充电 → **VOUTP 上升**；
- 上升会反过来改变 `PM7` 的 `Vds`，直到两边电流重新相等；
- 于是节点**自动停在**让两边相等的那个电压上。

一句话：**`NM8` 定"吸多少"，`PM7` 定"灌多少"，电压自己跑到两者相等的位置。**

#### 第五步：那为什么这个平衡点恰好"有用"？

因为输出要有大增益、要有对称摆幅，两只管子都必须待在**饱和区**：

```
NM8 饱和要求：  VOUTP > Vgs,N − Vth,N  ≈ 0.2~0.3 V        （不能太低）
PM7 饱和要求：  VOUTP < 1.8V − |Vgs,P − Vth,P|  ≈ 1.5~1.6 V（不能太高）

所以输出只能在中间一段区间里摆 → 静态点自然要定在 ≈ VDD/2 = 0.9 V
```

而"把输出平均值钉在 0.9 V"这件事，正是**共模反馈环**（第 4.5 节）在干的活：它把 `VOUTP` 和 `VOUTN` 的平均值强行拉到 `VCM = VDD/2`，保证两只输出管都舒服地待在饱和区、上下摆幅对称。

#### 小结：三句话记住它

1. **MOS 是压控电流源** —— 栅压决定电流，Vds 基本不影响电流。
2. **一个节点的电压 = 流入电流与流出电流相等的地方**（KCL）。管子只是"按电压决定电流"的阀门。
3. **上管灌、下管吸 = 推挽结构** —— 上管跟着信号变，下管恒定，差值被节点电压消化掉。

> 顺带回答另一个常见疑问："为什么输出级要叫 class-A？"因为 `NM8` 的电流**永远不为零**，`PM7` 也始终有电流——两只管子一直在导通，只是大小在变。这也正是 `I_OPA ≤ 3 mA` 这条约束卡的来源：全电路每条支路的静态电流加起来就是电源电流。

### 4.8 追问答疑：为什么 `VOUTP` 就是"放大后的输出"？

因为 `VOUTP` 是**最后一个"高阻节点"**——而放大器的增益本质上就是"**电流的变化 × 大电阻**"。信号只有落在高阻节点上，才能从小电流变成大幅度电压。

**"输出"的两层含义**：第一层是**接口约定**（`subckt OPA (... VOUTN VOUTP)` 把它列成了对外端口）；第二层才是你真正在问的——为什么信号在那里真的变大了。

**增益链路（两级都是"电流 × 大电阻"）**：

```
VINP/VINN ─① 差分对把电压差变成电流差─► gm1·(vinp−vinn)（微安级）
          ─② 这股电流流进高阻节点 net0/net8─► 电压 = 电流 × R_net0（R 很大）
          ─③ PM7 把栅压变化再变成漏电流变化─► gm2·Δv(net0)
          ─④ 这股电流流进输出节点 VOUTP─► 电压 = 电流 × R_out（R 也很大）
```

```
一级增益 A1 = gm1 · R_net0     （R_net0 ≈ ro_NM4级联 ∥ ro_PM2）
二级增益 A2 = gm2 · R_VOUTP    （R_VOUTP ≈ ro_PM7 ∥ ro_NM8）
总增益   A  = A1 · A2          （换算 dB 就是两级相加）
```

**为什么必须站在高阻节点上**：同样 1 µA 的电流变化，落在 1 kΩ 上只有 1 mV，落在 1 MΩ 上就是 1 V。这就是**不能用电阻做负载**的原因——电阻不能太大（会占掉电压余量、让管子掉出饱和区），而**恒流源**的等效阻抗是 `ro`（几十 kΩ~MΩ 级），同样的电流能换来大得多的电压。

**旁边的节点为什么都不是输出**：

| 节点 | 为什么不是输出 |
|---|---|
| `net37` | 差分对的**尾节点**，差模信号在这里正好互相抵消，**差模信息根本不出现** |
| `net4`/`net44` | 信号在这，但马上被级联管 `NM4/NM5` 接走，且阻抗不高 |
| `net0`/`net8` | **是**第一级的增益节点，但还要去驱动第二级，从接口上讲不对外 |
| `VOUTP` | 被末级驱动 + 高阻抗 + 对外引出 → **终端输出** ✓ |

**从网表怎么"认出"输出节点（模块二的识别思路）**——四条线索同时指向 `VOUTP`：

1. **它是端口**：`subckt OPA (... VOUTN VOUTP)` 里明确列着（*接口约定*）；
2. **它被"最后一级"驱动**：`PM7 (VOUTP net0 VDDA VDDA)` 的漏极就是它（*结构证据*）；
3. **它上面挂着补偿和负载**：`C11`(VOUTP↔net17)、测试台的 `CC2`(100 fF)（*结构证据*）；
4. **有反馈网络从它取样**：`R0` 从 `VOUTP` 取样到 `outaverage`（*结构证据*）。

**全差分视角**：`VOUTP` 和 `VOUTN` 永远**反相**——`net0` 升 → `PM7` 灌得少 → `VOUTP` 降；同时 `net8` 降 → `PM11` 灌得多 → `VOUTN` 升。所以

```
差模输出（有用信号）  VOUTP − VOUTN       ← 相减得到 2 倍有用信号
共模输出（要稳住的）  (VOUTP + VOUTN)/2   ← CMFB 钉在 VCM = 0.9 V
```

### 4.9 追问答疑：什么是 CMFB 误差放大器？

**它就是共模反馈环里那个"比较 + 放大"的电路**：把**输出的平均值**和**目标值 `VCM`** 相减，把这点微小的差值放大成控制电压 `vcmfb`，再由 `PM2/PM3` 去修正输出。名字里的"误差"就是"实际值 − 期望值"。

```
VOUTP ──R0──┐
            ├──► outaverage ──► ① 比较 ──► ② 放大 ──► ③ 修正
VOUTN ──R3──┘         ▲            │            │          │
                  C2/C3 滤波        │            │          ▼
                                和 VCM         vcmfb     net0/net8
                              (0.9V)比较    (控制电压)  (改输出级电流)
```

| 环节 | 器件 | 干什么 |
|---|---|---|
| **① 取样** | `R0`、`R3` | 电阻分压，取出两条输出的**平均值** → `outaverage` |
| **① 滤波** | `C2`、`C3` | 滤掉取样点上的交流纹波，只留缓慢变化的共模电平 |
| **② 比较 + 放大** | `PM8`（栅=VCM）、`PM12`（栅=outaverage）、尾 `PM4`、负载 `NM12/NM13` | **误差放大器本体（一颗 5 管 OTA）** |
| **② 输出级** | `PM6`、`NM11` | 把放大后的**电流**转成**电压** `vcmfb` |
| **③ 修正注入** | `PM2`、`PM3`（`multi=40`，全电路最大） | 往 `net0`/`net8` 注入修正电流 |

**误差放大器本体，就是一个"小运放"**：

```
                 VDDA
                  │
             ┌────┴────┐
             │  PM4    │ 尾电流源（栅 net6，multi=4）
             └────┬────┘
                  │ net13（尾节点）
        ┌─────────┴─────────┐
   ┌────┴────┐         ┌────┴────┐
   │  PM8    │         │  PM12   │   PMOS 差分输入对
   │ 栅=VCM  │         │栅=outaverage│  ← 一个接"期望值"，一个接"实际值"
   └────┬────┘         └────┬────┘
        │ net3              │ net52
   ┌────┴────┐         ┌────┴────┐
   │ NM12    │         │ NM13    │   电流镜负载（栅 net53）
   └────┬────┘         └────┬────┘
        │                   │
      GNDA                 ▼ 经 NM11（共栅）→ vcmfb
```

和主输入对 `PM9/PM10` 的唯一区别：那两个栅接的是**要放大的信号**（`VINP/VINN`），这两个栅接的是**期望值 `VCM`** 和**实际值 `outaverage`**。所以它放大的不是信号，而是"**共模偏离了多少**"这个误差。

**极性验证（为什么是负反馈）**——假设输出共模升高（`outaverage > VCM`）：

```
① outaverage ↑ → PM12（PMOS）|Vgs| 减小 → PM12 电流减小
   → 尾电流由 PM4 固定，电流被重新分配：PM8 分到更多
② net52 = PM12 漏极（供电流）+ NM13（恒定吸电流）→ 供少吸不变 → net52 ↓
③ NM11 共栅（源=net52、栅=IREF 固定）→ Vgs 增大 → 导通更多 → vcmfb ↓
④ vcmfb ↓ → PM2/PM3（PMOS，栅=vcmfb）灌入 net0/net8 的电流增加 → net0/net8 ↑
⑤ net0/net8 ↑ → PM7/PM11（PMOS 共源）|Vgs| 减小 → 电流减小 → VOUTP/VOUTN ↓
结果：输出共模一升高就被压回来 → 负反馈 ✓（共模降低时整条链反向工作）
```

**生活类比：空调温控**——`R0/R3` = 温度传感器，`VCM` = 设定温度，`PM8/PM12` = 比较电路，`vcmfb` = 压缩机功率控制信号，`PM2/PM3` = 压缩机。

**为什么不能靠主放大器自己搞定共模**：主放大器的输入对只对**差模**（`VINP − VINN`）敏感；两条输出线一起升高这种"共同动作"，在它的差模通路里**根本不产生信号**。所以必须另开一条专门看共模的通路。

**CMFB 的三种常见做法**（这颗用的是第一种）：

| 环节 | 可选方案 | 这颗电路 |
|---|---|---|
| 共模**取样** | 电阻分压 / 电容分压 / 差分对直接取 | **电阻分压** `R0`/`R3` + `C2/C3` 滤波 |
| **误差放大** | 单级差分对 / 折叠级联 / 带增益级 | **单级 PMOS 差分对** `PM8`/`PM12` |
| **修正注入** | 注入第一级高阻节点 / 注入尾电流 / 控制负载 | **注入第一级高阻节点** `net0`/`net8` |

> 工程含义：**CMFB 环路自己也要稳定**（不能振荡，且带宽要够）。这是模拟设计里的经典难点，也是技术报告里可以写的技术点。

## 5. 三个"看着奇怪"的地方

### 5.1 `R5 R6 C4 C5` 像是白画的

```
R5 (net11 net11)    C4 (net11 net11)
R6 (net12 net12)    C5 (net12 net12)
```

两个端子接**同一个网**，而且 `net11`/`net12` **除它们之外不接任何器件**。这意味着：

- 器件两端电压恒为 0 → 电流恒为 0 → **尺寸取任何值都不会改变任何仿真结果**；
- 它们既不是去耦电容也不是参考电阻，而是**电气上完全惰性的器件**（版图上常见于 dummy/填充）。

所以它们应该被判为 **Dummy/惰性器件，其尺寸变量直接剔除**（但器件本身保留在网表里，保证电路等价）。这是模块二的真实考点之一。

### 5.2 编号跳号了

- MOS：`NM0`–`NM15`（16 只，齐全）、`PM0`–`PM12`（13 只，齐全）✓
- 电阻：`R0 R1 R2 R3 R5 R6` —— **`R4` 不存在**
- 电容：`C0 C2 C3 C4 C5 C11` —— **`C1`、`C6`~`C10` 不存在**

这是原理图/导出过程的**编号残留**，不是漏读。

### 5.3 `net53` 上挂着一大堆栅极

`net53` 是偏置链造出来的电流镜栅压，`NM3 NM6 NM7 NM8 NM9 NM12 NM13` 的栅全在这里。这是**电流镜的分发节点**，非常正常。类似的还有 `IREF`（8 只管子的栅）、`net6`、`net5`。

## 6. 测试台在干什么（怎么测出增益 / PM / GM）

`subckt OPA` 之外的那 12 个器件就是**测试台（testbench）**，`I0` 才是运放本体：

```
I0 (IREF GND SUB net1 net2 vin_n vin_p vout_n vout_p) OPA
    └─ 把 OPA 的 9 个端口一个个接上测试台
```

| 器件 | 作用 |
|---|---|
| `VV_P` | 电源 `VDD = 1.8 V` |
| `VV0` / `VV1` | 地 / 衬底 = 0 V |
| `II12` | **偏置电流源**：从 VDD 灌 10 µA 进 `IREF`（`I_BIAS=10u`） |
| `VV3` | 造出 `net1 = VDD/2 = 0.9 V`，作为**输入共模基准** |
| `RR0` | **10 mΩ 采样电阻**：VDD→`net2`（=运放的 VDDA）。量 `V(VDD)−V(net2)` 再除以 10 mΩ 就能得到 **I_OPA** |
| `E0` / `E2` | 两个压控电压源（增益 0.5），把 `net0` 的单端交流信号转成**差分激励**；共模点钉在 `net1` |
| `V5` | 交流激励源（`net0`，幅度 1） |
| `CC0` / `CC2` | 每个输出对地 100 fF 的负载电容 |

**关键**：因为

```
V(vin_p) − V(vin_n) = V(net0) = 1 V（交流）
```

输入差分电压恰好是 1 V，所以**输出差分电压的模就是差分增益**：

```
A(jω) = |vout_p − vout_n|
```

`OPA_loopgain.scs` 里做的就是这件事：

```
ac ac start=1 stop=1G dec=10      ← 1 Hz 扫到 1 GHz
save vout_p vout_n                ← 只存这两条曲线
```

MDE 从这条曲线里读出 **直流增益、UGB（单位增益带宽）**，并据此推算 **PM（相位裕度）、GM（增益裕度）**。
注意这条曲线测的是**开环**增益 A(s)；在单位反馈下环路增益就等于 A(s)，这就是它叫 `loopgain` 的原因。

## 附：三个最容易劝退新手的错觉

| 你以为 | 其实 |
|---|---|
| `+ad=(NM15_fw<300n)?(...)` 是乱码 | 是版图寄生参数表达式，**看电路时整块跳过** |
| `l=NM15_l` 是写错了 | 是**参数化变量名**，等着优化器填数字 |
| 这电路太对称了，是不是重复了 | 全差分电路**本来就该两边完全对称**；而"两边对称"正是识别匹配器件、做参数约减的抓手 |
